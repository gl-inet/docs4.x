# Прискорення мережі {#network-acceleration}

Прискорення мережі зменшує навантаження на CPU та прискорює пересилання пакетів, але може конфліктувати з деякими функціями.

Коли прискорення мережі увімкнено, такі функції працюють некоректно: Client Speed and Traffic Statistics та Client Speed Limit.

## Налаштування {#setup}

У лівому меню вебпанелі адміністрування відкрийте **NETWORK** -> **Network Acceleration**.

![Прискорення мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/network_acceleration/network_acceleration.png){class="glboxshadow"}

Доступні три режими.

- **Auto**

    Режим Auto автоматично перемикається між двома режимами прискорення відповідно до фактичного використання.

- **Hardware Acceleration**

    Апаратне прискорення працює з <u>Ethernet</u> і <u>Repeater</u>.

    Апаратне прискорення передає часто виконувані мережеві завдання, наприклад NAT, пересилання пакетів і перевірку контрольних сум, спеціалізованому обладнанню, зокрема NPU або мікросхемам HWNAT. Воно працює з Ethernet (дротовими WAN/LAN) і підключеннями Repeater. У цих сценаріях із фіксованими шляхами та простими правилами воно забезпечує високу пропускну здатність, низьку затримку та мінімальне навантаження на CPU для передавання даних на швидкості фізичного з’єднання.

- **Software Acceleration**

    Програмне прискорення працює з <u>Cellular</u>.

    Програмне прискорення використовує звичайний CPU маршрутизатора разом з оптимізованими ядрами або драйверами, наприклад SWNAT. Воно працює зі стільниковим доступом Cellular (4G/5G), де апаратне прискорення зазвичай недоступне, та забезпечує сумісність і підтримку складних протоколів. Попри гнучкість, за високої пропускної здатності продуктивність може обмежуватися CPU, особливо під час використання додаткових функцій, як-от DPI, QoS або перенаправлення портів.
