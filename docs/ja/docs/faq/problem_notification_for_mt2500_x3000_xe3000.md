# GL-MT2500/GL-X3000/GL-XE3000に関する重要な問題のお知らせ {#critical-problem-notification-for-gl-mt2500gl-x3000gl-xe3000}

お客様各位

このお知らせは、GL-MT2500/GL-X3000/GL-XE3000デバイスにおける起動障害とU-Boot経由でのファームウェアリカバリーの問題に対処するためのものです。この問題は、一部のパラメーターが正しく定義されていなかったソフトウェアの不具合が原因で、ルーターが正常に動作していませんでした。その結果、この問題によりルーターの寿命がある程度短くなる可能性があると判断いたしました。心よりお詫び申し上げます。

この問題を完全に解決するために、GL-MT2500、GL-X3000、GL-XE3000のすべてのユーザーに、U-Bootブートローダーアップグレードとファームウェアアップグレードの両方を実行することを強くおすすめします。どちらのアップグレード手順も必須であり、省略しないでください。

デバイスがすでに最新ファームウェアにアップグレードされている場合でも、潜在的な問題を防ぐためにU-Bootブートローダーアップグレードは必須です。U-Bootブートローダーアップグレードを完了した後、最新ファームウェアがすでにインストールされている場合は、ファームウェアの再インストールをスキップできます。

アップグレードにはChromeまたはMicrosoft Edgeを使用してください。Mozilla/Firefoxは**使用しないでください**。

## GL-MT2500 {#gl-mt2500}

1. U-Bootブートローダーを[バージョン2025-02-24 15:04:07](https://github.com/gl-inet/mt798x-boot/blob/main/bin/uboot-mt2500-20250224-md5-74286e770cfb041b611d80d4adaef189.bin){target="_blank"}にダウンロードしてアップグレードします

2. ファームウェアを[バージョン4.7.4](https://fw.gl-inet.com/firmware/mt2500/release/openwrt-mt2500-4.7.4-0328-1743128340.bin)にダウンロードしてアップグレードします
