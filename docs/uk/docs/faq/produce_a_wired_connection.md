# Як підключити пристрій лише з Ethernet до Wi-Fi через маршрутизатор GL.iNet? {#how-to-connect-an-ethernet-only-device-to-wi-fi-with-a-glinet-router}

Якщо пристрій підтримує лише підключення Ethernet, але йому потрібен доступ до бездротової мережі, допоможе маршрутизатор GL.iNet.

Маршрутизатор GL.iNet може працювати як міст Ethernet–Wi-Fi для пристроїв лише з дротовим підключенням, даючи їм змогу приєднатися до бездротової мережі. Для цього налаштуйте маршрутизатор як Repeater.

Підключіть пристрій до порту LAN маршрутизатора, а потім налаштуйте [ретранслятор](../interface_guide/internet_repeater.md).
