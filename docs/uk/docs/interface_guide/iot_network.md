# Мережа IoT {#iot-network}

**Примітка**: Функція IoT Network з’явилася у прошивці v4.9.

---

У меню ліворуч у вебпанелі адміністрування перейдіть до **NETWORK** -> **IoT Network**.

На цій сторінці можна створити окрему мережу Wi-Fi для пристроїв IoT. Вона ізольована від основної мережі, що забезпечує кращу сумісність і вищий рівень безпеки.

**Примітка**: Деякі моделі (наприклад, GL-MT5000, GL-MT2500/GL-MT2500A) не підтримують Wi-Fi, тому налаштування IoT Network недоступні в їхній вебпанелі адміністрування.

Сторінка містить два розділи: Basic Settings і DHCP Server Settings.

## Основні налаштування {#basic-settings}

Можна задати підмережу в межах приватних діапазонів IPv4-адрес: `192.168.0.0/16`, `172.16.0.0/12`, `10.0.0.0/8`.

![Основні налаштування мережі IoT](https://static.gl-inet.com/docs/router/en/4/interface_guide/iot_network/iot1.png){class="glboxshadow"}

- **Gateway**

    **Шлюз за замовчуванням** мережі IoT — **192.168.10.1**. Якщо його адреса конфліктує з локальною мережею, змініть її.

- **Netmask**

    За замовчуванням — **255.255.255.0**. Якщо потрібна більша підмережа з більшою кількістю IP-адрес, виберіть **255.255.0.0**.

- **AP Isolation**

    Ця функція доступна починаючи з прошивки v4.5.

    Можна ізолювати клієнтські пристрої в окремому сегменті мережі. Вони не зможуть обмінюватися даними з іншими пристроями в тій самій мережі.

- **Block WAN Subnets**

    Ця функція доступна починаючи з прошивки v4.8.

    Коли ввімкнено, мережа IoT не може отримувати доступ до мережі вищого рівня та її підмережі.

## DHCP-сервер {#dhcp-server}

Коли мережу IoT увімкнено, її DHCP-сервер також умикається.

DHCP-сервер автоматично призначає IP-адреси та інші параметри зв’язку кожному клієнтському пристрою, підключеному до мережі IoT. Якщо DHCP-сервер вимкнено, налаштуйте мережеві параметри клієнтських пристроїв вручну. Інструкції з налаштування статичної IP-адреси наведено [тут](../tutorials/manually_configure_static_ip.md).

Можна змінити початкову та кінцеву IP-адреси відповідно до потреб, наприклад у разі розширення або зменшення мережі, конфліктів IP-адрес чи зміни діапазону маски підмережі.

![Налаштування DHCP-сервера мережі IoT](https://static.gl-inet.com/docs/router/en/4/interface_guide/iot_network/iot2.png){class="glboxshadow"}

За потреби натисніть **Advanced**, щоб виконати додаткові налаштування.

![Відкриття додаткових параметрів DHCP](https://static.gl-inet.com/docs/router/en/4/interface_guide/iot_network/iot3.png){class="glboxshadow"}

![Додаткові параметри DHCP-сервера](https://static.gl-inet.com/docs/router/en/4/interface_guide/iot_network/iot4.png){class="glboxshadow"}

- **Lease Time**: Термін дії IP-адреси, призначеної пристрою DHCP-сервером.

- **Gateway**: Пристрій, який спрямовує трафік між мережею IoT і зовнішніми мережами, наприклад інтернетом.

- **DNS Server 1**: Основний сервер, який перетворює доменні імена на IP-адреси.

- **DNS Server 2**: Додатковий сервер для перетворення доменних імен, якщо основний DNS-сервер недоступний.

- **LPR Server**: (Line Printer Remote Server) Служба, яка керує завданнями друку та дає змогу мережевим пристроям надсилати запити на друк віддаленим принтерам. Можна налаштувати кілька портів принтерів LPR.
