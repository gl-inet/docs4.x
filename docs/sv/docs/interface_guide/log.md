# Log {#log}

Öppna **SYSTEM** -> **Log** på vänster sida i webbadministrationspanelen.

Sidan Log visar loggar för System, Kernel, Crash, Cloud och Nginx för analys och felsökning.

Some cellular models that supports eSIM provides eSIM log.

Here's an example of GL-X3000.

![log page](https://static.gl-inet.com/docs/router/en/4/interface_guide/log/log.png){class="glboxshadow"}

**Filtrering** är tillgänglig på System Log från firmware v4.8. Välj nivå eller modul eller ange sökord.

Klicka på **Refresh** för senaste logginformationen.

Klicka på **Export Log** för att exportera System-, Kernel-, Crash- och Cloud-loggar. Skicka filen till GL.iNets tekniska support för snabbare analys.
