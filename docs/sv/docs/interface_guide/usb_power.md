# USB & Power {#usb-power}

**Note**: This page is only available on **GL-E5800 (Mudi 7)**.

Öppna **SYSTEM** -> **USB & Power** på vänster sida i webbadministrationspanelen.

På sidan konfigurerar du USB-protokoll, strömriktning, tidsgränser för inaktivitet och vänteläge.

## USB Settings {#usb-settings}

Avsnittet anpassar routerns USB-portar.

![usb settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/usb_power/e5800_usb.png){class="glboxshadow"}

- **USB Protocol Switch**: Växla USB-porten mellan USB 2.0 och USB 3.1.

- **Dual Role USB Mode**: Välj Device eller Host i listrutan.

    ![usb role](https://static.gl-inet.com/docs/router/en/4/interface_guide/usb_power/usb_role.png){class="glboxshadow"}

- **Power Direction**: Välj Input Priority eller Output Priority för USB-porten.

- **Power Threshold**: Set a specific power threshold percentage for the USB port to control the minimum power level required for USB operations, helping to preserve battery life.

## Power Settings {#power-settings}

Avsnittet optimerar strömförbrukning och enhetsfunktion.

![power settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/usb_power/e5800_power.png){class="glboxshadow"}

- **Wi-Fi Idle Timeout**: Ange 10 minuter till 2 timmar eller aldrig innan Wi-Fi går i vänteläge.

- **Ethernet Idle Timeout**: Ange 10 minuter till 2 timmar eller aldrig innan Ethernet går i vänteläge.

- **Power Off Timeout**: Ange 1 till 12 timmar eller aldrig innan routern stängs av vid inaktivitet.

- **Power On with Charger**: Ange om routern ska slås på automatiskt när en laddare ansluts.

- **Auto Standby**: Toggle this switch to activate/deactivate automatic standby for power saving.
