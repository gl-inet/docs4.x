# Fortify (GL-MT6000) ユーザーガイド

## 製品概要

Fortify (GL-MT6000) は、GL.iNet と ExpressVPN が共同でリリースした共同ブランドの Wi-Fi 6 ルーターです。すべてのユニットには、1 年間の ExpressVPN サブスクリプションが無料で付属しています。ユーザーはサブスクリプションを引き換えて、ルーターの Web 管理パネルでアカウントに直接接続できます。アクティブ化すると、ルーターを通過するすべてのトラフィックはExpressVPNの高速ネットワークと堅牢な暗号化を利用して、ネットワーク接続全体とオンラインプライバシーを保護します。

![fortify gl-mt6000](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/mt6000-fortify_interface.png){class="glboxshadow"}

## Fortifyのセットアップ方法

### 1. 電源を入れる

2 ピースの電源アダプターを組み合わせます。 Fortify ルーターに接続し、コンセントに差し込みます。自動的に起動します。

### 2. デバイスを接続します

デバイス（パソコン、ノートパソコン、スマートフォンなど）をWi-FiまたはEthernetでルーターに接続します。

- イーサネット

    イーサネット ケーブルを使用してデバイスをルーターの LAN ポートに接続します。

- Wi-Fi

    デバイスで、[設定] -> [WLAN] に移動し、利用可能なネットワークのリストでルーターの Wi-Fi ネットワーク名を見つけ、ネットワークに参加するためのパスワードを入力します。デフォルトのネットワーク名とパスワードはルーターのラベルに記載されています。

### 3. Web 管理パネルにログインします。

Web ブラウザを開き、アドレス バーに「`192.168.8.1`」と入力してログインします。右上隅で言語を選択し、管理者パスワードを設定して、「**Next**」をクリックします。パスワードの長さは 10 ～ 63 文字で、大文字、小文字、数字、特殊記号のうち少なくとも 2 つを含む必要があります。

![fortify login1](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/login1.png){class="glboxshadow"}

Wi-Fi をセットアップします。 Wi-Fi 情報を変更した場合は、更新された認証情報を使用してデバイスをルーターの Wi-Fi に再接続する必要があることに注意してください。

![fortify login2](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/login2.png){class="glboxshadow"}

### 4. インターネットのセットアップ

**注：** 次の手順は、GL.iNet Web管理画面からルーターを設定する場合に適用されます。[GL.iNetアプリ](https://www.gl-inet.com/pages/app#download-app-glinet){target="_blank"}を使用する場合は、アプリをダウンロードし、画面の案内に従ってください。

サポートされているインターネット接続方法 (イーサネット、リピーター、テザリング、セルラー) のいずれかを使用して Fortify を構成します。 [マルチ WAN](../../interface_guide/multi-wan.md) 機能を使用する場合は、複数のインターネット接続を設定してください。

=== "Ethernet"

    ![Ethernet Connection](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/mt6000_ethernet.png){class="glboxshadow"}

    Fortify ルーターの WAN ポートとモデムなどの上流のデバイスをイーサネット ケーブルで接続します。

    インターネットに正常に接続されると、ルーターの LED が白色に点灯します。

    詳細な手順については、[イーサネット ケーブルを介してインターネットに接続する](../../interface_guide/internet_ethernet.md) を参照してください。

=== "Repeater"

    ![Repeater Connection](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/mt6000_repeater.png){class="glboxshadow"}

    1. Web 管理パネルで、[インターネット] -> [リピータ] セクションに移動し、[**Connect**] をクリックします。
    2. 利用可能なネットワークから Wi-Fi を選択します。
    3. パスワードを入力し、「**Apply**」をクリックします。

    インターネットに正常に接続されると、ルーターの LED が白色に点灯します。

    詳細な手順については、[既存の Wi-Fi ネットワーク経由でインターネットに接続する](../../interface_guide/internet_repeater.md) を参照してください。

=== "Tethering"

    ![Tethering Connection](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/mt6000_tethering.png){class="glboxshadow"}

    1. USB ケーブルを使用してスマートフォンをルーターの USB ポートに接続します。
    2. スマートフォンで [設定] に移動し、USB テザリングを有効にします。 iPhone の場合、このデバイスを信頼し、パーソナル ホットスポットを有効にします。
    3. Web 管理パネルで、[インターネット] -> [テザリング] セクションに移動し、[**Connect**] をクリックします。

    インターネットに正常に接続されると、ルーターの LED が白色に点灯します。

    詳しい手順については、[USBテザリングでインターネットに接続する](../../interface_guide/internet_tethering.md)をご覧ください。

=== "Cellular"

    ![Cellular Connection](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt6000-fortify/mt6000_cellular.png){class="glboxshadow"}

    セルラー USB モデムをルーターの USB ポートに接続します。これは、USB モデムから接続されているすべてのデバイスにインターネットを共有する場合に便利です。

    インターネットに正常に接続されると、ルーターの LED が白色に点灯します。

    詳細な手順については、[セルラー経由でインターネットに接続する](../../interface_guide/internet_cellular.md) を参照してください。

以下は、Fortify Web 管理パネルの機能の概要です。

## ワイヤレス

[ワイヤレス] ページでは、メイン ネットワーク、ゲスト ネットワーク、IoT ネットワークなどの Fortify の Wi-Fi ネットワークを構成できます。各ネットワークは、2.4 GHz 帯域と 5 GHz 帯域の両方をサポートします。

ワイヤレスを設定するには、[ワイヤレス](../../interface_guide/wireless.md)を参照してください。

## クライアント

[クライアント] ページには、デバイス名、接続タイプ、IP および MAC アドレス、ダウンロードおよびアップロードの速度、トラフィックなど、接続されているデバイスに関する情報が表示され、ワンクリックで特定のクライアントをブロックしたり、他のアクションを実行したりする機能が提供されます。

詳細については、[クライアント](../../interface_guide/clients.md)を参照してください。

## クラウドサービス

=== "GoodCloud"

    GL.iNet [GoodCloud](https://www.goodcloud.xyz){target="_blank"}を使用すると、GL.iNetルーターへ簡単にリモートアクセスして管理できます。

    詳細については、[GoodCloud](../../interface_guide/cloud.md)を参照してください。

=== "AstroWarp"

    AstroWarp は、GL.iNet ルーター上でシームレスなリモート ネットワーキングのために構築された機能です。トラフィック難読化機能が組み込まれた AmneziaWG プロトコルを採用し、いつでもどこでも安定した安全なリモート アクセスを実現します。

    詳細は[AstroWarp](../../interface_guide/astrowarp.md)をご参照ください。

## VPN

VPN (virtual private network) は、ローカル デバイスと VPN サーバーの間に安全な暗号化されたトラフィック トンネルを確立します。これにより、VPN クライアントにプライバシーとセキュリティの追加層が追加され、リモート VPN サーバー ネットワークへのアクセスが可能になります。

Fortifyは[ExpressVPN](https://www.expressvpn.com/){target="_blank"}と統合されており、ExpressVPN接続を数分で有効にできます。すべてのFortifyには、1年間のExpressVPNサブスクリプションが付属しています。ルーターのWeb管理画面からサブスクリプションを引き換え、ExpressVPNアカウントを直接接続できます。VPN接続を有効にすると、ルーターを経由するすべてのトラフィックでExpressVPNの高速サーバーと強力な暗号化が使用され、ネットワーク全体とオンラインプライバシーが保護されます。

無料のサブスクリプションを引き換えて VPN トンネルを設定するには、[ExpressVPN アクティベーション ガイド](../../interface_guide/expressvpn_activation_guide.md) を参照してください。

OpenVPN サーバーをセットアップするには、[OpenVPN サーバー](../../interface_guide/openvpn_server.md) を参照してください。

WireGuard サーバーをセットアップするには、[WireGuard サーバー](../../interface_guide/wireguard_server.md) を参照してください。

## ネットワーク

=== "Multi-WAN"

    マルチ WAN は、同時に複数のインターネット接続 （Cellular、Repeater、Ethernetなど） を使用してルーターをセットアップできるネットワーク機能です。現在のインターネット接続に障害が発生した場合、ルーターは自動的に別のインターネット接続に切り替えます。これにより、スムーズで中断のないインターネット アクセスが保証されます。

    詳細については、[Multi-WAN](../../interface_guide/multi-wan.md)を参照してください。

=== "LAN"

    LAN (ローカル エリア ネットワーク) は、家庭やオフィスなどの限られた地理的エリア内のコンピュータとデバイスを接続するネットワークです。これは、デバイスがメイン Wi-Fi またはイーサネット ケーブルに接続されているときに参加するローカル ネットワークです。 LAN ページでは、基本設定、DHCP サーバー設定、アドレス予約について説明します。

    詳細については、[LAN](../../interface_guide/lan.md)を参照してください。

=== "Guest Network"

    [ゲスト ネットワーク] ページでは、訪問者専用の Wi-Fi ネットワークを作成できます。プライマリ ネットワークから分離されているため、セキュリティが強化されると同時に、便利なインターネット アクセスが提供されます。 IPv4 プライベート アドレス範囲 `192.168.0.0/16`、`172.16.0.0/12`、または `10.0.0.0/8` 内にゲスト サブネットを設定し、ゲートウェイとネットマスクの IP アドレスを指定できます。

    詳細については、[ゲストネットワーク](../../interface_guide/guest_network.md)を参照してください。

=== "IoT Network"

    [IoT ネットワーク] ページでは、IoT デバイス専用の Wi-Fi ネットワークを作成できます。プライマリ ネットワークから分離されているため、互換性が向上し、セキュリティが向上します。

    詳細は[IoTネットワーク](../../interface_guide/iot_network.md)をご覧ください。

<br>

=== "DNS"

    ルーターの DNS 設定は、ドメイン名を IP アドレスに変換する方法を制御します。このページでは、上流のデバイスから自動的に取得された DNS サーバー(s) を使用したり、カスタムのサーバーを設定したり、DNS 優先順位を構成したりできます。

    詳細については、[DNS](../../interface_guide/dns.md)を参照してください。

=== "Ethernet Port"

    [イーサネット ポート] ページでは、イーサネット ポートの役割 (WAN/LAN) を管理し、MAC アドレスやネゴシエートされた速度などのポートの詳細を表示できます。

    詳細については、[イーサネットポート](../../interface_guide/ethernet_port.md)を参照してください。

=== "IPv6"

    IPv6 (インターネット プロトコル バージョン 6) は、IPv4 を置き換えるように設計されたインターネット プロトコルの最新バージョンです。非常に大きなアドレス空間を提供し、事実上無制限の数の一意の IP アドレスを許可します。これは、インターネットに接続されるデバイスの増加に対応するために不可欠です。

    詳細については、[IPV6](../../interface_guide/network_mode.md)を参照してください。

=== "IGMP Snooping"

    IGMP スヌーピングは、イーサネット スイッチでマルチキャスト トラフィックを管理および制御するために使用されるネットワーク最適化手法です。

    詳細については、[IGMP Snooping](../../interface_guide/igmp_snooping.md)を参照してください。

<br>

=== "Network Mode"

    ネットワーク モードとは、デバイスがネットワークに接続し、他のデバイスと通信する方法を決定する構成設定を指します。

    ネットワークモードを設定するには、[ネットワークモード](../../interface_guide/network_mode.md)を参照してください。

=== "Drop-in Gateway"

    ドロップイン ゲートウェイは、AdGuard ホーム、暗号化 DNS、VPN など、メイン ルーターにはない機能を追加して、メイン ルーターの機能を拡張します。

    ドロップインゲートウェイの設定方法については、[ドロップインゲートウェイの設定方法](../../tutorials/how_to_set_up_drop_in_gateway.md)を参照してください。

=== "Network Acceleration"

    ネットワークの高速化により、CPU の負荷が軽減され、トラフィック パケットの転送が高速化されます。

    ネットワーク アクセラレーションを設定するには、[ネットワーク アクセラレーション](../../interface_guide/network_acceleration.md) を参照してください。

## フロー制御

=== "DPI Engine"

    DPI (Deep Packet Inspection) は、インテリジェントなネットワーク管理の中核機能です。従来のルーター （送信元または宛先アドレスのみを識別するもの） の制限を克服し、データ パケット ペイロードを詳細に分析し、機能ライブラリの比較を通じてユーザーがアクセスしたアプリケーションと Web サイトを正確に識別し、洗練されたトラフィックの分類と制御を可能にします。

    [Netify](https://www.netify.ai/){target="_blank"}と統合されたGL.iNet DPI機能は、効率的に導入できる軽量な組み込みプラグインを採用しています。Netifyのオンライン更新対応シグネチャデータベースにより、信頼性の高い管理と、より正確で効率的なネットワーク制御を実現します。

    詳細については、[DPI エンジン](../../interface_guide/dpi_engine.md) を参照してください。

=== "Data Statistics"

    Data Statistics は、アプリケーションごとのネットワーク使用状況を分類して視覚化するインテリジェントなトラフィック インサイト ダッシュボードを提供し、リアルタイムおよび履歴トラフィックを監視して、ネットワークの認識と制御を向上させるのに役立ちます。

    詳細は[データ統計](../../interface_guide/data_statistics.md)をご覧ください。

=== "Content Filter"

    コンテンツ フィルターは、DPI ベースの分類を活用したスマートなオンライン セーフティを提供し、有害または悪意のある Web サイトを自動的にブロックしてネットワークをクリーンで安全に保ちます。

    詳細については、[コンテンツフィルター](../../interface_guide/content_filter.md)を参照してください。

<br>

=== "QoS"

    QoS (Quality of Service) は、ネットワーク輻輳時に重要なアクティビティ （ビデオ通話、ゲームなど） を優先することで帯域幅の割り当てを最適化し、遅延を削減し、ネットワーク全体のパフォーマンスを向上させます。これはローカル クライアント トラフィックと VPN クライアント トンネル トラフィックに適用されますが、ルータが VPN サーバーとして機能するときに受信するトラフィックには適用されないことに注意してください。

    詳細については、[QoS](../../interface_guide/qos.md)を参照してください。

=== "SQM"

    SQM (Smart Queue Management) は、ルーターのネットワーク トラフィックをインテリジェントに管理して、遅延と「バッファー肥大化」を最小限に抑え、スムーズなゲームと音声通話を保証します。

    詳細は[SQM](../../interface_guide/sqm.md)をご参照ください。

=== "Parental Control"

    ペアレンタル コントロールは、お子様のデバイスの管理と制御を支援するように設計されています。これには、利用時間を制限したり、特定のコンテンツへのアクセスを制限したりすることが含まれます。

    詳細については、[ペアレンタルコントロール](../../interface_guide/parental_control_v4.9.md)を参照してください。

## セキュリティ

=== "Port forwarding"

    ポート転送により、インターネット上のリモート サーバーとデバイスがプライベート ネットワーク上のデバイスにアクセスできるようになります。

    詳細については、[ポートフォワーディング](../../interface_guide/port_forwarding.md)を参照してください。

=== "ACL"

    ACL (Access Control List の略) を使用すると、接続プロトコル、デバイス アドレス、ポートに基づいてネットワーク トラフィックを管理するルールを作成できます。ネットワーク アクセスを許可するかブロックするかを制御します。複数の ACL ルールが競合する場合、システムは優先度の高いルールを適用します。

    詳細は[ACL](../../interface_guide/acl.md)をご参照ください。

=== "Admin Access"

    管理者アクセスを使用すると、さまざまなセキュリティ設定を構成して、ネットワークとルーターを不正なアクセスから保護できます。このページには次のオプションが含まれています。

    * アクセス制御: ローカル ネットワークに接続されているデバイスからルーターのインターフェイスへのアクセスを管理および制限します。
    * リモート アクセス コントロール: インターネット経由で遠隔地からルーターのインターフェイスへのアクセスを構成および制限し、外部の脅威に対するセキュリティを強化します。
    * ルーターで開いているポート: ルーターでどのポートが開いているかを制御し、潜在的な脆弱性や不正アクセスを制限します。

    詳細については、[管理者アクセス](../../interface_guide/admin_access.md)を参照してください。

=== "NAT Mode"

    [NAT モード] ページでは、フル コーン NAT および SIP ALG (Application Layer Gateway) 機能を有効または無効にすることができます。

    詳細については、[NATモード](../../interface_guide/nat_settings.md)を参照してください。

## アプリケーション

=== "Plug-ins"

    プラグインは、既存のコンピュータ プログラムに特定の機能を追加し、その機能のカスタマイズや強化を可能にするソフトウェア コンポーネントです。

    詳細は[プラグイン](../../interface_guide/plugins.md)を参照してください。

=== "Dynamic DNS"

    ダイナミック DNS (DDNS) は、ドメインに関連付けられた IP アドレスをリアルタイムで自動的に検出し、更新します。これは、リモート ネットワークにアクセスするために静的 IP アドレスが必要なユーザーに役立ちます。

    詳細については、[ダイナミックDNS](../../interface_guide/ddns.md)を参照してください。

=== "Network Storage"

    ネットワーク ストレージとは、複数のユーザーとデバイスがネットワーク上でファイルにアクセスして共有できるようにする集中型データ ストレージ ソリューションを指します。

    詳細については、[ネットワークストレージ](../../interface_guide/network_storage.md)を参照してください。

=== "AdGuard Home"

    AdGuard Home は、ネットワーク全体の広告とトラッカーをブロックするソリューションであり、DNS サーバーとして機能し、ホーム ネットワークに接続されているすべてのデバイスにわたって不要なコンテンツをフィルタリングします。

    詳細については、[AdGuard ホーム](../../interface_guide/adguardhome.md) を参照してください。

<br>

=== "Bark"

    [Bark](https://www.bark.us/){target="_blank"}サービスは、お子様のデジタル環境を保護し、包括的なオンライン保護を提供します。通常は有料サブスクリプションが必要ですが、GL.iNetとBarkの提携により、Fortify（GL-MT6000）ではBark Homeプランを無料で利用でき、追加料金なしで高度な監視とアラート機能が提供されます。

    詳しくは[Bark](../../interface_guide/bark.md)をご参照ください。

=== "Tailscale"

    Tailscale は、所有するデバイスやアプリケーションに世界中のどこからでも安全かつ簡単にアクセスできるようにする VPN サービスです。

    Fortify (GL-MT6000) は Tailscale と統合されており、ルーターを Tailscale 仮想ネットワークに参加させることができます。接続すると、WAN および LAN リソースを含めてリモートからアクセスできます。

    詳細は[Tailscale](../../interface_guide/tailscale.md)をご参照ください。

=== "ZeroTier"

    ZeroTier は、ユーザーがインターネット上に安全な仮想ネットワークを作成し、同じローカル ネットワーク上にあるかのようにデバイスを接続できるようにするソフトウェア デファインド ネットワーク ソリューションです。

    詳細については、[ZeroTier](../../interface_guide/zerotier.md)を参照してください。

=== "Tor"

    Tor （The Onion Routerに由来） は、匿名通信を可能にする無料のオープンソース ソフトウェアです。ユーザーがプライバシーを保ってインターネットを探索できるようにします。

    詳細については、[Tor](../../interface_guide/tor.md) を参照してください。

## システム

=== "Overview"

    [概要] ページには、ルーターの現在のステータスとパフォーマンス メトリックの包括的なスナップショットが表示されます。このページでは、以下を表示できます。

    * CPU 平均負荷: ルーターの CPU の平均負荷を監視し、パフォーマンスを評価し、潜在的なボトルネックを特定するのに役立ちます。
    * メモリ使用量: ルーターのメモリの使用量を確認し、リソースの管理に役立てます。
    * LED コントロール: ルーターの LED ライトのオンとオフを切り替えて、デバイスの視覚的なインジケーターをカスタマイズできます。
    * フラッシュ使用量: ルーターのフラッシュ ストレージの使用率を表示し、ファームウェアと構成データ用の十分なスペースがあることを確認します。
    * デバイス情報: 稼働時間、ホスト名、モデル、アーキテクチャ、OpenWrt バージョン、カーネル バージョン、デバイス ID、デバイス MAC、デバイス S/N など、ルーターのシステムに関する詳細情報にアクセスします。
    * 外部ストレージ: USB ドライブや TF カードなど、ルーターに接続されている外部ストレージ デバイスのステータスを確認します。

    これらの機能は重要な洞察と制御を提供し、ルーターの動作を効果的に管理および監視するのに役立ちます。

    詳細は[概要](../../interface_guide/system_overview.md)をご参照ください。

=== "Admin Password"

    [管理者パスワード] ページでは、ルーターの管理インターフェイスのパスワードを設定または変更できます。

    詳細は[管理者パスワード](../../interface_guide/admin_password.md)をご確認ください。

=== "Upgrade"

    [アップグレード] ページは、ルーターのファームウェアを最新バージョンに更新し、パフォーマンス、セキュリティ、および新機能の強化を保証するために使用されます。このページには 2 つのオプションがあります。

    * ファームウェアのオンライン アップグレード: 最新のファームウェア バージョンを自動的に確認してメーカーのサーバーから直接インストールするため、更新プロセスが簡素化されます。
    * ファームウェアのローカル アップグレード: コンピューターからファームウェア ファイルを手動でアップロードしてルーターを更新し、アップグレードのバージョンとタイミングを制御します。

    詳細は[アップグレード](../../interface_guide/upgrade.md)をご参照ください。

=== "Scheduled Tasks"

    [スケジュールされたタスク] ページでは、事前定義されたスケジュールに基づいてさまざまなルーター機能を自動化し、利便性と効率を向上させることができます。このページの主な機能は次のとおりです。

    * LED 表示スケジュール: ルーターの LED ライトを自動的にオンまたはオフにするスケジュールを設定し、特定の時間帯の光害を軽減します。
    * 再起動のスケジュール: 指定した間隔で自動的に再起動するようにルーターを構成し、最適なパフォーマンスと安定性を維持します。
    * 5 GHz / 2.4 GHz Wi-Fi ステータス スケジュール: 5 GHz / 2.4 GHz Wi-Fi 帯域を制御するスケジュールを設定し、ネットワークの可用性と消費電力をより適切に管理できるようにします。

    これらのスケジュール オプションにより、ルーターの動作をより詳細に制御できるようになり、特定のニーズや好みを確実に満たすことができます。

    詳細については、[スケジュールされたタスク](../../interface_guide/scheduled_tasks.md)を参照してください。

<br>

=== "Time Zone"

    [タイム ゾーン] ページでは、ルーターの正しいタイム ゾーンを設定して、すべてのスケジュールされたタスク、ログ、およびシステム イベントに現地時間に従って正確にタイムスタンプが付けられるようにすることができます。この設定は、正確な記録を維持し、時間ベースの構成を適切に実行するために重要です。

    詳しくは[タイムゾーン](../../interface_guide/time_zone.md)をご参照ください。

=== "Reset Firmware"

    [ファームウェアのリセット] ページでは、ルーターの現在のファームウェア バージョンをデフォルト設定にリセットし、すべてのカスタム構成を消去できます。このプロセスにより、ルーターは現在インストールされているファームウェア バージョンのデフォルト設定に復元されます。これは、永続的な問題のトラブルシューティングや、現在のファームウェアのデフォルト構成で新規に開始する場合に役立ちます。

    詳細については、[ファームウェアのリセット](../../interface_guide/reset_firmware.md)を参照してください。

=== "Log"

    [ログ] ページでは、ルーターのアクティビティやイベントを記録するさまざまなログにアクセスでき、トラブルシューティングやパフォーマンスの監視に役立ちます。このページには以下が含まれます:

    * システム ログ: システム レベルのイベントとアクティビティの詳細なログ。
    * カーネル ログ: カーネルの操作とイベントに関連するログ。
    * クラッシュ ログ: システムのクラッシュとエラーの記録。重大な問題の診断に役立ちます。
    * Cloud Log: ルーターに統合された GoodCloud サービスに関連する対話とアクティビティのログ。
    * Nginx ログ: Nginx Web サーバーからのログ (ルーターで使用されている場合)。Web トラフィックとサーバー操作の詳細が記録されます。

    さらに、このページには [ログのエクスポート] ボタンがあり、収集されたすべてのログをテクニカル サポート分析のためにエクスポートできます。この機能は、複雑な問題を診断し、専門家の支援を受ける場合に非常に役立ちます。

    詳細は[ログ](../../interface_guide/log.md)を参照してください。

=== "Advanced Settings"

    [詳細設定] ページでは、OpenWrt LuCI インターフェイスを介して詳細構成オプションにアクセスできるため、経験豊富なユーザーは基本インターフェイス オプションを超えてルーターの設定と機能を微調整できます。これには、詳細なネットワーク構成、ファイアウォール設定、その他の高度なシステムのカスタマイズが含まれます。

    詳細は[詳細設定](../../interface_guide/advanced_settings.md)をご覧ください。
