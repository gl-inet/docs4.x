# Бездротова мережа (прошивка v4.8 та раніші версії) {#wireless-firmware-v48-and-earlier}

Ця сторінка описує прошивку v4.8.x та раніші версії. Якщо на пристрої встановлено іншу версію прошивки, скористайтеся перемикачем нижче, щоб відкрити відповідний посібник.

У меню ліворуч у вебпанелі адміністрування перейдіть до **WIRELESS**.

На сторінці Wireless можна налаштувати окремі мережі Wi-Fi: 2.4 GHz, 5 GHz, 6 GHz і MLO Wi-Fi (доступність залежить від моделі). У кожному діапазоні можна налаштувати основну або гостьову мережу Wi-Fi для гнучкого керування бездротовими з’єднаннями.

**Примітка**: Деякі моделі не підтримують Wi-Fi у діапазоні 5 GHz, зокрема GL-MT300N-V2 (Mango), GL-X300B (Collie) і GL-XE300 (Puli). Деякі моделі взагалі не мають Wi-Fi, наприклад GL-MT5000 (Brume 3) і GL-MT2500/GL-MT2500A (Brume 2).

## MLO Wi-Fi {#mlo-wi-fi}

| Підтримувані моделі            |           |
| :----------------------------- | :-------: |
| Flint 4 (GL-BE14000)           | √         |
| Slate 7 Pro (GL-BE10000)       | √         |
| Beryl 7 (GL-MT3600BE)          | √         |
| Flint 3e (GL-BE6500)           | √         |
| Flint 3 (GL-BE9300)            | √         |
| Slate 7 (GL-BE3600)            | √         |

MLO (Multi-Link Operation, багатоканальна робота) — одна з основних функцій Wi-Fi 7 (802.11be). Вона підвищує продуктивність мережі, значно зменшує затримку та поліпшує стабільність з’єднання, одночасно використовуючи кілька частотних діапазонів, зокрема 2.4 GHz, 5 GHz і 6 GHz.

Відкрийте вкладки нижче, щоб дізнатися про налаштування основної та гостьової мережі MLO Wi-Fi.

=== "MLO Wi-Fi"

    Для основної мережі MLO Wi-Fi можна налаштувати різні параметри: увімкнення та вимкнення Wi-Fi, вибір щонайменше двох радіодіапазонів, увімкнення та вимкнення випадкового BSSID, назву Wi-Fi (SSID), режим безпеки, пароль і видимість SSID.

    ![Основна мережа MLO Wi-Fi](https://static.gl-inet.com/docs/router/en/4/interface_guide/wireless/main_wifi_mlo.png){class="glboxshadow"}

    - Якщо MLO Wi-Fi використовує діапазон 6 GHz, її BSSID синхронізуватиметься під час зміни BSSID Wi-Fi 6GHz.

    - Режим безпеки MLO Wi-Fi за замовчуванням — WPA3-SAE, який підходить для більшості пристроїв із підтримкою MLO.

=== "Гостьова MLO Wi-Fi"

    Для гостьової мережі MLO Wi-Fi доступні спрощені налаштування: увімкнення та вимкнення Wi-Fi, вибір щонайменше двох радіодіапазонів, назва Wi-Fi (SSID), режим безпеки, пароль і видимість SSID.

    ![Гостьова мережа MLO Wi-Fi](https://static.gl-inet.com/docs/router/en/4/interface_guide/wireless/guest_wifi_mlo.png){class="glboxshadow"}

## Загальні налаштування Wi-Fi {#general-wi-fi-settings}

* Наведіть вказівник на значок QR-коду біля SSID Wi-Fi, щоб побачити QR-код мережі. Відскануйте його телефоном або планшетом, щоб швидко підключитися до відповідної мережі Wi-Fi.

    ![QR-код мережі Wi-Fi](https://static.gl-inet.com/docs/router/en/4/interface_guide/wireless/wifi_ssid_qr_code.png){class="glboxshadow"}

* **Randomized BSSID**: Увімкнено за замовчуванням. Перешкоджає відстеженню маршрутизатора за постійним BSSID. Докладніше дивіться в розділі [Randomized BSSID](#randomized-bssid).

* **Bandwidth** і **Channel** не можна змінити, коли маршрутизатор працює як [ретранслятор](internet_repeater.md), оскільки вони відповідають параметрам мережі, що ретранслюється.

* Якщо для **Channel** вибрано **Auto**, маршрутизатор не перемикатиме Wi-Fi на канал DFS автоматично.

* Під час перемикання з каналу без DFS на канал DFS з’явиться таке попередження:

    ![Попередження про перемикання на канал DFS](https://static.gl-inet.com/docs/router/en/4/interface_guide/wireless/switch_to_dfs_caution.png){class="glboxshadow"}

* Якщо для **Bandwidth** задано **160 MHz** (доступно лише на деяких моделях), Wi-Fi завжди використовуватиме канал DFS, навіть якщо для Channel вибрано канал без DFS або Auto.

## Випадковий BSSID {#randomized-bssid}

Randomized BSSID — функція конфіденційності, доступна починаючи з прошивки v4.6 та ввімкнена за замовчуванням. Вона перешкоджає визначенню розташування та відстеженню маршрутизатора за постійним BSSID Wi-Fi — MAC-адресою бездротового інтерфейсу маршрутизатора.

**Чому постійний BSSID створює ризик для конфіденційності**

Мобільні операційні системи, наприклад Android та iOS, використовують спільно зібрані дані Wi-Fi для визначення розташування:

1. Клієнтські пристрої — телефони та ноутбуки — періодично надсилають видимі їм BSSID разом зі своїм розташуванням за GPS на сервер виробника ОС або пристрою.

2. Виробники об’єднують ці дані в глобальну базу відповідності BSSID і розташування.

3. Будь-який пристрій з увімкненим Wi-Fi, навіть без GPS, може звертатися до цієї бази, щоб оцінювати своє розташування за навколишніми BSSID.

![Принцип роботи випадкового BSSID](https://static.gl-inet.com/docs/router/en/4/interface_guide/wireless/randomized-bssid-new.jpg){class="glboxshadow"}

Отже, маршрутизатор із постійним BSSID діє як стаціонарний маяк розташування: його можна віддалено знайти, а його переміщення, наприклад під час подорожей, — відстежувати з часом. Зловмисники також можуть звертатися до таких баз, щоб визначати розташування маршрутизаторів або ідентифікувати їх за інформацією про виробника в BSSID (OUI).

**Як Randomized BSSID захищає вас**

Коли цю функцію ввімкнено, маршрутизатор створює випадковий BSSID та оновлює його після кожного завантаження. Через постійну зміну BSSID його більше не можна пов’язати з фіксованим розташуванням у базах виробників, що розриває зв’язок BSSID із розташуванням, який використовують для відстеження.

| Стан | Поведінка |
| ----------------- | ---------------------- |
| Увімкнено (за замовчуванням) | Після кожного завантаження створюється новий випадковий BSSID |
| Вимкнено | Як BSSID маршрутизатор використовує свою справжню заводську MAC-адресу |

**Примітки**:

1. BSSID змінюється лише після перезавантаження маршрутизатора та залишається незмінним протягом поточного сеансу роботи.
2. Для гостьової мережі Wi-Fi BSSID залишається узгодженим із BSSID основної мережі Wi-Fi в тому самому частотному діапазоні.
3. Якщо діапазони радіомодуля MLO Wi-Fi включають 6 GHz, BSSID MLO Wi-Fi синхронізується з BSSID мережі Wi-Fi 6 GHz.
4. Randomized BSSID блокує відстеження за BSSID маршрутизатора, але не перешкоджає клієнтським пристроям повідомляти власне розташування та не забезпечує повного захисту конфіденційності: SSID, канал і характеристики сигналу залишаються видимими.
