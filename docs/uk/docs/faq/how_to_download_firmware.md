# Як завантажити прошивку для маршрутизатора GL.iNet? {#how-to-download-the-firmware-for-my-glinet-router}

Щоб оновити маршрутизатор або відновити його через U-Boot, завантажте файли прошивки за такими кроками:

1. У [центрі завантаження прошивок GL.iNet](https://dl.gl-inet.com) виберіть рядок пошуку та модель маршрутизатора.
2. Виберіть вкладку вгорі:
    * **Stable:** Офіційний випуск для щоденного використання, рекомендований більшості користувачів.
    * **Beta** (доступно лише для певних моделей): Попередня версія, яка ще перебуває в розробленні.
    * **Snapshot** (доступно лише для певних моделей): Щоденна збірка з найновішими оновленнями.
3. Натисніть кнопку **Download**.
