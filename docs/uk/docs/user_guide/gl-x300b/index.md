## Огляд пристрою {#product-overview}

Collie (GL-X300B) — це промисловий стільниковий шлюз, призначений для роботи за високих температур і в умовах потенційних фізичних небезпек. Існують три версії Collie: для стаціонарного використання у приміщеннях (GL-X300B-RS485 / GL-X300B-BLE) або у транспортних засобах (GL-X300B-GPS). Collie підходить для міжмашинного обміну даними між електричними пристроями в середовищах із високим рівнем електричних завад.

![Інтерфейси gl-x300b](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/hardware_info/gl-x300b_interface.jpg){class="glboxshadow"}

**Чим відрізняються GL-X300B-RS485, GL-X300B-BLE і GL-X300B-GPS?**

![Серія gl-x300b](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/hardware_info/x300b_series.png){class="glboxshadow"}

![Порівняння gl-x300b](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/hardware_info/model_comparison.png){class="glboxshadow"}

- **GL-X300B-RS485** містить мікросхему RS485 з інтерфейсом RS485. Модуль підтримує двонапрямне передавання даних між різними пристроями промислової автоматизації та IoT для збирання даних, керування й моніторингу.

- **GL-X300B-BLE** оснащено трьома зовнішніми всеспрямованими антенами для зв’язку Wi-Fi 2.4GHz, 4G LTE та BLE. Вони приймають сигнали з усіх напрямків і забезпечують гнучкість розміщення пристрою в промисловому середовищі.

- **GL-X300B-GPS** оснащено п’ятьма зовнішніми антенами: двома для Wi-Fi 2.4GHz, двома для 4G LTE та однією GPS-антеною. Виносні антени з кабелями дають змогу розміщувати точки приймання в різних місцях транспортного засобу, зменшуючи зони слабкого приймання під час пересування містами з високою щільністю мереж.

!!! Note

    Версії BLE і GPS доступні за умови мінімального обсягу замовлення.

    Виберіть відповідний антенний роз’єм для своєї версії пристрою. Несумісні роз’єми можуть спричинити несправність антени або неналежні характеристики сигналу. Антенні інтерфейси кожної версії наведено нижче:

    - X300B‑GPS: 5 x роз’ємів SMB типу «штекер»
    - X300B‑RS485: 2 x роз’єми RP‑SMA типу «гніздо», 1 x роз’єм SMA типу «гніздо»
    - X300B‑BLE: 3 x роз’єми RP‑SMA типу «гніздо»
   
    Антена повинна мати відповідний парний роз’єм. Якщо порт пристрою має тип «штекер», використовуйте антену з роз’ємом «гніздо»; якщо порт має тип «гніздо», використовуйте антену з роз’ємом «штекер».

## Установлення антен {#antenna-installation}

!!! note "GL-X300B-RS485"

    **Collie (GL-X300B-RS485)** постачається з такими антенами:

    * 1 x Зовнішня антена 4G
    * 2 x Зовнішні антени Wi-Fi (2.4GHz)

    Виконайте наведені нижче дії, щоб установити антени.

    1. Приєднайте антени в будь-якому порядку.

        - Приєднайте дві однакові антени Wi-Fi до портів **2.4G**.
        - Приєднайте одну антену 4G до порту **4G**.

        ![Антени x300b rs485](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/antenna_installation/x300b-rs485-back.png){class="gl-80-desktop glboxshadow"}

    2. Спрямуйте антени вгору для оптимальної роботи.

!!! note "GL-X300B-BLE"

    **Collie (GL-X300B-BLE)** постачається з такими антенами:

    * 1 x Зовнішня антена 4G
    * 1 x Зовнішня антена Wi-Fi (2.4GHz)
    * 1 x Зовнішня антена BLE

    Виконайте наведені нижче дії, щоб установити антени.

    1. Приєднайте антени в будь-якому порядку.

        - Приєднайте одну антену Wi-Fi до порту **2.4G**.
        - Приєднайте одну антену 4G до порту **4G**.
        - Приєднайте одну антену BLE до порту **BLE**.

        ![Антени x300b ble](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/antenna_installation/x300b-ble-back.png){class="gl-80-desktop glboxshadow"}

    2. Спрямуйте антени вгору для оптимальної роботи.

!!! note "GL-X300B-GPS"

    **Collie (GL-X300B-GPS)** постачається з такими антенами:

    * 2 x Зовнішні антени 4G
    * 2 x Зовнішні антени Wi-Fi (2.4GHz)
    * 1 x Зовнішня антена GPS

    Виконайте наведені нижче дії, щоб установити антени.

    1. Приєднайте антени в будь-якому порядку.

        - Приєднайте дві однакові антени Wi-Fi до портів **2.4G**.
        - Приєднайте дві однакові антени 4G до портів **4G**.
        - Приєднайте одну антену GPS до порту **GPS**.

        ![Антени x300b gps](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/antenna_installation/x300b-gps-back.png){class="gl-80-desktop glboxshadow"}

    2. Правильно розмістіть антени й не допускайте заплутування кабелів для оптимальної роботи.

## Інтернет {#internet}

Увійдіть до вебпанелі адміністрування маршрутизатора та виберіть **INTERNET** у меню ліворуч.

На цій сторінці можна вибрати тип інтернет-з’єднання, наприклад Ethernet, Repeater, Tethering або Cellular, залежно від моделі.

Collie (GL-X300B) підтримує три типи з’єднання: Ethernet, Repeater і Cellular.

### Ethernet {#ethernet}

Підключіть маршрутизатор до працюючого модема або мережевого пристрою за допомогою кабелю Ethernet для доступу до інтернету. Цей спосіб зазвичай забезпечує найшвидше та найнадійніше інтернет-з’єднання.

[Підключення до інтернету через кабель Ethernet](../../interface_guide/internet_ethernet.md)

![З’єднання Ethernet](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/internet/x300b_ethernet.png){class="glboxshadow"}

### Repeater {#repeater}

Налаштуйте маршрутизатор як повторювач для розширення покриття наявної мережі Wi-Fi. У цьому режимі він приймає та повторно передає бездротові сигнали у своєму радіусі дії, збільшуючи зону покриття. Цей спосіб корисний, коли один маршрутизатор не охоплює всю потрібну територію.

[Підключення до інтернету через наявну мережу Wi-Fi](../../interface_guide/internet_repeater.md)

![З’єднання Repeater](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/internet/x300b_repeater.png){class="glboxshadow"}

### Cellular {#cellular}
 
Вставте SIM-картку в слот маршрутизатора для підключення до інтернету. Так можна надати всім підключеним пристроям доступ до інтернету через одну SIM-картку.

[Підключення до інтернету через стільникову мережу](../../interface_guide/internet_cellular.md)

![Стільникове з’єднання](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-x300b/internet/x300b_cellular.png){class="glboxshadow"}

### Multi-WAN {#multi-wan}

Multi-WAN — це мережева функція, яка дає змогу одночасно налаштувати кілька інтернет-з’єднань, наприклад Ethernet, Repeater і Cellular. Якщо з’єднання з найвищим пріоритетом перестане працювати, маршрутизатор автоматично перемкнеться на інше. Це також називається аварійним перемиканням (Failover) і забезпечує безперервний доступ до інтернету.

Перейдіть до [Multi-WAN](../../interface_guide/multi-wan.md), щоб установити пріоритет кожного інтернет-з’єднання.

Також можна змінити режим Multi-WAN із Failover на Load Balance. У цьому режимі кілька мережевих інтерфейсів використовуються одночасно для збільшення сумарної пропускної здатності маршрутизатора.

## VPN {#vpn}

На маршрутизаторах GL.iNet попередньо встановлено OpenVPN і WireGuard® із підтримкою 30+ служб VPN. Коли клієнт VPN увімкнено, маршрутизатор може шифрувати трафік пристроїв у мережі, зокрема пристроїв, на яких не можна запускати застосунки VPN, відповідно до налаштувань політики VPN. Наші маршрутизатори також можуть працювати як сервери VPN: трафік клієнтських пристроїв у віддалених місцях спочатку спрямовується через VPN-тунель на сервер VPN, а потім — до публічного інтернету.
