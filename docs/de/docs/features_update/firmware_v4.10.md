# Firmware v4.10

Diese Version führt Mesh, das GL.iNet-Konto und native VLAN-Unterstützung ein. Außerdem verbessert sie die GoodCloud-Kontoverwaltung und bietet eine benutzerfreundlichere Oberfläche.

Die aktuelle Firmware erhalten Sie im [Firmware Download Center](https://dl.gl-inet.com/){target="_blank"}.

## Mesh

[Mesh](../interface_guide/mesh.md) basiert auf dem Wi-Fi EasyMesh™-Standard, erweitert die WLAN-Abdeckung im gesamten Zuhause und ermöglicht nahtloses Roaming. Wenn Sie mehrere GL.iNet-Router verwenden, legen Sie einen als Hauptrouter und die übrigen als Mesh-Knoten fest, um sich im gesamten Zuhause ohne Unterbrechung zwischen den WLAN-Zugangspunkten zu bewegen.

![mesh](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/mesh.png){class="glboxshadow"}

## Cloud-Dienste

Cloud-Dienste sind eine Suite cloudbasierter, im Router integrierter Funktionen, die zentral über Ihr GL.iNet-Konto verwaltet werden. Sie ermöglichen Echtzeit-Statusüberwachung, Remote-Geräteverwaltung, die gebündelte Bereitstellung von Firmware und sicheren Fernzugriff. In Firmware v4.10 bietet dieses Modul eine verbesserte einheitliche Cloud-Verwaltung.

Das Modul umfasst GL.iNet Account, GoodCloud und GoodPAS.

### GL.iNet Account

Das [GL.iNet-Konto](../interface_guide/glinet_account.md) bietet eine zentrale Profilseite, auf der Sie Ihre Geräte verbinden oder verwalten und auf Cloud-Dienste zugreifen können. Mit einem einzigen GL.iNet-Konto können Sie GoodCloud, GoodPAS und die GL.iNet App nahtlos nutzen und Ihr Netzwerk komfortabler verwalten.

![gl.inet account](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/account.png){class="glboxshadow"}

### GoodCloud

[GoodCloud](../interface_guide/cloud.md) ist eine Cloud-Plattform für die Remote-Bereitstellung und -Verwaltung von GL.iNet-Routern. Sie fasst Geräte an mehreren Standorten zusammen und unterstützt die gebündelte Konfiguration sowie Firmware-Upgrades. Darüber hinaus ermöglicht sie den Fernzugriff auf das webbasierte Admin-Panel und per SSH auf das Geräteterminal.

In Firmware v4.10 vereinfacht GoodCloud die Kontobindung und ermöglicht es, Cloud-Kontodaten beim Zurücksetzen auf die Werkseinstellungen zu löschen.

![goodcloud](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/goodcloud.png){class="glboxshadow"}

### GoodPAS

[GoodPAS](../interface_guide/goodpas.md) ist eine erweiterte Fernzugriffslösung, die in das GL.iNet Router SDK integriert ist. Sie basiert auf dem AmneziaWG-Protokoll und ermöglicht durch einfaches Koppeln von Geräten einen sicheren Zugriff auf das Heimnetzwerk, ohne dass eine Kontoregistrierung oder Benutzeranmeldung erforderlich ist.

![goodpas](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/goodpas.png){class="glboxshadow"}

## Subnetz

Die Seite [Subnetz](../interface_guide/subnet.md) fasst die Konfiguration von LAN, Gastnetzwerk, IoT-Netzwerk und benutzerdefinierten VLAN-Netzwerken in einer einheitlichen Ansicht zusammen. Über diese zentrale Oberfläche können Sie alle subnetzbezogenen Einstellungen verwalten sowie mehrere Subnetze erstellen und verwalten, um verschiedene Gerätetypen oder Datenverkehr voneinander zu isolieren.

Die folgende Abbildung zeigt die Subnetzseite auf dem Flint 3 (GL-BE9300).

![subnet](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/subnet.png){class="glboxshadow"}

## Ethernet-Port

Die Seite [Ethernet-Port](../interface_guide/ethernet_port_v4.10.md) zeigt alle Ethernet-Schnittstellen des Routers an. Sie können den Verbindungsstatus prüfen, Ports zwischen WAN- und LAN-Rollen umschalten und Details wie MAC-Adresse, ausgehandelte Geschwindigkeit und Verbindungsstatus anzeigen. Physische Schnittstellen können außerdem den von Ihnen erstellten Subnetzen zugewiesen werden.

Die folgende Abbildung zeigt die Seite Ethernet Port auf dem Flint 3 (GL-BE9300).

![ethernet port](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/ehternet_port.png){class="glboxshadow"}
