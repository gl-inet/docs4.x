# Firmware voor mijn GL.iNet-router downloaden {#how-to-download-the-firmware-for-my-glinet-router}

Volg de onderstaande stappen om firmwarebestanden te downloaden voor het bijwerken van je router of herstel via U-Boot:

1. Selecteer in het [GL.iNet firmware download center](https://dl.gl-inet.com) de zoekbalk en je routermodel.
2. Select a tab at the top:
    * **Stable:** de officiële versie voor dagelijks gebruik, aanbevolen voor de meeste gebruikers.
    * **Beta** (alleen beschikbaar voor bepaalde routermodellen): een voorlopige versie die nog in ontwikkeling is.
    * **Snapshot** (alleen beschikbaar voor bepaalde routermodellen): de dagelijkse build met de nieuwste updates.
3. Click the **Download** button.
