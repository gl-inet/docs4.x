# Скидання прошивки {#reset-firmware}

У меню ліворуч у вебпанелі адміністрування перейдіть до **SYSTEM** -> **Reset Firmware**.

Якщо маршрутизатор працює неправильно, спробуйте усунути проблему скиданням прошивки. Натисніть кнопку **Delete All and Reboot**, щоб скинути прошивку.

**Примітка:** Усі поточні налаштування, застосунки та дані буде втрачено. Процес триватиме приблизно 2 хвилини. НЕ вимикайте живлення маршрутизатора під час цього процесу.

![Скидання прошивки](https://static.gl-inet.com/docs/router/en/4/interface_guide/reset_firmware/reset_firmware_4.8.png){class="glboxshadow"}

Якщо вебпанель адміністрування недоступна, перегляньте відео нижче, щоб виконати скидання за допомогою кнопки скидання.
