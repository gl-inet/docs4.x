# Konfigurera ett Wi-Fi-gästnätverk på GL.iNet-routrar {#how-to-set-up-a-guest-wi-fi-network-on-glinet-routers}

Den här guiden visar hur du konfigurerar ett Wi-Fi-gästnätverk på GL.iNet-routrar.

Ett Wi-Fi-gästnätverk är ett separat nätverk på routern för enheter som du vill isolera från dina primära enheter. Det kan vara gästers enheter och smarta hem-enheter. Genom att skapa ett gästnätverk kan du förhindra obehörig åtkomst till och potentiella angrepp mot det primära nätverket och därmed förbättra nätverkssäkerheten.

Du kan konfigurera ett Wi-Fi-gästnätverk på GL.iNet-routern på två sätt: via [routerns administrationspanel](#set-up-a-guest-network-via-the-admin-panel) eller [GL.iNet-mobilappen](#set-up-a-guest-network-via-the-glinet-mobile-app).

## Konfigurera ett gästnätverk via administrationspanelen {#set-up-a-guest-network-via-the-admin-panel}

### 1. Aktivera Wi-Fi-gästnätverket {#1-enable-the-guest-wi-fi-network}

1. Ange `192.168.8.1` i en webbläsare.
2. Ange lösenordet och klicka sedan på **Login**.
3. Klicka på **Wireless** i det vänstra sidofältet.
![click wireless](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-wireless.jpeg){class="glboxshadow"}
4. Klicka på fliken **Guest Wi-Fi** i avsnittet för 5GHz- eller 2.4GHz Wi-Fi-nätverket.
![click guest](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-guest-wifi.jpeg){class="glboxshadow"}
5. Aktivera reglaget bredvid **Enable Wi-Fi**.

### 2. Ange ett nytt lösenord för Wi-Fi-gästnätverket {#2-set-a-new-guest-wi-fi-network-password}

Vi rekommenderar att du anger ett nytt lösenord för Wi-Fi-gästnätverket för att skydda säkerheten. Följ dessa steg:

1. Klicka på **Modify**.
![click modify](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-modify.jpeg){class="glboxshadow"}
2. Ange ett nytt lösenord bredvid **Wi-Fi Password**. (Du kan även ange ett nytt nätverksnamn bredvid **Wi-Fi Name**.)
3. Klicka sedan på **Apply**.

Wi-Fi-gästnätverket är nu konfigurerat. För att ansluta enheterna till nätverket letar du reda på gästnätverkets namn i listan över tillgängliga nätverk och anger lösenordet.

## Konfigurera ett gästnätverk via GL.iNet-mobilappen {#set-up-a-guest-network-via-the-glinet-mobile-app}

**Obs!** Innan du börjar installerar och konfigurerar du GL.iNet-mobilappen på enheten.

### 1. Aktivera Wi-Fi-gästnätverket {#1-enable-the-guest-wi-fi-network_1}

1. Tryck på fliken **Network** > **Wireless** på appens huvudskärm.
2. Leta reda på **Guest Network**.
3. Aktivera reglaget för nätverket där du vill konfigurera ett Wi-Fi-gästnätverk.
![toggle the switch](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/toggle-on-guest-network.jpeg){class="glboxshadow"}

### 2. Ange ett nytt lösenord för Wi-Fi-gästnätverket {#2-set-a-new-guest-wi-fi-network-password_1}

Vi rekommenderar att du anger ett nytt lösenord för Wi-Fi-gästnätverket för att skydda säkerheten. Följ dessa steg:

1. Tryck på alternativet **SSID** för nätverket där du konfigurerade ett Wi-Fi-gästnätverk.
2. Ange ett nytt lösenord bredvid **Password**. (Du kan även ange ett nytt nätverksnamn i fältet SSID.)
![enter a new password](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/tap-password.jpeg){class="glboxshadow"}
3. Tryck på **Done**.

Wi-Fi-gästnätverket är nu konfigurerat. För att ansluta enheterna till nätverket letar du reda på gästnätverkets namn i listan över tillgängliga nätverk och anger lösenordet.
