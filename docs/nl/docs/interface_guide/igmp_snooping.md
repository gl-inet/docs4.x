# IGMP Snooping {#igmp-snooping}

Ga links in het webbeheerpaneel naar **NETWORK** -> **IGMP Snooping**.

Je kunt IGMP snooping inschakelen om de multicastfunctie op de router te gebruiken.

IGMP Snooping luistert naar IGMP-protocolpakketten, haalt de bijbehorende informatie eruit en maakt en onderhoudt de Layer 2-doorstuurtabel voor multicast. Vervolgens worden de gegevens van de multicastgroep doorgestuurd naar de host die zich bij de groep heeft aangesloten. Andere hosts ontvangen deze gegevens niet.

**Opmerking**: IGMPv3 is compatibel met v1 en v2. Gebruik standaard v3 en schakel over als je een probleem ondervindt.
