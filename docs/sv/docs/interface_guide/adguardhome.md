# AdGuard Home {#adguard-home}

AdGuard Home är programvara som blockerar annonser och spårning i hela nätverket. När den har konfigurerats omfattas alla enheter i hemnätverket utan ytterligare klientprogramvara.

## Setup {#setup}

Logga in på routerns webbadministrationspanel och öppna **APPLICATIONS** -> **AdGuard Home**.

Aktivera AdGuard Home med reglaget och klicka på **Apply**.

![adguard home apply](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/apply.png){class="glboxshadow"}

- **AdGuard Home Handle Client Requests**: När alternativet är aktiverat behandlar AdGuard Home DNS-frågor från klientenheter direkt. Domänbaserade VPN-principer och regler för föräldrakontroll får då ingen effekt.

När funktionen är aktiverad visar sidan statistik som DNS-frågor och blockerade domäner via API:t från AdGuard Home.

![adguard home web panel](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/adguardhome_web_panel.png){class="glboxshadow"}

Klicka på **Settings Page** högst upp på sidan.

![adguard home started](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/settings_page.png){class="glboxshadow"}

Du omdirigeras till den officiella inställningssidan för AdGuard Home där du kan konfigurera avancerade filterregler.

![adguard home settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/adguardhome_dashboard.png){class="glboxshadow"}

Besök [AdGuard Home Support Center](https://adguard.com/en/support.html){target="_blank"} om du har frågor eller behöver mer hjälp.
