# Admin Password {#admin-password}

**Opmerking**: deze pagina is vanaf firmware v4.3 samengevoegd met [Security](security.md) en is sinds firmware v4.9 weer een afzonderlijke pagina.

Op deze pagina kun je het wachtwoord voor de beheerinterface van de router instellen of wijzigen.

---

Ga links in het webbeheerpaneel naar **SYSTEM** > **Admin Password**.

![admin password](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_password/admin_password.png){class="glboxshadow"}

Wijzig het aanmeldwachtwoord voor het webbeheerpaneel van je router. Je huidige wachtwoord is vereist om wijzigingen aan te brengen.

Het beheerderswachtwoord moet aan de volgende eisen voldoen:

- Minimaal 10 en maximaal 63 tekens.
- De volgende tekens zijn toegestaan: letters (hoofdlettergevoelig), cijfers en symbolen `` ! @ # $ % ^ & * ( ) _ + - = , . > < | ? / \ [ ] { } : ; " ' ` ~ ``.
- Er zijn ten minste twee van de volgende typen vereist: hoofdletters, kleine letters, cijfers en symbolen.
