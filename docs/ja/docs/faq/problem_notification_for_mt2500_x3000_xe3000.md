# GL-MT2500/GL-X3000/GL-XE3000 に関する問題のお知らせ {#problem-notification-for-gl-mt2500gl-x3000gl-xe3000}

**最終更新日：2026年11月11日**

この既知の問題は、一部の製造ロットのデバイスにのみ影響します。2025年7月1日以降に注文したデバイスは新しいロットである可能性が高く、U-Boot ブートローダーを更新する必要はありません。

お使いのデバイスの製造ロットが不明な場合は、変更を加える前に以下の情報を [support@gl-inet.com](mailto:support@gl-inet.com) にメールでお送りください。

- ルーターのモデルとファームウェアバージョン
- デバイスの MAC アドレス
- 問題の詳細（発生時に行っていた操作を含む）、表示されたエラーメッセージ、すでに試した対処手順

製造ロットを確認し、状況に応じた対処方法をご案内します。

以下の当初のお知らせは参考情報として掲載しています。更新手順は対象ロットにのみ適用されます。お使いのデバイスが対象かどうか不明な場合は、変更を加える前に上記の方法でサポートにご連絡ください。

**公開日：2025年3月26日**

お客様各位

このお知らせは、GL-MT2500/GL-X3000/GL-XE3000デバイスにおける起動障害とU-Boot経由でのファームウェアリカバリーの問題に対処するためのものです。この問題は、一部のパラメーターが正しく定義されていなかったソフトウェアの不具合が原因で、ルーターが正常に動作していませんでした。その結果、この問題によりルーターの寿命がある程度短くなる可能性があると判断いたしました。心よりお詫び申し上げます。

この問題を完全に解決するために、GL-MT2500、GL-X3000、GL-XE3000のすべてのユーザーに、U-Bootブートローダーアップグレードとファームウェアアップグレードの両方を実行することを強くおすすめします。どちらのアップグレード手順も必須であり、省略しないでください。

デバイスがすでに最新ファームウェアにアップグレードされている場合でも、潜在的な問題を防ぐためにU-Bootブートローダーアップグレードは必須です。U-Bootブートローダーアップグレードを完了した後、最新ファームウェアがすでにインストールされている場合は、ファームウェアの再インストールをスキップできます。

アップグレードにはChromeまたはMicrosoft Edgeを使用してください。Mozilla/Firefoxは**使用しないでください**。

## GL-MT2500 {#gl-mt2500}

1. U-Boot ブートローダーを更新します。

    [uboot-mt2500-20250224.bin](https://github.com/gl-inet/mt798x-boot/blob/main/bin/uboot-mt2500-20250224-md5-74286e770cfb041b611d80d4adaef189.bin){target="_blank"}をダウンロードし、[U-Boot ブートローダーを更新します](upgrade_uboot_version.md)。

2. ファームウェアを更新します。

    [ルーターの最新ファームウェア](https://dl.gl-inet.com/router/mt2500/stable){target="_blank"}をダウンロードし、[ルーターのファームウェアを更新します](../tutorials/how_to_upgrade_downgrade_router.md)。
