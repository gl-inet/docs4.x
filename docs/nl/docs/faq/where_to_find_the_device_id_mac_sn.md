# Waar vind ik Device ID, MAC-adres en serienummer? {#where-to-find-the-device-id-mac-address-and-serial-number}

## Method 1 {#method-1}

Je vindt deze gegevens aan de onderkant van je router.

Bij nieuwere modellen lijkt het etiket aan de onderkant op de onderstaande afbeelding en bevat het de basisgegevens van het apparaat. In dit voorbeeld is het MAC-adres **E4:95:6E:40:DB:A1**, Device ID **hh0dba1** en Serial Number **7c0be4bb45d96057**.

![label of gl-x750](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/back_label_new.png){class="glboxshadow"}

Bij oudere modellen staat Device ID niet op het etiket, maar wel DDNS. De eerste 7 tekens van DDNS vormen Device ID. In dit voorbeeld is het MAC-adres **E4:95:6E:40:DB:A1**, Device ID **hh0dba1** en Serial Number **7c0be4bb45d96057**.

![label of gl-ar150](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/back_label_old.png){class="glboxshadow"}

## Method 2 {#method-2}

Meld je aan bij het webbeheerpaneel en ga naar SYSTEM -> Overview om de apparaatgegevens te bekijken.

![device overview](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/overview_device_info.png){class="glboxshadow"}
