# Прошивка v4.11 {#firmware-v411}

У цій версії поліпшено відстеження якості мережі та оцінювання безпеки, щоб допомогти визначати проблеми з’єднання й потенційні ризики. Також удосконалено DNS, QoS, SQM і статистику даних для гнучкішого керування мережею та контролю трафіку.

Завантажте найновішу прошивку з [центру завантаження прошивок](https://dl.gl-inet.com/){target="_blank"}.

## Якість мережі {#network-quality}

[Network Quality](../interface_guide/network_quality.md) — це нова функція відстеження інтернет-з’єднання в реальному часі. Вона оцінює швидкість реагування, затримку та роботу DNS, а також виявляє розриви з’єднання й втрати пакетів. Це допомагає визначати нестабільність мережі та проблеми підключення, які можуть залишатися непомітними під час самого лише тестування пропускної здатності.

![Якість мережі](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/network_quality.png){class="glboxshadow"}

## Перевірка безпеки {#security-scan}

[Security Scan](../interface_guide/security_scan.md) — це нова функція, яка оцінює налаштування безпеки маршрутизатора та надає оцінку безпеки, попередження про ризики й рекомендації з оптимізації. Вона перевіряє, зокрема, безпеку Wi-Fi, WAN ping, віддалений SSH, перенаправлення портів і захист вмісту DPI, допомагаючи визначати та усувати потенційні ризики. Сканування починається автоматично після відкриття сторінки. Натисніть значок оцінки, щоб скинути результати та повторити сканування.

![Перевірка безпеки](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/security_scan.png){class="glboxshadow"}

## DNS {#dns}

У цій версії налаштування [DNS](../interface_guide/dns_v4.11.md) удосконалено: WAN DNS, VPN DNS і Manual DNS об’єднано на одній сторінці. Можна переглянути стан DNS для кожного типу з’єднання, налаштувати власні DNS-сервери та вибрати, чи застосовувати ручні налаштування DNS до VPN-тунелів або самого маршрутизатора.

![DNS](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/dns.png){class="glboxshadow"}

## QoS {#qos}

[QoS](../interface_guide/qos.md) (Quality of Service) надає параметр **Run Speedtest** для вимірювання пропускної здатності WAN: швидкостей завантаження та передавання даних з автоматичним заповненням відповідних полів. До політики Application Priority у цій версії додано два варіанти: **Device Priority** і **Advanced QoS**.

![QoS](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/qos.png){class="glboxshadow" width=600}

- **Device Priority**: Вибрані локальні клієнти отримують вищий мережевий пріоритет під час перевантаження WAN.

- **Application Priority**: Установіть власні пріоритети для різних застосунків; маршрутизатор розподілятиме пропускну здатність відповідно до них.

- **Advanced QoS**: Створюйте розширені правила QoS для трафіку з високим пріоритетом.

## SQM {#sqm}

[SQM](../interface_guide/sqm.md) (Smart Queue Management) надає параметр **Run Speedtest** для вимірювання пропускної здатності WAN: швидкостей завантаження та передавання даних з автоматичним заповненням відповідних полів. Доступні дві дисципліни обслуговування черг: **cake** і **fq_codel**.

![SQM](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/sqm.png){class="glboxshadow" width=600}

- **cake**: Інтелектуальне автоматичне формування трафіку з найкращим загальним контролем затримки (рекомендовано).

    Для цієї дисципліни черг нова функція **Cake Autorate** динамічно змінює налаштовану пропускну здатність на основі RTT пробних запитів. Вона використовує легкі запити ping замість активних тестів швидкості та рекомендована для WAN-з’єднань із мінливою пропускною здатністю.

    ![SQM Cake Autorate](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/sqm_cake_autorate.png){class="glboxshadow" width=600}

- **fq_codel**: Просте й ефективне справедливе обслуговування черг із базовим зменшенням затримки.

## Статистика даних {#data-statistics}

[Data Statistics](../interface_guide/data_statistics.md) тепер підтримує фільтрування трафіку за клієнтом і нові способи відображення, зокрема стовпчикові та кругові діаграми. Під час перегляду App Traffic Statistics можна вибрати конкретного клієнта та перемикати види діаграм для зрозумілішого аналізу використання трафіку.

![Статистика даних](https://static.gl-inet.com/docs/router/en/4/features_update/4.11/data_statistics.png){class="glboxshadow"}
