# Sicherheitsprüfung

**Hinweis**: Diese Funktion wurde mit Firmware v4.11 eingeführt.

---

Navigieren Sie im linken Menü des webbasierten Admin-Panels zu **SECURITY** -> **Security Scan**.

Security Scan führt eine Sicherheitsprüfung Ihres Routers durch. Dabei werden die Sicherheitseinstellungen des Routers bewertet und neben Risikowarnungen und Optimierungsvorschlägen eine Sicherheitsbewertung erstellt. Anhand der Prüfergebnisse können Sie die Konfiguration anpassen, um die Sicherheit des Routers zu erhöhen.

Beim Öffnen dieser Seite wird automatisch eine Sicherheitsprüfung gestartet. Sie umfasst mehrere Sicherheitspunkte wie WLAN-Sicherheit, WAN Ping, Remote SSH, Port Forwarding und DPI Content Protection. Sie können außerdem auf das Bewertungssymbol klicken, um die Prüfung zurückzusetzen und erneut auszuführen. Nach Abschluss der Prüfung werden die wichtigsten Kennzahlen angezeigt.

![Security Scan](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/security_scan.png){class="glboxshadow"}

- **Score**: Allgemeine Sicherheitsbewertung Ihrer Routerkonfiguration.

- **Risks**: Kritische Sicherheitsprobleme, die behoben werden müssen.

- **Suggestions**: Empfohlene bewährte Maßnahmen zur Verbesserung der Sicherheit; keine zwingend erforderlichen Korrekturen.

- **Safe**: Elemente, welche die Sicherheitsprüfung bestanden haben.

Über die beiden Registerkarten unten können Sie die detaillierten Prüfergebnisse anzeigen.

- **Risk & Suggestion**

    Klicken Sie auf **Risk & Suggestion**, um Risiken und Optimierungsvorschläge anzuzeigen.

    ![Risk & Suggestion](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/risk_suggestion.png){class="glboxshadow"}

    Um die Sicherheit des Routers zu verbessern, können Sie neben jedem Element auf **Go to Settings** klicken. Dadurch gelangen Sie direkt zur entsprechenden Konfigurationsseite, auf der Sie die Einstellungen anpassen können.

- **Safe**

    Klicken Sie auf **Safe**, um alle Elemente anzuzeigen, welche die Sicherheitsprüfung bestanden haben.

    ![safe](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/safe.png){class="glboxshadow"}
