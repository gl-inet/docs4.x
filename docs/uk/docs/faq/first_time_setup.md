# Початкове налаштування {#first-time-setup}

Початкове налаштування маршрутизаторів GL.iNet загалом подібне. Більшість моделей мають модуль Wi-Fi, але деякі — ні.

Тому нижче наведено окремі інструкції для моделей із Wi-Fi та без нього.

* [Моделі з Wi-Fi](#for-models-that-have-wi-fi)
* [Моделі без Wi-Fi](#for-models-that-dont-have-wi-fi)

## Моделі з Wi-Fi {#for-models-that-have-wi-fi}

У цьому прикладі використано GL-MT3000 (Beryl AX).

Підготуйте такі складові комплекту:

- Маршрутизатор GL-MT3000 (Beryl AX)
- Адаптер живлення
- Кабель Ethernet

Перегляньте це відео або виконайте наведені нижче дії.

<iframe width="560" height="315" src="https://www.youtube.com/embed/WW8wGk68lEU" title="Відеопрогравач YouTube" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

1. **Увімкніть живлення**

    Підключіть один кінець адаптера живлення до маршрутизатора, а інший — до розетки. Маршрутизатор увімкнеться автоматично.

    Деякі моделі, наприклад Slate AX, мають слот TF. Якщо потрібно використати карту TF, вставте її перед увімкненням маршрутизатора. Гаряча заміна карт TF не підтримується.

2. **Підключіться до маршрутизатора**

    Підключіть пристрій, наприклад смартфон, ноутбук або комп’ютер, до маршрутизатора через Ethernet або Wi-Fi.

    * Ethernet: підключіть пристрій кабелем Ethernet до порту LAN маршрутизатора.

    * Wi-Fi: знайдіть SSID і ключ Wi-Fi на нижній етикетці маршрутизатора. Виберіть його SSID на пристрої та введіть ключ Wi-Fi.

        !!! tip

            1. QR-код на нижній етикетці містить стандартні відомості Wi-Fi. Відскануйте його сканером QR-кодів для швидкого підключення.
            2. На деяких старих моделях, якщо ключа Wi-Fi немає на етикетці, спробуйте «goodlife».

    Одразу після підключення до Wi-Fi інтернет може бути недоступний. Спочатку налаштуйте мережу за наступним кроком.

3. **Увійдіть у вебпанель адміністрування**

    Відкрийте браузер (для кращої сумісності рекомендовано Chrome, Edge або Safari) і перейдіть на [http://192.168.8.1](http://192.168.8.1). Відкриється сторінка входу GL.iNet. Якщо вебпанель недоступна, див. [усунення несправностей](cannot_access_web_admin_panel.md).

    Задайте пароль адміністратора та натисніть **Next**.

    ![Пароль адміністратора mt3000](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_admin_password.png){class="glboxshadow"}

    Налаштуйте Wi-Fi. Якщо змінено відомості Wi-Fi, підключіться знову з новими параметрами та натисніть **Next**.

    ![Налаштування Wi-Fi mt3000](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_set_up_wifi.png){class="glboxshadow"}

    Дочекайтеся завершення ініціалізації маршрутизатора.

    ![Ініціалізація mt3000](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_initializing.png){class="glboxshadow"}

    Після цього відкриється вебпанель адміністрування маршрутизатора.

    ![Вебпанель адміністрування mt3000](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_admin_panel.png){class="glboxshadow"}

4. **Підключіться до інтернету**

    * [Підключення до інтернету кабелем Ethernet](../interface_guide/internet_ethernet.md)
    * [Підключення до інтернету через наявну мережу Wi-Fi](../interface_guide/internet_repeater.md)
    * [Спільний доступ до інтернету через USB](../interface_guide/internet_tethering.md)
    * [Підключення до інтернету через USB-модем](../interface_guide/internet_cellular.md)
