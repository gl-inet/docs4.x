# Advanced Settings {#advanced-settings}

Ga links in het webbeheerpaneel naar **SYSTEM** -> **Advanced Settings**.

Je kunt geavanceerde instellingen wijzigen met LuCI, de standaardwebinterface van OpenWrt.

![advanced settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/go_to_luci.png){class="glboxshadow"}

LuCI is een open en onafhankelijk project dat door OpenWrt wordt onderhouden en wordt geleverd in de huidige staat. GL.iNet is niet verantwoordelijk voor het onderhoud van LuCI.

Klik op de knop **Go To LuCI**. Je wordt doorgestuurd naar de aanmeldpagina van LuCI.

![luci login](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/luci_login.jpg){class="glboxshadow"}

Voer het aanmeldwachtwoord in. Dit is hetzelfde wachtwoord als voor het webbeheerpaneel.

Je wordt aangemeld bij LuCI. Hieronder staat een voorbeeld van de LuCI-pagina voor GL-AX1800 (Flint).

![luci logged in](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/luci_logged_in.jpg){class="glboxshadow"}
