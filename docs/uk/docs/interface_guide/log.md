# Журнал {#log}

У меню ліворуч у вебпанелі адміністрування перейдіть до **SYSTEM** -> **Log**.

На сторінці Log можна переглядати журнали System, Kernel, Crash, Cloud і Nginx для аналізу та усунення несправностей.

Деякі моделі зі стільниковим з’єднанням і підтримкою eSIM також мають журнал eSIM.

Нижче наведено приклад для GL-X3000.

![Сторінка журналів](https://static.gl-inet.com/docs/router/en/4/interface_guide/log/log.png){class="glboxshadow"}

Починаючи з прошивки v4.8, на сторінці System Log доступна **фільтрація**. Для швидкого пошуку записів виберіть рівень або модуль чи введіть ключові слова.

Натисніть **Refresh**, щоб отримати найновіші записи журналу.

Натисніть **Export Log**, щоб експортувати журнали System, Kernel, Crash і Cloud. Коли ви звертаєтеся до GL.iNet, надішліть експортований файл журналу технічній підтримці, щоб прискорити аналіз проблеми.
