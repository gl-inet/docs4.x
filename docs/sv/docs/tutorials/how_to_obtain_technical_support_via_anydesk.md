# Få teknisk support via AnyDesk {#how-to-obtain-technical-support-via-anydesk}

**Med fjärrhjälp kan våra tekniker kontrollera nätverksinställningarna direkt och snabbt hjälpa dig att konfigurera nätverket eller felsöka nätverksproblem.**

**Innan du godkänner fjärrhjälp bör du ta några minuter till följande förberedelser:**

## 1. Stäng program som inte behövs {#1-close-unnecessary-applications}

Stäng i förväg alla program som inte behövs. Det minskar störningar och skyddar din integritet.

## 2. Säkerställ en stabil nätverksanslutning {#2-ensure-network-stable}

Vi rekommenderar att datorn använder både Wi-Fi och en trådbunden anslutning för att undvika avbrott eller fördröjningar under fjärrhjälpen.

## 3. Ladda ned och installera AnyDesk {#3-download-and-install-anydesk}

Besök den officiella [AnyDesk-webbplatsen](https://anydesk.com/) och ladda ned den version som passar ditt operativsystem.

![download anydesk](https://static.gl-inet.com/docs/router/en/4/tutorials/remote_support_via_anydesk/install_anydesk.png){class="glboxshadow"}

Starta AnyDesk efter installationen.

## 4. Hämta AnyDesk-adressen {#4-obtain-anydesk-address}

När AnyDesk körs visas en numerisk adress, vanligtvis i formatet ”123 456 789”. Det är adressen som du ska dela med supportteknikern.

![get anydesk address](https://static.gl-inet.com/docs/router/en/4/tutorials/remote_support_via_anydesk/anydesk_address.png){class="glboxshadow"}

## 5. Dela AnyDesk-adressen {#5-share-anydesk-address}

Skicka AnyDesk-adressen till supportpersonalen så att de kan ansluta till enheten.

## 6. Godkänn anslutningsbegäran {#6-accept-connection-request}

När teknikern försöker ansluta visas en uppmaning om anslutningsbegäran.

Kontrollera att du litar på teknikern och klicka sedan på ”Accept” för att ge åtkomst till enheten.

![accept request](https://static.gl-inet.com/docs/router/en/4/tutorials/remote_support_via_anydesk/accept_request.png){class="glboxshadow"}

## 7. Kommunicera under sessionen {#7-communicate-during-session}

Under supportsessionen kan du kommunicera via högtalare, chattfönstret i AnyDesk-sessionen eller någon annan metod så att problemen kan åtgärdas effektivt.

## 8. Avsluta sessionen {#8-end-the-session}

När supportsessionen är klar avslutar du anslutningen genom att klicka på den röda knappen "End Session" i AnyDesk-gränssnittet. Då stängs den aktuella fjärrsupportsessionen. Om du har aktiverat **Unattended Access** ska du inaktivera det separat i AnyDesks säkerhetsinställningar. Gör även följande för att skydda din integritet fullständigt:

- Stäng AnyDesk-programmet helt och minimera det inte bara.
- Starta om datorn om du är orolig för kvarvarande processer.
- Kontrollera AnyDesks säkerhetsinställningar för att bekräfta att inga behörigheter för fjärråtkomst fortfarande är aktiva.
