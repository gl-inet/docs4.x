# Відновлення мережі або скидання до заводських налаштувань {#how-to-repair-network-or-factory-reset}

Усі маршрутизатори GL.iNet мають фізичний механізм скидання: кнопку або отвір із кнопкою всередині. Натискання кнопки безпосередньо або через отвір має однаковий ефект: відновлення мережевого доступу або скидання до заводських налаштувань.

Для моделей з отвором використовуйте шпильку, розігнуту скріпку або подібний інструмент.

Перед скиданням дочекайтеся повного запуску маршрутизатора. **НЕ натискайте** кнопку скидання одразу після увімкнення живлення, оскільки це може запустити аварійний режим U-Boot.

## Відновлення мережі {#repair-network}

Утримуйте кнопку скидання **4 секунди** та відпустіть її для програмного скидання, яке може відновити роботу мережі.

Ця дія перезапускає мережевий інтерфейс і повертає параметри інтернет-інтерфейсу до стандартних, зберігаючи налаштування Wi-Fi, VPN, системи тощо.

**Примітка**:

1. Якщо Wi-Fi вимкнено, програмне скидання поверне його до стану «увімкнено» за замовчуванням.

2. Програмне скидання також дає змогу швидко перейти з режиму Non-Router у режим Router.

## Скидання до заводських налаштувань {#reset-to-factory}

**Для моделей без сенсорного екрана** доступні два способи скидання: кнопкою скидання або через вебпанель адміністрування. Перегляньте це відео або виконайте наведені нижче дії.

<iframe width="560" height="315" src="https://www.youtube.com/embed/jguDqBWP-Fw" title="Відеопрогравач YouTube" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

1. Використайте фізичний механізм скидання: кнопку або отвір.

    Утримуйте кнопку скидання або натисніть її шпилькою через отвір протягом **10 секунд**, а потім відпустіть для скидання до заводських налаштувань. Усі дані користувача буде видалено.

    **Примітка:** якщо скидання не допомагає, може знадобитися [відновлення через Uboot](debrick.md).

2. Скиньте прошивку через вебпанель адміністрування.

    Увійдіть у вебпанель адміністрування та відкрийте SYSTEM -> Reset Firmware. Натисніть кнопку скидання прошивки.

    **Примітка:** усі поточні налаштування й дані буде втрачено. Процес триває приблизно 2 хвилини. НЕ вимикайте живлення маршрутизатора під час скидання.

    ![Скидання прошивки GL.iNet](https://static.gl-inet.com/docs/router/en/4/faq/repair_network_or_reset_firmware/reset_firmware_4.8.png){class="glboxshadow"}

**Для моделей із сенсорним екраном** доступні три способи скидання: через сенсорний екран, кнопкою скидання або через вебпанель адміністрування.

У відео нижче ці способи показано на Mudi 7 (GL-E5800). Такі самі дії застосовуються до всіх моделей із сенсорним екраном.
