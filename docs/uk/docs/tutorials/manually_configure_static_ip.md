# Як вручну налаштувати статичну IP-адресу на клієнтських пристроях? {#how-to-manually-configure-static-ip-on-the-client-devices}

=== "Windows 11"

    У Windows 11 статичну IP-адресу для бездротових і дротових адаптерів можна налаштувати через застосунок **Settings**.

    **Налаштування статичної IP-адреси адаптера Wi-Fi**

    Щоб призначити адаптеру Wi-Fi статичну IP-адресу, виконайте такі кроки:

    1. У Windows 11 відкрийте **Settings** -> **Network & Internet** -> вкладку **Wi-Fi** -> виберіть поточне мережеве з’єднання.

    2. У розділі **IP settings** натисніть **Edit**.

        ![Редагування IP-адреси у Windows 11](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/Windows_11_edit_IP_address.png){class="glboxshadow"}

    3. Виконайте наведені нижче кроки для налаштування:

        ![Налаштування статичної IP-адреси](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/Settings_app_set_static_IP_address.png){class="glboxshadow"}

        - Виберіть **Manual** і ввімкніть перемикач **IPv4**.

        - Установіть статичну IP-адресу для Windows 11, наприклад 10.1.4.119.

        - Укажіть **Subnet mask**, наприклад 255.255.255.0.

        - Укажіть адресу **Default Gateway**.

        - Укажіть адресу **Preferred DNS** (обов’язково).

        - За потреби вкажіть адресу **Alternate DNS**.

        - У розкривному меню **DNS over HTTPS** виберіть **Off** для основної та альтернативної адрес DNS. Щоб увімкнути DoH, можна вибрати такі параметри:

            - **Off**: увесь DNS-трафік передається без шифрування.

            - **On (automatic template)**: увесь DNS-трафік передається із шифруванням.

            - **On (manual template)**: дає змогу вказати конкретний шаблон. Це потрібно лише тоді, коли служба DNS не працює автоматично або має шаблон, який працює належним чином.

        - Вимкніть перемикач **Fallback to plaintext**, якщо ввімкнено DoH.

            - Порада: якщо ввімкнути цю функцію, система шифруватиме DNS-трафік, але дозволятиме надсилати запити без шифрування.

    4. Натисніть **Save**.

        Після виконання цих кроків статичну конфігурацію мережі буде застосовано на комп’ютері. Щоб перевірити нові налаштування, відкрийте браузер і завантажте вебсайт.


    ## **Налаштування статичної IP-адреси адаптера Ethernet** {#set-static-ip-address-on-ethernet-adapter}

    Щоб призначити адаптеру Ethernet (дротовому) статичну IP-адресу у Windows 11, виконайте такі кроки:

    1. Відкрийте **Settings** -> **Network & Internet** -> вкладку **Ethernet**.

    2. У розділі **IP settings** натисніть **Edit**.

        ![Редагування параметрів TCP/IP для Ethernet](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/Edit_TCP_IP_Ethernet_settings.png){class="glboxshadow"}

    3. Виконайте наведені нижче кроки для налаштування:

        ![Налаштування статичної IP-адреси](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/Settings_app_set_static_IP_address.png){class="glboxshadow"}

        - Виберіть **Manual**.

        - Увімкніть перемикач **IPv4**.

        - Установіть статичну IP-адресу для Windows 11, наприклад 10.1.4.119.

        - Укажіть **Subnet mask**, наприклад 255.255.255.0.

        - Укажіть адресу **Default Gateway**.

        - Укажіть адресу **Preferred DNS** (обов’язково).

        - За потреби вкажіть адресу **Alternate DNS**.

        - У розкривному меню **DNS over HTTPS** виберіть **Off** для основної та альтернативної адрес DNS. Щоб увімкнути DoH, можна вибрати такі параметри:

            * **Off**: увесь DNS-трафік передається без шифрування.

            * **On (automatic template)**: увесь DNS-трафік передається із шифруванням.

            * **On (manual template)**: дає змогу вказати конкретний шаблон. Це потрібно лише тоді, коли служба DNS не працює автоматично або має шаблон, який працює належним чином.

        - Вимкніть перемикач **Fallback to plaintext**, якщо ввімкнено DoH.

    4. Натисніть **Save**.

        Після виконання цих кроків перевірте налаштування, відкривши вебсайт у браузері.


=== "macOS"

    Щоб налаштувати статичну IP-адресу в macOS, виконайте такі дії:

    Якщо ви користуєтеся MacBook, можна створити нове мережеве розташування. Це дасть змогу використовувати статичну IP-адресу лише для певних мереж.

    У меню Apple виберіть **System Preferences**.

    Виберіть **Network**. З’явиться наведене нижче вікно.

    ![Мережеві налаштування Mac](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/Mac_network_settings.png){class="glboxshadow"}

    На бічній панелі виберіть активний мережевий інтерфейс. У цьому прикладі використовується бездротове з’єднання, тому виберіть **Wi-Fi**.

    Запишіть поточну IP-адресу свого Mac. Потрібно буде вибрати нову IP-адресу з наведеного діапазону приватних IP-адрес. Докладніше про це — нижче.

    Натисніть **Advanced**.

    Виберіть **TCP/IP**. З’явиться наведене нижче вікно.

    ![Налаштування Wi-Fi на Mac](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/Mac_Wi-Fi_settings.png){class="glboxshadow"}

    У меню **Configure IPv4** виберіть **Manually**.

    Введіть статичну IP-адресу в поле **IPv4 Address**. Один зі способів вибрати адресу — змінити останню частину поточної IP-адреси. Для мережі 192.168.7.0/24 виберіть вільну адресу вузла від 192.168.7.1 до 192.168.7.254. Не використовуйте адресу мережі або широкомовну адресу.

    Натисніть **OK** -> **Apply**.


=== "Android"

    Кроки можуть відрізнятися залежно від версії Android. Цю інструкцію створено для Android 11.

    1. Відкрийте **Settings** -> виберіть **Network & Internet**, потім **Wi-Fi** -> натисніть поточну підключену мережу, щоб відкрити меню налаштувань.

    ![Список доступних мереж](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/list_available_networks.png){class="gl-50-desktop"}
    {class="glboxshadow"}

    2. Щоб налаштувати статичну IP-адресу, виконайте такі дії:

    - Натисніть значок олівця у верхньому правому куті, щоб відкрити налаштування мережі.

        ![Значок олівця](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/pencil_icon.png){class="gl-50-desktop"}
        {class="glboxshadow"}

    - Виберіть **Advanced Options**.

        ![Додаткові параметри](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/advanced_options.png){class="gl-50-desktop"}
        {class="glboxshadow"}

    - Виберіть **IP Settings**.

    - Змініть значення з **DHCP** на **Static**.

        ![Зміна DHCP на Static](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/DHCP_to_Static.png){class="gl-50-desktop"}
        {class="glboxshadow"}

    - Для домашніх та інших приватних мереж виберіть вільну адресу вузла у своїй поточній підмережі. Стандартні діапазони приватних IP-адрес: від 10.0.0.0 до 10.255.255.255, від 172.16.0.0 до 172.31.255.255, від 192.168.0.0 до 192.168.255.255.

    - Введіть IP-адресу.
        - Цей крок залежить від конкретної мережі. Приклад: 192.168.1.128.

    - Поле **Gateway** має заповнитися автоматично на основі IP-адреси. Якщо цього не сталося, введіть IP-адресу шлюзу вашої мережі.
        - Приклад: якщо IP-адреса вашого маршрутизатора 192.168.1.1, введіть 192.168.1.1.

    3. Натисніть **Save** і дочекайтеся повторного підключення до мережі.

=== "iOS"

    Для домашніх та інших приватних мереж виберіть вільну адресу вузла у своїй поточній підмережі. Стандартні діапазони приватних IP-адрес:

    Від 10.0.0.0 до 10.255.255.255
    Від 172.16.0.0 до 172.31.255.255
    Від 192.168.0.0 до 192.168.255.255

    Щоб налаштувати статичну IP-адресу, виконайте такі дії:

    - Натисніть значок **Settings**.

    - Перейдіть до **Wi-Fi**.

    - Натисніть синій значок інформації (i) поруч із назвою мережі Wi-Fi.
         - У версіях, старіших за iOS 7, це може бути синій значок помилки.

    - Перейдіть на вкладку **Static**, показану нижче.


    ![Налаштування IP-адреси в iOS](https://static.gl-inet.com/docs/router/en/4/tutorials/manually_configure_static_ip/IP_Settings_Screen_iOS.png){class="glboxshadow"}

    - Натисніть поле **IP Address**.

    - Введіть статичну IP-адресу, яку хочете використовувати на iPhone/iPad.

    - Натисніть поле **Router**.

    - Введіть IP-адресу маршрутизатора.

    - Натисніть **Subnet Mask** і введіть значення.

        - Використовуйте маску підмережі, до якої ви підключені.

    - Натисніть кнопку **Wi-Fi** у верхньому лівому куті екрана, щоб зберегти налаштування.
