# Manual del usuario {#user-manual}

Esta página contiene actualmente manuales en PDF solo para modelos seleccionados. Se añadirán guías para modelos adicionales con regularidad.

Haga clic en un modelo a continuación para descargar su manual de usuario completo en PDF para consultarlo sin conexión.

**NOTA:** El contenido de estos documentos está sujeto a cambios sin previo aviso debido a actualizaciones del firmware del producto. Salvo acuerdo formal por escrito en contrario, estos documentos se proporcionan únicamente como referencia informativa. Ninguna declaración, dato o recomendación aquí contenidos constituirá garantía de ningún tipo.
