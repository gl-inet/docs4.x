# IGMP Snooping {#igmp-snooping}

У меню ліворуч у вебпанелі адміністрування перейдіть до **NETWORK** -> **IGMP Snooping**.

Увімкніть IGMP Snooping, щоб використовувати групове передавання даних на маршрутизаторі.

IGMP Snooping відстежує пакети протоколу IGMP, отримує з них потрібні відомості, створює та підтримує таблицю пересилання групового трафіку на рівні 2. Потім дані групи надсилаються лише хостам, які приєдналися до цієї групи; решта хостів їх не отримують.

**Примітка**: IGMPv3 сумісний із v1 і v2. За замовчуванням використовуйте v3; якщо виникнуть проблеми, виберіть іншу версію.
