# OpenVPN: TCP і UDP {#openvpn-tcp-vs-udp}

Сервер OpenVPN на маршрутизаторах GL.iNet підтримує протоколи TCP і UDP. Нижче наведено їхні відмінності.

TCP надійніший, але повільніший. UDP швидший, проте менш надійний.

Якщо для належної роботи застосунку потрібні низька затримка та безперервне передавання даних, краще вибрати UDP. В інших випадках TCP забезпечує надійне передавання даних без втрат.

UDP краще підходить для ігор, потокового передавання та служб VoIP. TCP — для електронної пошти, перегляду вебсторінок і передавання файлів.

Рекомендуємо спочатку спробувати UDP і переходити на TCP лише в разі нестабільного з’єднання, втрати пакетів або інших проблем із надійністю.
