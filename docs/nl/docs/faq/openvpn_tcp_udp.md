# OpenVPN, TCP vs UDP {#openvpn-tcp-vs-udp}

De OpenVPN-server van een GL.iNet-router ondersteunt zowel TCP als UDP. Wat is het verschil?

TCP is more reliable but slower in speed. UDP is faster but less reliable.

Als een toepassing een lage latentie en continue gegevensoverdracht vereist, is UDP een betere keuze. In andere gevallen biedt TCP betrouwbare gegevensoverdracht zonder verlies tijdens de verzending.

UDP is geschikter voor games, streaming en VoIP-diensten. TCP is geschikter voor e-mail, webbrowsen en bestandsoverdracht.

We raden aan eerst UDP te proberen en alleen naar TCP over te schakelen bij een instabiele verbinding, pakketverlies of andere betrouwbaarheidsproblemen.
