# Довідка {#help}

У вебпанелі адміністрування натисніть значок знака питання праворуч у рядку заголовка.

![Меню довідки](https://static.gl-inet.com/docs/router/en/4/interface_guide/help/help.png){class="glboxshadow"}

Тут можна відкрити [документацію з підтримки маршрутизаторів](../index.md).

Починаючи з прошивки v4.8, можна звернутися до технічної підтримки одним натисканням, що спрощує отримання допомоги.

Натисніть **Contact Tech Support**: відкриється сторінка Log, а праворуч з’явиться спливне вікно.

![Звернення до технічної підтримки](https://static.gl-inet.com/docs/router/en/4/interface_guide/help/contact_support.png){class="glboxshadow"}

![Надсилання відгуку](https://static.gl-inet.com/docs/router/en/4/interface_guide/help/send_feedback.png){class="glboxshadow"}

Параметри Upload System Log і Upload Debug Info позначені за замовчуванням.

Заповніть потрібні відомості та натисніть **Send**, щоб отримати допомогу.
