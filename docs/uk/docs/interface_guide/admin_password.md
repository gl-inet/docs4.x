# Пароль адміністратора {#admin-password}

**Примітка**: Починаючи з прошивки v4.3, цю сторінку було об’єднано зі сторінкою [Безпека](security.md), а з прошивки v4.9 її відновлено як окрему сторінку.

На цій сторінці можна встановити або змінити пароль для інтерфейсу адміністрування маршрутизатора.

---

У лівому меню вебпанелі адміністрування відкрийте **SYSTEM** > **Admin Password**.

![Пароль адміністратора](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_password/admin_password.png){class="glboxshadow"}

Змініть пароль для входу у вебпанель адміністрування маршрутизатора. Для внесення змін потрібно ввести поточний пароль.

Пароль адміністратора має відповідати таким вимогам:

- Щонайменше 10 і щонайбільше 63 символи.
- Дозволено літери (з урахуванням регістру), цифри та символи `` ! @ # $ % ^ & * ( ) _ + - = , . > < | ? / \ [ ] { } : ; " ' ` ~ ``.
- Пароль має містити символи щонайменше двох із таких категорій: великі літери, малі літери, цифри та спеціальні символи.
