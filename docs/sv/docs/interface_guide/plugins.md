# Plug-ins {#plug-ins}

Öppna **APPLICATIONS** -> **Plug-ins** på vänster sida i webbadministrationspanelen.

På sidan kan du hantera OpenWrt-paket och installera eller ta bort dem.

Klicka på **Update** innan du använder insticksprogram från tredje part. **Uppdatera inte förinstallerade insticksprogram från officiell GL.iNet-firmware**, till exempel `nginx`, `adguard home` och `tailscale`.

![Plug-ins](https://static.gl-inet.com/docs/router/en/4/interface_guide/plug-ins/plug-ins.png){class="glboxshadow"}

Manuellt installerade insticksprogram kan uppdateras, men GL.iNet ansvarar inte för säkerhetsproblem från tredje part. Kontakta respektive utvecklare.
