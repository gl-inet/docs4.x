# Прошивка v4.10 {#firmware-v410}

У цій версії з’явилися Mesh, GL.iNet Account і вбудована підтримка VLAN. Також поліпшено керування обліковим записом GoodCloud та зроблено інтерфейс зручнішим.

Завантажте найновішу прошивку з [центру завантаження прошивок](https://dl.gl-inet.com/){target="_blank"}.

## Mesh {#mesh}

[Mesh](../interface_guide/mesh.md) — це функція на основі стандарту Wi-Fi EasyMesh™, яка розширює покриття Wi-Fi в усьому домі та забезпечує безперервний роумінг. Якщо у вас кілька маршрутизаторів GL.iNet, налаштуйте один як основний маршрутизатор, а решту — як mesh-вузли для роумінгу Wi-Fi під час пересування домом.

![Mesh](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/mesh.png){class="glboxshadow"}

## GL.iNet Account {#glinet-account}

[GL.iNet Account](../interface_guide/glinet_account.md) надає єдину сторінку для підключення та керування пристроями й доступу до хмарних сервісів. Один обліковий запис GL.iNet Account дає змогу користуватися GoodCloud і застосунком GL.iNet для зручнішого керування мережею та пристроями. Також можна швидко відкрити сторінку GoodPAS (у v4.10 на моделях, відмінних від GL-MG1300, вона називається AstroWarp) для встановлення захищеного з’єднання між дорожнім маршрутизатором і домашньою мережею.

![Обліковий запис GL.iNet](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/account.png){class="glboxshadow"}

## GoodCloud {#goodcloud}

[GoodCloud](../interface_guide/cloud.md) — це хмарна платформа для віддаленого розгортання та керування маршрутизаторами GL.iNet. Вона об’єднує пристрої з різних місць і підтримує групове налаштування та оновлення прошивки. Також доступні віддалений доступ до вебпанелі адміністрування та термінала пристрою через SSH для зручнішого керування маршрутизаторами.

У прошивці v4.10 GoodCloud спрощує прив’язування облікового запису та дає змогу видалити дані хмарного облікового запису під час скидання до заводських налаштувань.

![GoodCloud](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/goodcloud.png){class="glboxshadow"}

## Підмережі {#subnet}

Сторінка [Subnet](../interface_guide/subnet.md) об’єднує налаштування LAN, Guest Network, IoT Network і власних мереж VLAN в одному поданні. Єдиний інтерфейс для всіх параметрів підмереж дає змогу створювати та керувати кількома підмережами для ізоляції різних типів пристроїв або трафіку.

На зображенні нижче показано сторінку Subnet на Flint 3 (GL-BE9300).

![Підмережі](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/subnet.png){class="glboxshadow"}

## Порти Ethernet {#ethernet-port}

На сторінці [Ethernet Port](../interface_guide/ethernet_port_v4.10.md) відображаються всі інтерфейси Ethernet маршрутизатора. Можна перевірити стан з’єднання, перемикати порти між ролями WAN і LAN та переглядати подробиці, зокрема MAC-адресу, узгоджену швидкість і стан каналу. Також можна призначати фізичні інтерфейси будь-яким створеним підмережам для конфігурацій VLAN (Virtual Local Area Network).

На зображенні нижче показано сторінку Ethernet Port на Flint 3 (GL-BE9300).

![Порти Ethernet](https://static.gl-inet.com/docs/router/en/4/features_update/4.10/ehternet_port.png){class="glboxshadow"}
