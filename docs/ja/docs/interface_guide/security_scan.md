# セキュリティスキャン

**注**：この機能はファームウェアv4.11で導入されました。

---

Web管理画面の左側で、**SECURITY** -> **Security Scan**に移動します。

セキュリティスキャンは、ルーターのセキュリティを確認します。ルーターのセキュリティ設定を評価し、セキュリティスコア、リスク警告、最適化の提案を表示します。スキャン結果に基づいて設定を調整し、ルーターのセキュリティを強化できます。

このページを開くと、セキュリティスキャンが自動的に開始されます。Wi-Fi Security、WAN Ping、Remote SSH、Port Forwarding、DPI Content Protectionなど、複数のセキュリティ項目が確認されます。スコアのアイコンをクリックしてリセットし、スキャンを再実行することもできます。スキャンが完了すると、主要な指標を確認できます。

![Security Scan](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/security_scan.png){class="glboxshadow"}

- **Score**：ルーター設定の総合セキュリティスコアです。

- **Risks**：対処が必要な重大なセキュリティ問題です。

- **Suggestions**：セキュリティを改善するための推奨事項で、必須の修正ではありません。

- **Safe**：セキュリティチェックに合格した項目です。

次の2つのタブをクリックすると、詳細なスキャン結果を確認できます。

- **Risk & Suggestion**

    **Risk & Suggestion**をクリックして、リスクと最適化の提案を表示します。

    ![Risk & Suggestion](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/risk_suggestion.png){class="glboxshadow"}

    ルーターのセキュリティを改善するには、各項目の横にある**Go to Settings**をクリックして対応する設定ページへ直接移動し、設定を調整します。

- **Safe**

    **Safe**をクリックして、セキュリティチェックに合格したすべての項目を表示します。

    ![safe](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/safe.png){class="glboxshadow"}
