# MAC Address {#mac-address}

Deze handleiding geldt voor firmware v4.5 en ouder.

De pagina MAC Address heette voorheen MAC Clone en is sinds v4.2 hernoemd naar MAC Address.

Sinds v4.6 zijn de MAC-adresinstellingen voor de interfaces Ethernet en Repeater verplaatst naar respectievelijk [Ethernet Port](ethernet_port.md) en [Repeater](internet_repeater.md).

---

Ga links in het webbeheerpaneel naar **NETWORK** -> **MAC Address**.

Je kunt het standaard-MAC-adres van de router bekijken, het MAC-adres van een client klonen, handmatig een MAC-adres invoeren of een willekeurig adres genereren.

Als het apparaat meerdere Ethernet-poorten als WAN-poort ondersteunt, kun je het MAC-adres voor elke poort afzonderlijk instellen. De instelling geldt alleen wanneer de Ethernet-poort als WAN-poort wordt gebruikt.

![default mac address](https://static.gl-inet.com/docs/router/en/4/interface_guide/mac_address/mac_address.png){class="glboxshadow"}

* Het standaard-MAC-adres uit de fabriek.

    ![default mac address](https://static.gl-inet.com/docs/router/en/4/interface_guide/mac_address/factory_default.png){class="glboxshadow"}

* Het MAC-adres van een client klonen.

    ![clone mac address](https://static.gl-inet.com/docs/router/en/4/interface_guide/mac_address/clone.png){class="glboxshadow"}

    **Opmerking:** veel nieuwe apparaten gebruiken voor verschillende Wi-Fi-netwerken een ander willekeurig MAC-adres. Het hier weergegeven adres is daarom mogelijk niet het fysieke adres. Een willekeurig MAC-adres kan op apparaten ook Private Wi-Fi Address of random hardware address heten.

* Handmatig een MAC-adres invoeren of een willekeurig adres genereren.

    ![Manual input or generate a random mac address](https://static.gl-inet.com/docs/router/en/4/interface_guide/mac_address/manual.png){class="glboxshadow"}

## Gebruikssituaties {#usage-scenarios}

Gebruik bij een openbare hotspot een willekeurig MAC-adres als je niet wilt dat de hotspot je werkelijke adres kent of de internettoegang daarop beperkt. Raadpleeg [Verbinding maken met een hotspot met captive portal](../faq/connect_to_a_hotspot_with_captive_portal.md).
