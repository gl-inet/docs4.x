# How to upgrade to firmware 4.x? {#how-to-upgrade-to-firmware-4x}

**This document is outdated and no longer maintained. Click [here](../interface_guide/upgrade.md) for the latest upgrade guide.**

---

Volg de onderstaande stappen om je router van firmware 3.x naar 4.x bij te werken.

Opmerking: behoud de instellingen niet wanneer je van v3.x naar v4.x bijwerkt, omdat dit instabiliteit kan veroorzaken. Maak vóór de upgrade een back-up van belangrijke instellingen.

De GL-B1300 en GL-S1300 ondersteunen de meshfunctie niet in firmware v4.x.

---

## Method 1. Local Upgrade {#method-1-local-upgrade}

Je kunt de firmware via het webbeheerpaneel bijwerken.

1. Upgrade the firmware to the latest stable 3.x version.

2. Download the 4.x firmware [here](https://dl.gl-inet.com){target="_blank"}. Make sure you **download the one for common upgrade**.

3. Meld je aan bij het webbeheerpaneel, ga naar **Upgrade** -> **Local Upgrade** en upload het firmwarebestand dat je zojuist hebt gedownload.

    **Opmerking:** firmware 4.x is niet compatibel met firmware 3.x. Behoud de instellingen **NIET** wanneer je een upgrade uitvoert vanaf firmware 3.x.

    ![local upgrade](https://static.gl-inet.com/docs/router/en/4/faq/upgrade_to_4/ax1800_upgrade_4.png){class="glboxshadow gl-90-desktop"}

## Method 2. U-Boot Upgrade {#method-2-u-boot-upgrade}

1. Download the 4.x firmware [here](https://dl.gl-inet.com){target="_blank"}. Make sure you **download the one for U-Boot**.

2. Refer to this [U-Boot](debrick.md) guide to flash the firmware.
