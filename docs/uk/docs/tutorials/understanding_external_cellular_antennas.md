# Що потрібно знати про зовнішні стільникові антени {#understanding-external-cellular-antennas}

Зовнішні стільникові антени можуть поліпшити якість стільникового з’єднання за певних умов, але не гарантують збільшення швидкості завантаження чи передавання даних.

У цьому посібнику пояснено, коли зовнішня антена може допомогти, як вибрати сумісну антену та які чинники впливають на продуктивність стільникового з’єднання.

## Коли варто використовувати зовнішню антену? {#when-should-i-use-an-external-antenna}

Зовнішня антена може поліпшити з’єднання, якщо маршрутизатор установлено в місці, де стільниковий сигнал послаблюється, перш ніж досягти пристрою.

Типові приклади:

- Будинки на колесах і кемпери
- Транспортні засоби
- Підвали
- Будівлі з бетонними, цегляними або металевими стінами
- Технічні приміщення або мережеві шафи
- Сільська місцевість зі слабким стільниковим покриттям

Перш ніж купувати антену, спробуйте перемістити маршрутизатор ближче до вікна або вище. У багатьох випадках самого переміщення маршрутизатора достатньо для значного поліпшення якості сигналу.

## Коли зовнішня антена не допоможе? {#when-wont-an-external-antenna-help}

Зовнішня антена не може вирішити всі проблеми зі стільниковим з’єднанням.

Поліпшення може бути незначним або відсутнім, якщо:

- Маршрутизатор уже отримує сильний стільниковий сигнал.
- Базова станція перевантажена.
- Оператор мобільного зв’язку обмежує швидкість мережі.
- Антена не підтримує частотні діапазони вашого оператора.
- Довгі антенні кабелі спричиняють надмірні втрати сигналу.
- Антену встановлено майже в тому самому місці, де розташовані внутрішні антени маршрутизатора.

Сильніший сигнал не завжди означає вищу швидкість інтернету.

## Вибір відповідної антени {#choosing-the-right-antenna}

Перш ніж купувати антену, переконайтеся, що вона сумісна як із вашим маршрутизатором, так і з мережею мобільного оператора.

Перевірте такі характеристики:

- Тип роз’єму відповідає вашому маршрутизатору.
- Антена підтримує стільникові частотні діапазони, які використовує ваш оператор.
- Антена призначена для LTE, 5G або обох технологій, залежно від вашого маршрутизатора.
- Антена підходить для умов установлення (у приміщенні, у транспортному засобі, надворі тощо).

Відповідний тип антенного роз’єму вказано в документації вашого маршрутизатора.

## Технологія MIMO {#understanding-mimo}

Більшість сучасних мереж LTE і 5G використовують технологію **Multiple Input Multiple Output (MIMO)** — передавання й приймання через кілька антен — для підвищення пропускної здатності та надійності з’єднання.

Багато стільникових маршрутизаторів GL.iNet мають кілька стільникових антенних портів для підтримки MIMO.

Для найкращої продуктивності:

- Підключіть усі необхідні антенні кабелі.
- За можливості використовуйте сумісну MIMO-антену.
- Дотримуйтеся рекомендацій виробника антени щодо відстані між антенами та їхньої орієнтації.

Використання лише однієї антени з маршрутизатором, розрахованим на кілька антен, може знизити загальну продуктивність.

## Коефіцієнт підсилення антени та втрати в кабелі {#antenna-gain-and-cable-loss}

Коефіцієнт підсилення антени зазвичай вимірюють у **dBi**.

Вищий коефіцієнт підсилення не завжди означає кращу продуктивність.

Антени з вищим коефіцієнтом підсилення зазвичай мають вужчу діаграму спрямованості, тому підходять для стаціонарного встановлення, коли відоме розташування базової станції, що обслуговує з’єднання.

Довжина кабелю не менш важлива. Кожен антенний кабель спричиняє втрати сигналу, перш ніж він досягне маршрутизатора.

Для найкращого результату:

- Використовуйте найкоротший кабель, який підходить для вашого встановлення.
- Уникайте зайвих перехідників.
- Для довгих кабельних трас використовуйте коаксіальний кабель із малими втратами.

## Всеспрямовані та спрямовані антени {#omnidirectional-vs-directional-antennas}

### Всеспрямовані антени {#omnidirectional-antennas}

Всеспрямовані антени приймають сигнали з усіх напрямків.

Їх зазвичай рекомендують для:

- Транспортних засобів
- Будинків на колесах
- Мобільних установок
- Місць із кількома базовими станціями поблизу

### Спрямовані антени {#directional-antennas}

Спрямовані антени зосереджують приймання сигналу в певному напрямку.

Їх зазвичай рекомендують, коли:

- Маршрутизатор залишається в одному місці.
- Відоме розташування базової станції, що обслуговує з’єднання.
- Стільникове покриття слабке.
- Потрібна максимальна якість сигналу.

Для найкращої продуктивності спрямовані антени зазвичай потрібно ретельно зорієнтувати.

## Оцінювання поліпшення {#measuring-improvement}

Не покладайтеся лише на індикатор рівня сигналу в інтерфейсі маршрутизатора.

Порівняйте показники сигналу до та після встановлення антени.

Корисні показники:

- RSRP (рівень сигналу)
- RSRQ (якість сигналу)
- SINR (співвідношення сигналу до завад)
- Діапазон LTE або 5G, який використовується для з’єднання
- Стан агрегації частот

Виконайте кілька тестів швидкості за подібних умов, оскільки продуктивність стільникового з’єднання природно змінюється протягом дня.

## Поширені запитання {#frequently-asked-questions}

### Чи можна використовувати будь-яку стільникову антену? {#can-i-use-any-cellular-antenna}

Ні.

Антена повинна мати відповідний тип роз’єму та підтримувати стільникові частотні діапазони, які використовують ваш маршрутизатор і мобільний оператор.

### Чи варто купувати антену з найбільшим доступним коефіцієнтом підсилення? {#should-i-buy-the-highest-gain-antenna-available}

Не обов’язково.

Вибирайте антену, яка підходить для ваших умов установлення, а не лише за заявленим коефіцієнтом підсилення.

### Чи завжди зовнішня антена збільшує швидкість інтернету? {#will-an-external-antenna-always-increase-my-internet-speed}

Ні.

Продуктивність залежить від багатьох чинників, зокрема якості сигналу, агрегації частот, завантаженості базової станції, умов мережі та вашого мобільного оператора.

### Чи працюватимуть внутрішні стільникові антени після підключення зовнішніх? {#will-the-internal-cellular-antennas-still-be-used-when-external-antennas-are-connected}

Ні.

На стільникових маршрутизаторах GL.iNet із портами для зовнішніх стільникових антен підключення сумісних зовнішніх антен вимикає відповідні внутрішні стільникові антени.

Для найкращої продуктивності підключіть усі необхідні кабелі зовнішніх антен. Підключення лише одного кабелю до маршрутизатора, розрахованого на кілька стільникових антен, може знизити продуктивність MIMO та загальну якість з’єднання.

### Чи можна підключити Wi-Fi-антену до стільникового антенного порту? {#can-i-connect-a-wi-fi-antenna-to-a-cellular-antenna-port}

Ні.

Wi-Fi-антени та стільникові антени призначені для різних радіосистем і не є взаємозамінними.
