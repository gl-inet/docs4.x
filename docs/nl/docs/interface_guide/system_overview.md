# Systeemoverzicht {#system-overview}

Ga links in het webbeheerpaneel naar **SYSTEM** -> **Overview**.

De pagina Overview toont de status van hardware en biedt eenvoudige bediening, waaronder:

- Status van CPU, Memory, Flash en External Storage.
- Status van hardware zoals Fan en Battery.
- Bediening van leds en Fan.
- Apparaatgegevens.

GL-MT3000 wordt hieronder als voorbeeld gebruikt.

![system overview](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/overview.png){class="glboxshadow"}

## Gemiddelde CPU-belasting {#cpu-average-load}

Bij de meeste modellen zonder ventilator wordt de gemiddelde CPU-belasting als volgt weergegeven.

![system overview, cpu average load, no fan](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/cpu_average_load_no_fan.jpg){class="glboxshadow"}

Bij modellen met een ingebouwde ventilator wordt de gemiddelde CPU-belasting als volgt weergegeven.

![system overview, cpu average load, with fan](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/cpu_average_load.png){class="glboxshadow gl-70-desktop"}

Beweeg de muis over de grafiek om specifieke waarden weer te geven.

Klik rechts op de temperatuur om tussen Celsius en Fahrenheit te schakelen.

Klik rechtsboven op het Fan-pictogram om Fan Settings te openen.

![system overview, fan settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/fan_settings.png){class="glboxshadow gl-70-desktop"}

!!! note "Modellen met ingebouwde ventilator"

    - GL-BE14000 (Flint 4)
    - GL-BE10000 (Slate 7 Pro)
    - GL-BE9300 (Flint 3)
    - GL-BE6500 (Flint 3e)
    - GL-MT3600BE (Beryl 7)
    - GL-X2000 (Spitz Plus)
    - GL-X3000 (Spitz AX)
    - GL-XE3000 (Puli AX)
    - GL-BE3600 (Slate 7)
    - GL-MT3000 (Beryl AX)
    - GL-AXT1800 (Slate AX)

## Geheugengebruik {#memory-usage}

Beweeg de muis over de grafiek om specifieke waarden weer te geven.

**Opmerking**: dit is het geheugen dat voor Linux beschikbaar is. Het totale weergegeven geheugen is kleiner dan het fysieke geheugen omdat een deel aan het Wi-Fi-subsysteem of andere opstartgebieden wordt toegewezen.

![system overview, memory usage](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/memory_usage.png){class="glboxshadow gl-70-desktop"}

## LED {#led}

Klik op het tandwielpictogram om de ledinstellingen van [Scheduled Tasks](scheduled_tasks.md) te openen.

![system overview, memory usage](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/led.png){class="glboxshadow gl-70-desktop"}

## Flash {#flash}

Dit toont het totale flashgeheugen, waaronder System used, Apps used en Available.

![system overview, flash](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/flash.png){class="glboxshadow"}

## Apparaatgegevens {#device-info}

Dit gedeelte toont de basisgegevens van het apparaat.

Device ID, Device MAC en Device S/N zijn toegevoegd in firmware v4.7 en hoger.

![system overview, device info](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/device_info.jpg){class="glboxshadow gl-80-desktop"}

## Externe opslag {#external-storage}

Dit gedeelte is beschikbaar sinds v4.5 en toont de totale en beschikbare capaciteit van USB Disk.

Some models in firmware v4.7 and above version support switching USB protocol.

![system overview, external storage](https://static.gl-inet.com/docs/router/en/4/interface_guide/system_overview/external_storage.jpg){class="glboxshadow"}
