# Een gast-Wi-Fi-netwerk instellen op GL.iNet-routers {#how-to-set-up-a-guest-wi-fi-network-on-glinet-routers}

In deze handleiding lees je hoe je een gast-Wi-Fi-netwerk instelt op GL.iNet-routers.

Een gast-Wi-Fi-netwerk is een afzonderlijk netwerk op een router voor apparaten die je van je hoofdapparaten wilt scheiden. Dit kunnen apparaten van gasten en smarthomeapparaten zijn. Met een gastnetwerk voorkom je onbevoegde toegang tot en mogelijke aanvallen op je primaire netwerk, waardoor je netwerk beter beveiligd is.

Je kunt op twee manieren een gast-Wi-Fi-netwerk instellen op je GL.iNet-router: via het [webbeheerpaneel van de router](#set-up-a-guest-network-via-the-admin-panel) of de [mobiele GL.iNet-app](#set-up-a-guest-network-via-the-glinet-mobile-app).

## Een gastnetwerk instellen via het webbeheerpaneel {#set-up-a-guest-network-via-the-admin-panel}

### 1. Het gast-Wi-Fi-netwerk inschakelen {#1-enable-the-guest-wi-fi-network}

1. Voer in een webbrowser `192.168.8.1` in.
2. Voer je wachtwoord in en klik op **Login**.
3. Klik in de linkerzijbalk op **Wireless**.
![click wireless](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-wireless.jpeg){class="glboxshadow"}
4. Klik in het gedeelte voor je 5GHz- of 2.4GHz-Wi-Fi-netwerk op het tabblad **Guest Wi-Fi**.
![click guest](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-guest-wifi.jpeg){class="glboxshadow"}
5. Schakel de optie naast **Enable Wi-Fi** in.

### 2. Een nieuw wachtwoord voor het gast-Wi-Fi-netwerk instellen {#2-set-a-new-guest-wi-fi-network-password}

Voor een goede beveiliging wordt aangeraden een nieuw wachtwoord voor je gast-Wi-Fi-netwerk in te stellen. Volg deze stappen:

1. Klik op **Modify**.
![click modify](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-modify.jpeg){class="glboxshadow"}
2. Voer naast **Wi-Fi Password** een nieuw wachtwoord in. (Je kunt naast **Wi-Fi Name** ook een nieuwe netwerknaam invoeren.)
3. Klik vervolgens op **Apply**.

Je hebt nu een gast-Wi-Fi-netwerk ingesteld. Zoek de naam van het gastnetwerk in de lijst met beschikbare netwerken en voer het wachtwoord in om je apparaten ermee te verbinden.

## Een gastnetwerk instellen via de mobiele GL.iNet-app {#set-up-a-guest-network-via-the-glinet-mobile-app}

**Opmerking:** installeer en configureer de mobiele GL.iNet-app op je apparaat voordat je begint.

### 1. Het gast-Wi-Fi-netwerk inschakelen {#1-enable-the-guest-wi-fi-network_1}

1. Tik in het hoofdscherm van de app op het tabblad **Network** > **Wireless**.
2. Zoek **Guest Network**.
3. Schakel de optie in voor het netwerk waarvoor je een gast-Wi-Fi-netwerk wilt instellen.
![toggle the switch](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/toggle-on-guest-network.jpeg){class="glboxshadow"}

### 2. Een nieuw wachtwoord voor het gast-Wi-Fi-netwerk instellen {#2-set-a-new-guest-wi-fi-network-password_1}

Voor een goede beveiliging wordt aangeraden een nieuw wachtwoord voor je gast-Wi-Fi-netwerk in te stellen. Volg deze stappen:

1. Tik op de optie **SSID** van het netwerk waarvoor je een gast-Wi-Fi-netwerk hebt ingesteld.
2. Voer naast **Password** een nieuw wachtwoord in. (Je kunt in het SSID-veld ook een nieuwe netwerknaam invoeren.)
![enter a new password](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/tap-password.jpeg){class="glboxshadow"}
3. Tik op **Done**.

Je hebt nu een gast-Wi-Fi-netwerk ingesteld. Zoek de naam van het gastnetwerk in de lijst met beschikbare netwerken en voer het wachtwoord in om je apparaten ermee te verbinden.
