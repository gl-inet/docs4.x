# Що таке LuCI? {#what-is-luci}

LuCI — вебінтерфейс OpenWrt для виконання додаткових налаштувань.

Це відкритий незалежний проєкт, який супроводжує OpenWrt. GL.iNet не відповідає за супровід LuCI.

Щоб відкрити LuCI, у меню ліворуч у вебпанелі адміністрування перейдіть до SYSTEM -> Advanced Settings.

![Відкриття LuCI з додаткових налаштувань](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/go_to_luci.png){class="glboxshadow"}

Натисніть кнопку **Go To LuCI**, щоб відкрити сторінку входу в LuCI.

![Сторінка входу в LuCI](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/luci_login.jpg){class="glboxshadow"}

Уведіть пароль для входу. Він збігається з паролем вебпанелі адміністрування.

Відкриється сторінка LuCI. Нижче наведено приклад для GL-AX1800 (Flint).

![Інтерфейс LuCI після входу](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/luci_logged_in.jpg){class="glboxshadow"}
