# Посібник користувача Beryl (GL-MT1300) {#beryl-gl-mt1300-user-guide}

<span id="hardware-info"></span>

## Огляд пристрою {#product-overview}

Beryl (GL-MT1300) — продуктивний компактний маршрутизатор із потужним апаратним забезпеченням, сучасними протоколами кібербезпеки та оригінальним дизайном. Це вдосконалена версія популярного Slate (GL-AR750S), яка представляє нове покоління дорожніх маршрутизаторів.

![Інтерфейси gl-mt1300](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt1300/hardware_info/mt1300_interface.jpg){class="glboxshadow"}

## Комплект постачання {#package-contents}

Тип адаптера в комплекті залежить від країни доставки.

До комплекту входять:

- 1 x посібник користувача
- 1 x Beryl (GL-MT1300)
- 1 x кабель Ethernet
- 1 x картка подяки
- 1 x гарантійна картка
- 1 x адаптер живлення (вибраний тип вилки)

![Комплект постачання gl-mt1300](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt1300/first_time_setup/mt1300_unboxing.jpg){class="glboxshadow"}

Перегляньте [відео розпакування](../../video_library/unboxing_first_set_up.md#gl-mt1300-beryl) Beryl.

## Інтернет {#internet}

Увійдіть до вебпанелі адміністрування маршрутизатора та виберіть **INTERNET** у меню ліворуч.

На цій сторінці можна вибрати тип інтернет-підключення, наприклад Ethernet, Repeater, Tethering або Cellular.

### Ethernet {#ethernet}

Щоб отримати доступ до інтернету, підключіть маршрутизатор кабелем Ethernet до активного модема або іншого мережевого пристрою. Зазвичай цей спосіб забезпечує найшвидше та найнадійніше інтернет-з’єднання.

[Дізнайтеся, як підключитися до інтернету через кабель Ethernet](../../interface_guide/internet_ethernet.md)

![Підключення Ethernet](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt1300/internet/mt1300_ethernet.png){class="glboxshadow"}

### Ретранслятор {#repeater}

Налаштуйте маршрутизатор як ретранслятор для розширення покриття наявної мережі Wi-Fi. У цьому режимі він приймає та повторно передає бездротові сигнали в межах досяжності, збільшуючи покриття. Цей спосіб корисний, якщо одного маршрутизатора недостатньо для покриття всієї потрібної площі.

[Дізнайтеся, як підключитися до інтернету через наявну мережу Wi-Fi](../../interface_guide/internet_repeater.md)

![Підключення через ретранслятор](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt1300/internet/mt1300_repeater.png){class="glboxshadow"}

### USB Tethering {#tethering}

Підключіть USB-порт маршрутизатора USB-кабелем до смартфона з активним мобільним підключенням для доступу до інтернету. Цей спосіб дає змогу кільком пристроям, підключеним до маршрутизатора, використовувати мобільний трафік смартфона.

[Дізнайтеся, як підключитися до інтернету через USB Tethering](../../interface_guide/internet_tethering.md)

![Підключення через USB Tethering](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt1300/internet/mt1300_tethering.png){class="glboxshadow"}

### Стільникове підключення {#cellular}

Підключіть маршрутизатор до інтернету, вставивши USB-модем із підтримкою стільникового зв’язку в його USB-порт. Цей спосіб корисний для надання всім підключеним пристроям доступу до інтернету через USB-модем.

[Дізнайтеся, як підключитися до інтернету через USB-модем](../../interface_guide/internet_cellular.md)

![Стільникове підключення](https://static.gl-inet.com/docs/router/en/4/user_guide/gl-mt1300/internet/mt1300_cellular.png){class="glboxshadow"}

### Multi-WAN {#multi-wan}

Multi-WAN дає змогу одночасно налаштувати на маршрутизаторі кілька інтернет-підключень (наприклад, Ethernet і Repeater). Якщо підключення з найвищим пріоритетом перестане працювати, маршрутизатор автоматично перемкнеться на інше. Це називається **Failover** — аварійне перемикання, яке забезпечує безперервний доступ до інтернету.

Перейдіть до [Multi-WAN](../../interface_guide/multi-wan.md), щоб установити пріоритет кожного інтернет-підключення.

Також можна змінити режим Multi-WAN із **Failover** на **Load Balance**. Це дає змогу одночасно використовувати кілька мережевих інтерфейсів для збільшення загальної пропускної здатності маршрутизатора.
