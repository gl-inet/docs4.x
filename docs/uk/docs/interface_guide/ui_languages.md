# Мови інтерфейсу {#ui-languages}

Ця функція доступна починаючи з прошивки v4.6.

---

Натисніть кнопку мови у верхньому правому куті, щоб змінити або додати мови інтерфейсу.

Щоб додати мови інтерфейсу або оновити його текст, натисніть **Add Languages**.

![Список мовних пакетів інтерфейсу](https://static.gl-inet.com/docs/router/en/4/interface_guide/ui_languages/add_languages.jpg){class="glboxshadow"}

У спливному вікні виберіть потрібну мову та натисніть **Update**. Маршрутизатор автоматично завантажить найновіший мовний пакет із нашого репозиторію. Деінстальовані мовні пакети буде видалено (крім англійського).

Щоб автоматично отримувати найновіший мовний пакет для виправлення можливих проблем із текстом, увімкніть **Enable Auto Update** і задайте час оновлення. Маршрутизатор автоматично завантажуватиме найновіший мовний пакет у встановлений час.

![Список мовних пакетів інтерфейсу](https://static.gl-inet.com/docs/router/en/4/interface_guide/ui_languages/languages_list.png){class="glboxshadow"}
