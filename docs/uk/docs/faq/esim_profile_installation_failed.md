# Що робити, якщо профіль eSIM не встановлюється? {#what-should-i-do-if-esim-profile-installation-fails}

Якщо під час додавання профілю eSIM на маршрутизатор GL.iNet виникає помилка встановлення, виконайте наведені нижче дії.

1. Перевірте підключення маршрутизатора до інтернету.

    Переконайтеся, що маршрутизатор успішно підключено до інтернету. Нестабільна мережа може перешкоджати завантаженню профілю eSIM, через що маршрутизатор не зможе отримати та встановити його.

    За можливості підключіть маршрутизатор до іншої мережі, наприклад точки доступу смартфона або публічного Wi-Fi, та знову завантажте профіль eSIM для перевірки.

2. Змініть налаштування DNS.

    Якщо інтернет працює належним чином, увійдіть у вебпанель адміністрування та відкрийте **NETWORK** -> **DNS**.

    Для DNS Mode виберіть **Manual DNS** і задайте інші публічні DNS-сервери для перевірки, наприклад Google DNS (`8.8.8.8`, `8.8.4.4`) або Cloudflare DNS (`1.1.1.1`, `1.0.0.1`).

    Натисніть **Apply**, щоб зберегти зміни, і повторно завантажте профіль eSIM.

    ![Ручне налаштування DNS](https://static.gl-inet.com/docs/router/en/4/faq/esim_profile_installation_failed/manual_dns.jpg){class="glboxshadow"}

3. Вимкніть AdGuard Home.

    Якщо AdGuard Home доступний і увімкнений на маршрутизаторі, вимкніть його та повторіть встановлення профілю eSIM.

4. Перевірте доступність профілю eSIM.

    Перевірте, чи цей профіль eSIM або QR-код уже активовано чи встановлено на іншому пристрої.

    Більшість профілів eSIM можна встановити лише один раз; їх не можна активувати на кількох пристроях. За можливості зверніться до провайдера eSIM, щоб перевірити доступність поточного профілю. Якщо QR-код або код активації прострочено, отримайте новий і знову спробуйте завантажити його на маршрутизатор.

5. Перевірте код активації.

    QR-код правильного формату надає код активації, який починається з **LPA:**. Деякі нестандартні QR-коди містять лише код без префікса LPA. У такому разі вручну додайте `LPA:` на початку коду перед натисканням Install.

    ![Код активації eSIM](https://static.gl-inet.com/docs/router/en/4/faq/esim_profile_installation_failed/activation_code.jpg){class="glboxshadow" width="600"}

6. Перевірте, чи потрібен код підтвердження.

    Деякі профілі, наприклад Smarty eSIM, потребують коду підтвердження під час встановлення. Перевірте пакет eSIM або інструкцію, щоб з’ясувати, чи потрібен такий код. Якщо так, введіть правильний код.

    ![Код підтвердження eSIM](https://static.gl-inet.com/docs/router/en/4/faq/esim_profile_installation_failed/confirmation_code.jpg){class="glboxshadow" width="600"}

7. Якщо попередні дії не допомогли, експортуйте журнал eSIM зі сторінки eSIM Management.

    ![Експорт журналу eSIM](https://static.gl-inet.com/docs/router/en/4/faq/esim_profile_installation_failed/export_log.png){class="glboxshadow"}

    Надішліть журнал і наведені нижче відомості на [support@gl-inet.com](mailto:support@gl-inet.com), щоб отримати допомогу.

    - Опис проблеми
    - Випробувані способи усунення несправностей, якщо такі були
    - Ваш провайдер eSIM
