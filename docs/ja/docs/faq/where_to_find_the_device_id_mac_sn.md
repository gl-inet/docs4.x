# デバイスID、MACアドレス、シリアル番号はどこで確認できますか？ {#where-to-find-the-device-id-mac-address-and-serial-number}

## 方法1 {#method-1}

これらの情報はルーターの底面に記載されています。

新しいモデルの場合、底面のラベルは以下の画像のようになっており、デバイスの基本情報が記載されています。たとえば、下の写真では、MACは **E4:95:6E:40:DB:A1**、デバイスIDは**hh0dba1**、シリアル番号は**7c0be4bb45d96057**です。

![label of gl-x750](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/back_label_new.png){class="glboxshadow"}

古いモデルの場合、底面のラベルにデバイスIDは記載されていませんが、DDNSが記載されています。DDNSの最初の7文字がデバイスIDです。例として下の写真を見ると、MACは **E4:95:6E:40:DB:A1**、デバイスIDは**hh0dba1**、シリアル番号は**7c0be4bb45d96057**です。

![label of gl-ar150](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/back_label_old.png){class="glboxshadow"}

## 方法2 {#method-2}

Web管理パネルにログインし、SYSTEM -> Overview に移動すると、デバイスの詳細情報が表示されます。

![device overview](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/overview_device_info.png){class="glboxshadow"}
