# Оновлення до прошивки 4.x {#how-to-upgrade-to-firmware-4x}

**Ця інструкція застаріла та більше не підтримується. Актуальну інструкцію з оновлення наведено [тут](../interface_guide/upgrade.md).**

---

Виконайте наведені нижче дії, щоб оновити маршрутизатор із прошивки 3.x до 4.x.

Примітка: не зберігайте налаштування під час переходу з v3.x на v4.x, оскільки це може спричинити нестабільність. Перед оновленням створіть резервну копію важливих налаштувань.

GL-B1300 і GL-S1300 не підтримують Mesh у прошивці v4.x.

---

## Спосіб 1. Локальне оновлення {#method-1-local-upgrade}

Прошивку можна оновити через вебпанель адміністрування.

1. Оновіть прошивку до останньої стабільної версії 3.x.

2. Завантажте прошивку 4.x за [цим посиланням](https://dl.gl-inet.com){target="_blank"}. Виберіть **варіант для звичайного оновлення**.

3. Увійдіть у вебпанель адміністрування та відкрийте **Upgrade** -> **Local Upgrade**. Завантажте отриманий файл прошивки.

    **Примітка:** прошивка 4.x несумісна з 3.x. Під час переходу з 3.x **НЕ** зберігайте налаштування.

    ![Локальне оновлення](https://static.gl-inet.com/docs/router/en/4/faq/upgrade_to_4/ax1800_upgrade_4.png){class="glboxshadow gl-90-desktop"}

## Спосіб 2. Оновлення через U-Boot {#method-2-u-boot-upgrade}

1. Завантажте прошивку 4.x за [цим посиланням](https://dl.gl-inet.com){target="_blank"}. Виберіть **варіант для U-Boot**.

2. Встановіть прошивку за [інструкцією U-Boot](debrick.md).
