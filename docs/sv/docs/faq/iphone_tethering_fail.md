# Internetdelning från iPhone misslyckas {#iphone-tethering-failed}

Om internetdelning från en iPhone misslyckas kan du prova följande steg för att lösa problemet.

1. Kontrollera att **Maximise Compatibility** är **Enabled** (iPhone 8 eller senare).

    ![maxcompat](https://static.gl-inet.com/docs/router/en/4/faq/iphone_tethering_fail/maxcompat.png){class="glboxshadow gl-50-desktop" }

2. Inaktivera hotspot på telefonen, vänta i 5 sekunder och aktivera funktionen igen.

    ![hotspot](https://static.gl-inet.com/docs/router/en/4/faq/iphone_tethering_fail/hotspot.png){class="glboxshadow gl-50-desktop"}

3. Kontrollera att iOS-versionen är 15 eller senare.

4. Koppla ur och anslut Lightning-/Type-C-kabeln igen.

5. Använd en annan USB-kabel. Kontrollera att den stöder dataöverföring och inte endast laddning.

6. Använd routerns ursprungliga strömförsörjning.

7. Starta om både routern och din iPhone. Ibland löser en omstart av iPhone problemet med internetdelning.
