# Moet ik Ethernet WAN configureren wanneer ik VPN gebruik? {#do-i-have-to-configure-ethernet-wan-when-using-vpn}

Nee. Wanneer je de GL.iNet-router als VPN-client instelt, kun je elke WAN-bron configureren. Je LAN en WLAN worden via de VPN-tunnel geleid.

## Configure by Wi-Fi Repeater {#configure-by-wi-fi-repeater}

Je kunt de GL.iNet-router die als VPN-client is ingesteld draadloos met je primaire router verbinden. De GL.iNet-router werkt dan als wifi-repeater.

![repater](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/repeater.jpg){class="glboxshadow"}

## Configure by Ethernet cable {#configure-by-ethernet-cable}

Je kunt de GL.iNet-router die als VPN-client is ingesteld via een Ethernetkabel met je primaire router verbinden.

![ethernet](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/ethernet.jpg){class="glboxshadow"}

## Configure by USB Tethering {#configure-by-usb-tethering}

Je kunt de GL.iNet-router die als VPN-client is ingesteld via een USB-kabel met je telefoon verbinden. Dit wordt ook USB Tethering genoemd.

![tethering](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/tethering.jpg){class="glboxshadow"}
