# Analyse de sécurité

**Remarque** : cette fonctionnalité a été introduite dans le firmware v4.11.

---

Dans le menu latéral gauche du panneau d'administration Web, accédez à **SECURITY** -> **Security Scan**.

Security Scan effectue un contrôle de sécurité du routeur. Il évalue les paramètres de sécurité et produit un score accompagné d'alertes de risque et de suggestions d'optimisation. Vous pouvez adapter la configuration selon les résultats afin de renforcer la sécurité du routeur.

Une analyse de sécurité démarre automatiquement à l'ouverture de cette page. Elle vérifie plusieurs éléments, notamment Wi-Fi Security, WAN Ping, Remote SSH, Port Forwarding et DPI Content Protection. Vous pouvez également cliquer sur l'icône du score pour réinitialiser et relancer l'analyse. Une fois celle-ci terminée, les principales mesures sont affichées.

![Security Scan](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/security_scan.png){class="glboxshadow"}

- **Score** : score de sécurité global de la configuration du routeur.

- **Risks** : problèmes de sécurité critiques nécessitant une correction.

- **Suggestions** : bonnes pratiques recommandées pour améliorer la sécurité, sans caractère obligatoire.

- **Safe** : éléments ayant réussi le contrôle de sécurité.

Vous pouvez parcourir les résultats détaillés à l'aide des deux onglets ci-dessous.

- **Risk & Suggestion**

    Cliquez sur **Risk & Suggestion** pour afficher les risques et les suggestions d'optimisation.

    ![Risk & Suggestion](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/risk_suggestion.png){class="glboxshadow"}

    Pour améliorer la sécurité du routeur, cliquez sur **Go to Settings** en regard de chaque élément afin d'accéder directement à la page de configuration correspondante et d'ajuster les paramètres.

- **Safe**

    Cliquez sur **Safe** pour afficher tous les éléments ayant réussi le contrôle de sécurité.

    ![safe](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/safe.png){class="glboxshadow"}
