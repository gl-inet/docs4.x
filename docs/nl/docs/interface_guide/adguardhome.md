# AdGuard Home {#adguard-home}

AdGuard Home blokkeert advertenties en tracking in het hele netwerk. Na de installatie beschermt het alle apparaten in je thuisnetwerk zonder aanvullende software op de clients.

## Instellen {#setup}

Meld je aan bij het webbeheerpaneel van de router en ga naar **APPLICATIONS** -> **AdGuard Home**.

Zet de schakelaar om om AdGuard Home in te schakelen en klik op **Apply**.

![adguard home apply](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/apply.png){class="glboxshadow"}

- **AdGuard Home Handle Client Requests**: wanneer dit is ingeschakeld, verwerkt AdGuard Home DNS-query's van clientapparaten rechtstreeks. VPN-beleid op basis van domeinen en regels voor ouderlijk toezicht werken dan niet.

Na inschakeling toont de pagina via de API van AdGuard Home statistieken, waaronder DNS-query's en geblokkeerde domeinen.

![adguard home web panel](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/adguardhome_web_panel.png){class="glboxshadow"}

Klik bovenaan de pagina op **Settings Page**.

![adguard home started](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/settings_page.png){class="glboxshadow"}

Je wordt doorgestuurd naar de officiële instellingenpagina van AdGuard Home om geavanceerde filterregels te configureren.

![adguard home settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/adguardhome_dashboard.png){class="glboxshadow"}

Ga bij vragen naar het [AdGuard Home Support Center](https://adguard.com/en/support.html){target="_blank"} voor verdere hulp.
