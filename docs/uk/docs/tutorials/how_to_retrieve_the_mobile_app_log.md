# Як отримати журнал мобільного застосунку {#how-to-retrieve-the-mobile-app-log}

Якщо під час використання мобільного застосунку GL-Inet виникають несправності й ви хочете отримати його журнал, виконайте наведені нижче кроки.

## Перейдіть на головну сторінку застосунку {#go-to-the-app-main-page}

Натисніть значок **Wheel** у нижньому лівому куті.

![Головна сторінка мобільного застосунку](https://static.gl-inet.com/docs/router/en/4/tutorials/app_log/Applog1.jpg){class="glboxshadow gl-50-desktop"}

## Натисніть **Enable** у розділі APP LOG(BETA) {#tap-the-enable-at-app-logbeta}

![Увімкнення журналу застосунку](https://static.gl-inet.com/docs/router/en/4/tutorials/app_log/Applog2.jpg){class="glboxshadow gl-50-desktop"}

## Натисніть **Show Log-Window** {#tap-show-log-window}

![Відкриття вікна журналу](https://static.gl-inet.com/docs/router/en/4/tutorials/app_log/Applog3.jpg){class="glboxshadow gl-50-desktop"}

## Ліворуч з’явиться синій значок **L** {#a-blue-l-icon-will-appear-on-the-left-side}

Натисніть значок L, щоб переглянути журнал функції, яку ви щойно використовували в застосунку.

![Значок журналу застосунку](https://static.gl-inet.com/docs/router/en/4/tutorials/app_log/Applog4.jpg){class="glboxshadow gl-50-desktop"}
