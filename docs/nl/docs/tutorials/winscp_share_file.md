# Gedeelde bestanden openen met WinSCP {#use-winscp-to-access-your-share-files}

Met **WinSCP** kun je bestanden openen die via de functie voor bestandsdeling van **GL.iNet-routers** worden gedeeld.

Stel je **WebDAV**-links in op het tabblad voor netwerkopslag. Raadpleeg [WebDAV instellen](../interface_guide/network_storage.md#set-up-webdav) voor details.

## Setup links in WinSCP {#setup-links-in-winscp}

Ga na de WebDAV-configuratie terug naar de pagina **Share Folders** van de netwerkopslag.

![webdav1](https://static.gl-inet.com/docs/router/en/4/tutorials/network_storage/webdav_client/webdav1.png){class="glboxshadow gl-80-desktop"}

Klik met de rechtermuisknop op **"..."** en kopieer de HTTPS-link.

![webdav2](https://static.gl-inet.com/docs/router/en/4/tutorials/network_storage/webdav_client/webdav2.png){class="glboxshadow"}

Start WinSCP, selecteer WebDAV en TLS/SSL-versleuteling. Plak de link bij **Host name**. Het poortnummer wordt automatisch 6008.

![webdav3](https://static.gl-inet.com/docs/router/en/4/tutorials/network_storage/webdav_client/webdav3.png){class="glboxshadow"}

Voer je gebruikersnaam en wachtwoord in, sla de gegevens op en meld je aan. De gedeelde map wordt geopend.

![webdav4](https://static.gl-inet.com/docs/router/en/4/tutorials/network_storage/webdav_client/webdav4.png){class="glboxshadow"}
