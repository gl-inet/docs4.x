# Оновлення {#upgrade}

У меню ліворуч у вебпанелі адміністрування перейдіть до **SYSTEM** -> **Upgrade**, щоб оновити прошивку маршрутизатора.

На деяких моделях зі стільниковим з’єднанням за потреби також можна оновити версію модуля.

!!! Warning

    Залишайте живлення ввімкненим під час оновлення. **НЕ** вимикайте живлення маршрутизатора. Після оновлення пристрій автоматично перезавантажиться; це може тривати кілька хвилин.

## Оновлення прошивки {#firmware-upgrade}

### Оновлення через інтернет {#online-upgrade}

Online Upgrade автоматично перевіряє наявність найновішої офіційної прошивки через інтернет, завантажує та встановлює її безпосередньо на маршрутизаторі. Це дає змогу зручно оновити офіційну прошивку одним натисканням, якщо маршрутизатор підключено до інтернету.

Поточна версія прошивки відображається в розділі **Firmware Online Upgrade**.

![Оновлення прошивки через інтернет](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/online_upgrade.png){class="glboxshadow"}

- **Accept Preview Plan**

    Якщо ввімкнено, можна випробувати нові функції до випуску остаточної версії та надати нам відгук. Такі оновлення можуть бути нестабільними.

**Примітка**: Якщо під час оновлення через інтернет з’являється **Download Failed**, перейдіть до System -> Time Zone та виправте помилку часового поясу, синхронізувавши його з браузером.

![Помилка завантаження прошивки](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/online_download_failed.jpg){class="glboxshadow" width="360"}

![Синхронізація часового поясу](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/time_zone.png){class="glboxshadow"}

### Локальне оновлення {#local-upgrade}

Local Upgrade підтримує ручне завантаження файла прошивки для встановлення. Це дає змогу оновлювати прошивку, повертатися до раніших версій або встановлювати певні бета-версії для перевірки нових функцій.

Спочатку завантажте файл прошивки з нашого [центру завантажень](https://dl.gl-inet.com){target="_blank"}, а потім перейдіть до **Firmware Local Upgrade**.

![Локальне оновлення прошивки](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/local_upgrade.png){class="glboxshadow"}

Виберіть файл або перетягніть його в область завантаження. Система перевірить прошивку.

![Завантажений файл прошивки](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/local_upgrade_uploaded.png){class="glboxshadow"}

- **Keep Settings:** Якщо ввімкнено, поточні налаштування буде збережено. Після оновлення з’явиться запит на повторне встановлення пакетів, які користувач установив самостійно. НЕ позначайте цей параметр під час повернення до ранішої версії прошивки.

Натисніть **Install**, щоб оновити прошивку.

## Оновлення модема {#modem-upgrade}

На стільникових маршрутизаторах GL.iNet можна оновлювати прошивку стільникового модема через вебпанель адміністрування.

Якщо стільникове з’єднання не працює або працює нестабільно, можна спробувати оновити стільниковий модуль. Перед оновленням модема рекомендуємо звернутися до технічної підтримки для усунення несправностей.

### Оновлення через інтернет {#online-upgrade_1}

Тут відображається поточна версія стільникового модема. Якщо маршрутизатор підключено до інтернету, він автоматично перевіряє наявність найновішої версії на сервері виробника, що спрощує оновлення.

![Оновлення модема через інтернет](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/modem_online_upgrade.png){class="glboxshadow"}

### Локальне оновлення {#local-upgrade_1}

За потреби вручну завантажте файл прошивки модема з комп’ютера, щоб оновити стільниковий модем.

![Локальне оновлення модема](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/modem_local_upgrade.png){class="glboxshadow"}

## Оновлення DPI через інтернет {#dpi-online-upgrade}

DPI Online Upgrade перевіряє та оновлює рушій DPI і його базу сигнатур для точного визначення трафіку в Data Statistics, Content Filter та інших функціях DPI.

**Примітка**: Ця функція з’явилася у прошивці v4.11.

![Оновлення DPI через інтернет](https://static.gl-inet.com/docs/router/en/4/interface_guide/upgrade/dpi_online_upgrade.png){class="glboxshadow" width=700}
