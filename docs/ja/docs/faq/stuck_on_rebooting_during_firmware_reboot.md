# ファームウェア再起動中に「Rebooting」のまま進まない {#stuck-on-rebooting-during-firmware-reboot}

ファームウェアの再起動中にルーターが「Rebooting」のまま進まない場合は、以下の手順に従って問題を解決してください。

![stuck on rebooting](https://static.gl-inet.com/docs/router/en/4/faq/troubleshooting/stuck_on_rebooting/rebooting.png){class="glboxshadow"}

各手順の後に、問題が解決したかどうかを確認してください。解決した場合は、残りの手順は不要です。

1. 再起動プロセスが自動的に完了するかどうかを確認するため、少なくとも5分間待ちます。特にファームウェアアップデート後は、再起動プロセスに想定より時間がかかることがあります。

2. 5分経っても再起動プロセスが完了しない場合は、電源ケーブルを抜いてルーターの電源を切ります。30秒待ってから電源ケーブルを再度挿し込み、ルーターが起動するのを待ちます。

3. Webブラウザを開き、`192.168.8.1`にアクセスします。再起動操作が成功した場合は、ルーターのログインページにリダイレクトされます。

4. ブラウザのプライベート/シークレットモードを有効にし、`192.168.8.1`にアクセスします。再起動プロセスが成功した場合、ルーターのログインページにリダイレクトされます。

5. 別のブラウザ（Chrome、Edge、Safariなど）を使用して`192.168.8.1`にアクセスします。再起動プロセスが成功した場合、ルーターのログインページにリダイレクトされます。

6. ルーターのWeb管理パネルにまだアクセスできない、またはルーターが正常に機能していない場合は、[こちら](repair_network_or_reset_firmware.md#reset-to-factory)のガイドに従ってルーターを工場出荷時のデフォルト設定にリセットしてみてください。
