# Advanced Settings {#advanced-settings}

Öppna **SYSTEM** -> **Advanced Settings** på vänster sida i webbadministrationspanelen.

Du kan ändra avancerade inställningar med LuCI, standardwebbgränssnittet för OpenWrt.

![advanced settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/go_to_luci.png){class="glboxshadow"}

LuCI är ett öppet och oberoende projekt som underhålls av OpenWrt och tillhandahålls i befintligt skick. GL.iNet ansvarar inte för underhållet av LuCI.

Klicka på **Go To LuCI**. Du omdirigeras till inloggningssidan för LuCI.

![luci login](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/luci_login.jpg){class="glboxshadow"}

Ange inloggningslösenordet, som är samma som lösenordet för webbadministrationspanelen.

Du loggas in på LuCI-sidan. Nedan visas LuCI-sidan för GL-AX1800 (Flint) som exempel.

![luci logged in](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/luci_logged_in.jpg){class="glboxshadow"}
