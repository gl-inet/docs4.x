# Часовий пояс {#time-zone}

У меню ліворуч у вебпанелі адміністрування перейдіть до **SYSTEM** -> **Time Zone**.

Маршрутизатор записує часові позначки подій відповідно до системного часу. Для належної роботи деяких функцій потрібен правильний час. Переконайтеся, що вибрано та синхронізовано правильний часовий пояс.

Часовий пояс не синхронізується автоматично. Натисніть кнопку **Sync**, щоб оновити його.

![Часовий пояс до синхронізації](https://static.gl-inet.com/docs/router/en/4/interface_guide/time_zone/time_zone_no_sync.png){class="glboxshadow"}
