# Як отримати віддалений доступ до вебпанелі адміністрування маршрутизатора GL.iNet? {#how-to-remotely-access-the-web-admin-panel-of-a-glinet-router}

Для наведених нижче способів потрібно заздалегідь виконати налаштування, поки ви фізично перебуваєте біля маршрутизатора.

## Спосіб 1. GoodCloud {#method-1-goodcloud}

[GL.iNet GoodCloud](https://www.goodcloud.xyz){target="_blank"} — платформа для спрощення віддаленого розгортання та керування підключеними пристроями. Вона дає змогу легко отримувати віддалений доступ до маршрутизаторів GL.iNet і керувати ними. Прив’яжіть маршрутизатор GL.iNet до GoodCloud, щоб отримувати доступ до його вебпанелі адміністрування в будь-який час і з будь-якого місця.

Докладніше дивіться в [цьому посібнику](../interface_guide/cloud.md){target="_blank"}.

## Спосіб 2. VPN {#method-2-vpn}

Якщо маршрутизатор має **публічну IP-адресу**, до його вебпанелі адміністрування можна отримати віддалений доступ через тунель VPN. Цей спосіб потребує розширених налаштувань і більше часу.

1. Переконайтеся, що маршрутизатор має публічну IP-адресу. [Як перевірити наявність публічної IP-адреси?](../tutorials/how_to_check_if_isp_assigns_you_a_public_ip_address.md){target="_blank"}

2. Налаштуйте маршрутизатор як сервер WireGuard. Докладніше дивіться [тут](../interface_guide/wireguard_server.md){target="_blank"}.

3. Експортуйте файл конфігурації сервера WireGuard для подальшого використання.

4. У вебпанелі адміністрування маршрутизатора перейдіть до **VPN** -> **WireGuard Server** і натисніть **Options** угорі праворуч. Увімкніть **Allow Remote Access to the LAN Subnet** і натисніть **Apply**.

5. Налаштуйте пристрій, з якого потрібен віддалений доступ до маршрутизатора, як клієнт WireGuard, імпортувавши файл конфігурації вручну.

    - Якщо клієнт WireGuard — кінцевий пристрій, наприклад смартфон або ноутбук, [установіть застосунок WireGuard](https://www.wireguard.com/install){target="_blank"} та імпортуйте файл, щоб установити з’єднання.

    - Якщо клієнт WireGuard — інший маршрутизатор GL.iNet, наприклад маршрутизатор для подорожей, скористайтеся [цим посібником](../interface_guide/wireguard_client.md#set-up-wireguard-client-manually-for-other-providers){target="_blank"}, щоб імпортувати файл конфігурації та встановити з’єднання.
