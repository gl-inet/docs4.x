# Де знайти ідентифікатор пристрою, MAC-адресу та серійний номер? {#where-to-find-the-device-id-mac-address-and-serial-number}

## Спосіб 1 {#method-1}

Знайдіть ці відомості на нижній стороні маршрутизатора.

На новіших моделях нижня етикетка схожа на зображену нижче та містить основні відомості про пристрій. У цьому прикладі MAC — **E4:95:6E:40:DB:A1**, Device ID — **hh0dba1**, а Serial Number — **7c0be4bb45d96057**.

![Етикетка gl-x750](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/back_label_new.png){class="glboxshadow"}

На старіших моделях нижня етикетка не містить Device ID, проте на ній є DDNS. Перші 7 символів DDNS — це Device ID. У прикладі нижче MAC — **E4:95:6E:40:DB:A1**, Device ID — **hh0dba1**, а Serial Number — **7c0be4bb45d96057**.

![Етикетка gl-ar150](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/back_label_old.png){class="glboxshadow"}

## Спосіб 2 {#method-2}

Увійдіть у вебпанель адміністрування та перейдіть до SYSTEM -> Overview, щоб переглянути відомості про пристрій.

![Огляд відомостей про пристрій](https://static.gl-inet.com/docs/router/en/4/faq/where_to_find_the_device_id_mac_sn/overview_device_info.png){class="glboxshadow"}
