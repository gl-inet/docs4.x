# Admin Password {#admin-password}

**Obs!** Sidan slogs ihop med [Security](security.md) från firmware v4.3 och återställdes som fristående sida i firmware v4.9.

På den här sidan kan du ange eller ändra lösenordet för routerns administratörsgränssnitt.

---

Öppna **SYSTEM** > **Admin Password** på vänster sida i webbadministrationspanelen.

![admin password](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_password/admin_password.png){class="glboxshadow"}

Ändra inloggningslösenordet för routerns webbadministrationspanel. Det aktuella lösenordet krävs för att göra ändringar.

The admin password must meet the following requirements:

- Minimum 10 characters and maximum 63 characters.
- Letters (case sensitive), numbers and symbols `` ! @ # $ % ^ & * ( ) _ + - = , . > < | ? / \ [ ] { } : ; " ' ` ~ `` are allowed.
- Minst två av följande teckentyper krävs: versaler, gemener, siffror och symboler.
