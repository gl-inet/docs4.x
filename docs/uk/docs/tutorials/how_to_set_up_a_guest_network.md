# Як налаштувати гостьову мережу Wi-Fi на маршрутизаторах GL.iNet {#how-to-set-up-a-guest-wi-fi-network-on-glinet-routers}

У цій інструкції описано, як налаштувати гостьову мережу Wi-Fi на маршрутизаторах GL.iNet.

Гостьова мережа Wi-Fi — це окрема мережа маршрутизатора для пристроїв, які потрібно ізолювати від основних пристроїв. Це можуть бути пристрої гостей або розумного дому. Створення гостьової мережі допомагає запобігти несанкціонованому доступу до основної мережі та потенційним атакам на неї, підвищуючи безпеку мережі.

Налаштувати гостьову мережу Wi-Fi на маршрутизаторі GL.iNet можна двома способами: через [вебпанель адміністрування маршрутизатора](#set-up-a-guest-network-via-the-admin-panel) або [мобільний застосунок GL.iNet](#set-up-a-guest-network-via-the-glinet-mobile-app).

## Налаштування гостьової мережі через вебпанель адміністрування {#set-up-a-guest-network-via-the-admin-panel}

### 1. Увімкніть гостьову мережу Wi-Fi {#1-enable-the-guest-wi-fi-network}

1. У веббраузері введіть `192.168.8.1`.
2. Введіть пароль і натисніть **Login**.
3. На бічній панелі ліворуч натисніть **Wireless**.
![Відкриття Wireless](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-wireless.jpeg){class="glboxshadow"}
4. У розділі мережі Wi-Fi 5GHz або 2.4GHz відкрийте вкладку **Guest Wi-Fi**.
![Відкриття Guest Wi-Fi](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-guest-wifi.jpeg){class="glboxshadow"}
5. Увімкніть перемикач поруч із **Enable Wi-Fi**.

### 2. Установіть новий пароль гостьової мережі Wi-Fi {#2-set-a-new-guest-wi-fi-network-password}

Для захисту мережі рекомендуємо встановити новий пароль гостьової мережі Wi-Fi. Виконайте такі кроки:

1. Натисніть **Modify**.
![Зміна налаштувань Wi-Fi](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/click-modify.jpeg){class="glboxshadow"}
2. Поруч із **Wi-Fi Password** введіть новий пароль. (Поруч із **Wi-Fi Name** також можна ввести нову назву мережі.)
3. Натисніть **Apply**.

Гостьову мережу Wi-Fi налаштовано. Щоб підключити до неї пристрої, знайдіть її назву у списку доступних мереж і введіть пароль.

## Налаштування гостьової мережі через мобільний застосунок GL.iNet {#set-up-a-guest-network-via-the-glinet-mobile-app}

**Примітка:** Перш ніж почати, встановіть і налаштуйте мобільний застосунок GL.iNet на своєму пристрої.

### 1. Увімкніть гостьову мережу Wi-Fi {#1-enable-the-guest-wi-fi-network_1}

1. На головному екрані застосунку натисніть вкладку **Network** > **Wireless**.
2. Знайдіть **Guest Network**.
3. Увімкніть перемикач для мережі, у якій потрібно налаштувати гостьову мережу Wi-Fi.
![Увімкнення гостьової мережі](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/toggle-on-guest-network.jpeg){class="glboxshadow"}

### 2. Установіть новий пароль гостьової мережі Wi-Fi {#2-set-a-new-guest-wi-fi-network-password_1}

Для захисту мережі рекомендуємо встановити новий пароль гостьової мережі Wi-Fi. Виконайте такі кроки:

1. Натисніть параметр **SSID** мережі, у якій ви налаштували гостьову мережу Wi-Fi.
2. Поруч із **Password** введіть новий пароль. (У полі SSID також можна ввести нову назву мережі.)
![Введення нового пароля](https://static.gl-inet.com/docs/router/en/4/tutorials/how_to_set_up_a_guest_network/tap-password.jpeg){class="glboxshadow"}
3. Натисніть **Done**.

Гостьову мережу Wi-Fi налаштовано. Щоб підключити до неї пристрої, знайдіть її назву у списку доступних мереж і введіть пароль.
