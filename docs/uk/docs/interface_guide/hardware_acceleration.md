# Апаратне прискорення {#hardware-acceleration}

**Примітка**: Цей посібник стосується прошивки v4.2 та раніших версій. Для новіших версій дивіться [Прискорення мережі](network_acceleration.md).

---

Апаратне прискорення (також відоме як *апаратний NAT, перенесення оброблення потоків на обладнання або offloading*) зменшує навантаження на процесор, переносячи пересилання пакетів із процесора на апаратні компоненти SoC/NIC маршрутизатора. Зазвичай це підвищує максимальну пропускну здатність і знижує використання процесора, проте має суттєві обмеження, особливо для функцій, які залежать від мережевого стека Linux (netfilter/iptables/nftables) або механізмів керування чергами ядра (qdisc), що використовуються SQM (Smart Queue Management, інтелектуальним керуванням чергами).

Коли апаратне прискорення ввімкнено, такі функції працюватимуть некоректно: Client Speed and Traffic Statistics (статистика швидкості та трафіку клієнтів) і Client Speed Limit (обмеження швидкості клієнтів).

## Швидке налаштування {#quick-setup}

У меню ліворуч у вебпанелі адміністрування перейдіть до **NETWORK** -> **Hardware Acceleration**.

Увімкніть перемикач і натисніть Apply.

## Апаратний і програмний NAT {#hardware-nat-vs-software-nat}

* Якщо головне для вас — пропускна здатність (наприклад, широкосмугове з’єднання на кілька гігабіт за секунду), а SQM на маршрутизаторі або формування трафіку для окремих клієнтів не потрібні, увімкніть Hardware NAT / Network Acceleration. Це забезпечує найвищу пропускну здатність і найнижче навантаження на процесор.

* Якщо потрібні низька затримка, стабільний QoS, обмеження для окремих клієнтів або ви використовуєте SQM (cake/fq_codel), застосовуйте програмний NAT (вимкніть апаратне прискорення пересилання пакетів). Для роботи SQM і QoS пакети мають проходити через стек qdisc ядра. Пакети, що обробляються апаратно, оминають цей шлях, тому формування трафіку до них не застосовується.
