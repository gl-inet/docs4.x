# ファームウェアリセット中に「Reverting」でスタックする {#stuck-on-reverting-during-firmware-reset}

ルーターがファームウェアリセット中に「Reverting」でスタックする場合は、以下の手順に従って問題を解決してください。

![stuck on reverting](https://static.gl-inet.com/docs/router/en/4/faq/troubleshooting/stuck_on_reverting/reverting.png){class="glboxshadow"}

各手順の後、問題が解決したかどうかを確認します。解決した場合は、残りの手順をスキップできます。

1. リセット（Reverting）プロセスが自動的に完了するかどうかを確認するため、少なくとも10分間待ちます。リセットプロセスには想定より時間がかかることがあります。

2. 10分経ってもリセットプロセスが完了しない場合は、電源ケーブルを抜いてルーターの電源を切ります。30秒待ってから電源ケーブルを再度挿し込み、ルーターが起動するのを待ちます。

3. Webブラウザを開き、`192.168.8.1`にアクセスしてログインします。リセット操作が成功した場合は、セットアップガイドにリダイレクトされます。

4. ブラウザのプライベート/シークレットモードを有効にし、`192.168.8.1`にアクセスします。リセットプロセスが成功した場合、セットアップガイドにリダイレクトされます。

5. 別のブラウザ（Chrome、Edge、Safariなど）を使用して`192.168.8.1`にアクセスします。リセットプロセスが成功した場合、セットアップガイドにリダイレクトされます。

6. ルーターのWeb管理パネルにまだアクセスできない、またはルーターが正常に機能していない場合は、[こちら](repair_network_or_reset_firmware.md#reset-to-factory)のガイドに従ってルーターを工場出荷時のデフォルト設定にリセットしてみてください。
