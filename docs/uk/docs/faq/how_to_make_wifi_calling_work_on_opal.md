# Як налаштувати роботу Wi-Fi Calling на Opal (GL-SFT1200)? {#how-to-make-wi-fi-calling-work-on-opal-gl-sft1200}

## Оновлення прошивки {#upgrade-firmware}

У вебпанелі адміністрування перейдіть до SYSTEM -> Upgrade та оновіть прошивку до найновішої версії. Перевірте її в [центрі завантаження прошивок](https://dl.gl-inet.com/){target="_blank"}.

![Оновлення прошивки Opal](https://static.gl-inet.com/docs/router/en/4/faq/wifi_call/opal4317.jpg){class="glboxshadow"}

## Вимкнення прискорення мережі {#disable-network-acceleration}

За нашим досвідом і відгуками користувачів, Wi-Fi Calling працює належно після вимкнення Network/Hardware Acceleration.

Після оновлення прошивки увійдіть у вебпанель адміністрування, перейдіть до **NETWORK** -> **Network Acceleration** і вимкніть функцію.

![Вимкнення прискорення мережі](https://static.gl-inet.com/docs/router/en/4/faq/wifi_call/netacc.jpg){class="glboxshadow"}
