# Hur laddar jag ned firmware till min GL.iNet-router? {#how-to-download-the-firmware-for-my-glinet-router}

Om du vill uppdatera routern (eller återställa den via U-Boot) laddar du ned firmwarefilerna genom att följa dessa steg:

1. Välj sökfältet och din routermodell i [GL.iNets nedladdningscenter för firmware](https://dl.gl-inet.com).
2. Välj en flik högst upp:
    * **Stable:** Den officiella versionen för daglig användning, som rekommenderas för de flesta användare.
    * **Beta** (endast tillgänglig för vissa routermodeller): En förhandsversion som fortfarande är under utveckling.
    * **Snapshot** (endast tillgänglig för vissa routermodeller): Den dagliga versionen som innehåller de senaste uppdateringarna.
3. Klicka på knappen **Download**.
