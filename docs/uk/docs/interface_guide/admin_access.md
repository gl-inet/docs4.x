# Доступ до адміністрування {#admin-access}

**Примітка**: Цю сторінку додано в прошивці v4.9.

---

У лівому меню вебпанелі адміністрування відкрийте **SECURITY** -> **Admin Access**.

На цій сторінці можна налаштувати різні параметри безпеки, щоб захистити мережу й маршрутизатор від несанкціонованого доступу.

## Контроль доступу {#access-control}

Розділ **Access Control**, який у прошивці v4.7 і раніших версіях називається **Local Access Control**, керує доступом до різних інтерфейсів адміністрування маршрутизатора.

Він дає змогу запобігти спробам сканування та вторгнення через стандартний порт і уникнути мережевих проблем, спричинених конфліктами портів.

**Примітка**: Якщо ви змінили номер порту в прошивці, для доступу до панелі адміністрування потрібно вказати правильний номер порту. Якщо ви забули його, скиньте налаштування маршрутизатора, щоб відновити стандартний номер порту.

![Контроль доступу](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_access/access_control_4.8.png){class="glboxshadow"}

### Панель адміністрування {#admin-panel}

- **HTTP Port**: За замовчуванням — 80. Використовується для незашифрованого доступу до вебпанелі адміністрування через HTTP.

- **HTTPS Port**: За замовчуванням — 443. Використовується для захищеного доступу до вебпанелі адміністрування через HTTPS.

- **Force HTTPS**: Якщо ввімкнено, доступ до вебпанелі адміністрування здійснюється обов’язково через захищене з’єднання HTTPS.

- **Auto-Logout Time**: За замовчуванням — 5 хвилин. З міркувань безпеки сеанси адміністрування автоматично завершуються після цього періоду бездіяльності. Час автоматичного виходу можна змінити в межах від 1 хвилини до 3 годин.

### LuCI {#luci}

> Примітка: Перш ніж налаштовувати контроль доступу до LuCI, установіть LuCI на сторінці **Advanced Settings**.

- **HTTP Port**: За замовчуванням — 8080. Використовується для незашифрованого доступу до інтерфейсу LuCI через HTTP.

- **HTTPS Port**: За замовчуванням — 8443. Використовується для захищеного доступу до інтерфейсу LuCI через HTTPS.

- **Force HTTPS**: Якщо ввімкнено, доступ до інтерфейсу LuCI здійснюється обов’язково через захищене з’єднання HTTPS.

### SSH {#ssh}

- **Enable SSH**: Визначає, чи дозволено доступ до маршрутизатора через SSH. Увімкнено за замовчуванням.

- **SSH Port**: За замовчуванням — 22. Цей порт використовується для доступу до маршрутизатора через SSH.

### Заборонений порт {#prohibited-port}

Якщо ви вкажете номер порту, який збігається із зарезервованим портом (або портом, зарезервованим для певних служб браузерами чи мережевими правилами), з’явиться повідомлення «This port is forbidden by the browser».

## Контроль віддаленого доступу {#remote-access-control}

Після ввімкнення віддаленого доступу можна дозволити його лише з певних місць. Наприклад, можна дозволити віддалений доступ до домашніх пристроїв лише з офісу, дещо обмеживши зручність заради кращого захисту.

![Контроль віддаленого доступу](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_access/security_remote_access_control.png){class="glboxshadow"}

- **Allow Ping from WAN**: У разі мережевих проблем дозвіл на Ping із порту WAN допомагає користувачам або адміністраторам мережі перевірити, чи правильно підключено маршрутизатор, а також визначити мережеву затримку та втрати пакетів.

- **HTTPS Remote Access**: Протокол HTTPS переважно використовується для обміну даними між веббраузерами та вебсерверами й забезпечує захищене передавання даних. Його можна використовувати для безпечного та надійного передавання даних під час віддаленого керування серверами або доступу до вебзастосунків через браузер.

- **SSH Remote Access**: Протокол SSH переважно використовується для безпечного доступу до віддалених комп’ютерів і серверів, керування ними та передавання файлів. Якщо потрібно віддалено входити на сервери через командний рядок або скрипти для адміністрування системи, передавання файлів чи інших операцій, SSH дає змогу створити захищений тунель і забезпечити безпеку та конфіденційність передавання даних.

- **Allow Remote Access from Specific IPs**: Ця функція використовується разом із **Allow Ping from WAN**, **HTTPS Remote Access** або **SSH Remote Access**. Можна додати кілька визначених IP-адрес, щоб віддалено керувати маршрутизаторами з пристроїв із цими IP-адресами.

## Відкриття портів на маршрутизаторі {#open-ports-on-router}

Щоб служби маршрутизатора, наприклад вебслужба або FTP, були доступні ззовні, на маршрутизаторі потрібно відкрити відповідні порти.

Щоб відкрити порт, натисніть **Add**.

![Відкриття портів на маршрутизаторі](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_access/open_ports_on_router.png){class="glboxshadow"}

![Додавання відкритого порту](https://static.gl-inet.com/docs/router/en/4/interface_guide/admin_access/add_new_open_port.png){class="glboxshadow"}

- **Protocol:** Виберіть протокол: `TCP/UDP`, `TCP` або `UDP`.

- **Port:** Введіть номер порту, який потрібно відкрити.

- **Description:** Додайте опис правила (необов’язково).

- **Enable:** Увімкніть або вимкніть це правило за допомогою перемикача.
