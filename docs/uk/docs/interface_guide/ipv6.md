# IPv6 {#ipv6}

IPv6 (Internet Protocol version 6, інтернет-протокол версії 6) — найновіша версія інтернет-протоколу, розроблена на заміну IPv4. Вона надає значно більше унікальних IP-адрес, розв’язує проблему вичерпання адрес IPv4 та підтримує зростання кількості підключених пристроїв у світі.

У меню ліворуч у вебпанелі адміністрування перейдіть до **NETWORK** -> **IPv6**.

На цій сторінці можна ввімкнути та налаштувати IPv6 на маршрутизаторі.

![Налаштування IPv6](https://static.gl-inet.com/docs/router/en/4/interface_guide/ipv6/ipv6.png){class="glboxshadow"}

Коли IPv6 увімкнено, інтерфейси WAN, зокрема Ethernet, отримують IPv6-адреси через DHCPv6. Також можна вручну змінити IPv6-адресу на сторінці налаштувань Ethernet.

**Примітка**: Деякі функції (наприклад, міжмережевий екран, GoodCloud і OpenVPN DCO) ще не підтримують IPv6. Їх одночасне використання з IPv6 імовірно спричинить проблеми зі з’єднанням.

Увімкніть **Enable IPv6**, виберіть режим основної мережі та спосіб отримання DNS-серверів, а потім натисніть **Apply**.

![Увімкнення IPv6](https://static.gl-inet.com/docs/router/en/4/interface_guide/ipv6/ipv6_enabled.png){class="glboxshadow"}

**Mode**: Доступні чотири режими: **Native**, **Passthrough**, **NAT6** і **Static IPv6**.

- Native: Застосовується, коли маршрутизатор безпосередньо отримує публічну IPv6-адресу та автоматично призначає IPv6-адреси підключеним пристроям. Цей режим задовольняє потреби більшості користувачів у доступі через IPv6.

- Passthrough: Застосовується, коли пакети IPv6 потрібно передавати безпосередньо, без оброблення або перетворення. Наприклад, певні мережеві застосунки чи служби можуть потребувати повного збереження вмісту пакетів IPv6 для подальшого оброблення або аналізу. Технічні фахівці використовують це для налагодження мережі або аналізу безпеки.

- NAT6: Підходить для сценаріїв, де маршрутизатор використовується як шлюз керування, який призначає динамічні внутрішні IPv6-адреси кожному пристрою мережі. У цьому режимі кінцеві пристрої підключаються через оптичний мережевий термінал і отримують IPv6-адресу локальної мережі.

- Static IPv6: Підходить для пристроїв або служб, яким потрібна фіксована IPv6-адреса, наприклад серверів чи мережевих принтерів. Пристрій завжди використовує ту саму IPv6-адресу, що спрощує керування та доступ.

**DNS acquisition method**: Визначає, як маршрутизатор отримує адреси DNS-серверів IPv6. Доступні два варіанти: **Automatic** і **Manual**.

- Automatic: Маршрутизатор отримуватиме адреси DNS-серверів IPv6 динамічно, наприклад через DHCPv6.

- Manual: Уведіть власні адреси DNS-серверів IPv6. Оскільки DNS перетворює доменні імена на відповідні IP-адреси, ручне налаштування DNS-серверів може спричинити збої DNS-пошуку. Використовуйте цей спосіб обережно.
