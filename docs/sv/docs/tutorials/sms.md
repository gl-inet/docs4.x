# SMS {#sms}

GL.iNets mobilroutrar har ett inbyggt modem som stöder sändning och mottagning av SMS när ett SIM-kort har satts i.

**Obs!** Funktionen fungerar endast på GL.iNet 4G-/5G-modeller med den ursprungliga 4G LTE-/5G NR-modulen. Den stöds inte på andra moduler eller USB-moduler.

## Snabbkonfiguration {#quick-setup}

GL-X3000 (Spitz AX) används som exempel.

1. Följ [den här länken](../interface_guide/internet_cellular.md) för att först konfigurera mobilroutern.

2. Logga in på routerns webbadministrationspanel och gå till **INTERNET** -> **Cellular**. Klicka på kuvertikonen i det övre högra hörnet.

    ![sms](https://static.gl-inet.com/docs/router/en/4/tutorials/sms/sms.png){class="glboxshadow gl-90-desktop"}

3. SMS-sidan öppnas. Där kan du visa mottagna meddelanden eller skriva nya.

    ![sms receive](https://static.gl-inet.com/docs/router/en/4/tutorials/sms/sms_receive.png){class="glboxshadow gl-90-desktop"}

    Klicka på ett meddelande för att visa informationen.

    ![sms detail](https://static.gl-inet.com/docs/router/en/4/tutorials/sms/sms_detail.png){class="glboxshadow"}

    Klicka på knappen **Send Message** i det övre högra hörnet för att skriva ett nytt meddelande.

    ![sms new message](https://static.gl-inet.com/docs/router/en/4/tutorials/sms/sms_new_message1.png){class="glboxshadow"}

    ![sms new message](https://static.gl-inet.com/docs/router/en/4/tutorials/sms/sms_new_message2.png){class="glboxshadow"}

    * Recipient

        Välj den internationella landskoden och ange numret.

    * From Modem(SIM)

        Välj vilket SIM-kort meddelandet ska skickas från.

    * SMS Contents

        Varje SMS kan innehålla högst 160 tecken.
