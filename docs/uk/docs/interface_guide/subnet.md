# Підмережі {#subnet}

**Примітка**: наразі ця сторінка доступна на Flint 4 (GL-BE14000). Вона з’явиться на інших моделях із прошивкою v4.10.

---

У лівому меню вебпанелі адміністрування відкрийте **NETWORK** -> **Subnet**.

На цій сторінці можна централізовано налаштовувати мережі **Main Network**, **Guest Network**, **IoT Network** і власні **VLAN Networks** та керувати ними. Ви можете створювати кілька підмереж і керувати ними для ізоляції різних типів пристроїв або трафіку.

## Основна мережа {#main-network}

**Main Network** — мережа, до якої пристрій підключається через основну мережу Wi-Fi або кабель Ethernet.

У розділі Main Network відображаються стан усіх інтерфейсів, VLAN ID, IP-адреса маршрутизатора та DHCP Range.

![Основна мережа](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/main-network-1.png){class="glboxshadow"}

Натисніть **Edit** у нижньому правому куті, щоб налаштувати основну мережу.

![Редагування основної мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/main-network-2.png){class="glboxshadow"}

Сторінка конфігурації містить Basic settings, DHCP server settings і Address Reservation.

### Основні налаштування {#basic-settings}

Можна задати підмережу в межах приватних діапазонів IPv4: `192.168.0.0/16`, `172.16.0.0/12`, `10.0.0.0/8`.

![Основні налаштування головної мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/main-network-basic.png){class="glboxshadow" width=650}

- **Router IP Address**

    Цю адресу вводять у рядку адреси браузера, щоб відкрити сторінку адміністрування маршрутизатора.

    За замовчуванням використовується **192.168.8.1**. Змініть адресу, якщо вона конфліктує з вашою мережею.

- **Netmask**

    За замовчуванням використовується **255.255.255.0**. Якщо потрібна більша підмережа з більшою кількістю IP-адрес, виберіть **255.255.0.0**.

- **VLAN ID**

    VLAN ID основної мережі за замовчуванням — **1**. Його змінити не можна.

- **AP Isolation**

    Можна ізолювати клієнтські пристрої в окремому сегменті мережі. Вони не зможуть обмінюватися даними з іншими пристроями в тій самій мережі.

### Сервер DHCP {#dhcp-server}

**DHCP Server** увімкнено за замовчуванням. Сервер DHCP автоматично призначає IP-адреси та інші параметри зв’язку кожному клієнтському пристрою.

Якщо сервер DHCP вимкнено, мережеві параметри клієнтських пристроїв потрібно налаштувати вручну. Як вручну налаштувати статичну IP-адресу, описано [тут](../tutorials/manually_configure_static_ip.md).

Можна змінити початкову й кінцеву IP-адреси відповідно до потреб, наприклад у разі розширення або скорочення мережі, конфліктів IP-адрес чи зміни діапазону маски підмережі.

![Сервер DHCP основної мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/main-network-dhcp-server-1.png){class="glboxshadow" width=650}

За потреби натисніть **Advanced** для додаткового налаштування.

![Додаткові налаштування DHCP основної мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/main-network-dhcp-server-2.png){class="glboxshadow" width=650}

![Параметри DHCP основної мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/main-network-dhcp-server-3.png){class="glboxshadow" width=650}

- **Lease Time**: період, протягом якого IP-адреса, призначена DHCP, є дійсною для пристрою.

- **Gateway**: пристрій, який маршрутизує трафік між локальною мережею та зовнішніми мережами, зокрема інтернетом.

- **DNS Server 1**: основний сервер для перетворення доменних імен на IP-адреси.

- **DNS Server 2**: додатковий сервер для визначення адрес доменів, коли основний DNS-сервер недоступний.

- **LPR Server** (Line Printer Remote Server): сервіс, який керує завданнями друку та дозволяє мережевим пристроям надсилати запити друку на віддалені принтери. Можна налаштувати кілька портів принтерів LPR.

### Резервування адрес {#address-reservation}

Якщо зарезервувати IP-адресу для клієнта в LAN, він отримуватиме ту саму адресу під час кожного звернення до сервера DHCP маршрутизатора. Зарезервуйте адреси для комп’ютерів або серверів, яким потрібні постійні IP-параметри.

**Примітка:** після налаштування клієнти повинні повторно підключитися до маршрутизатора, щоб застосувати зміни.

Натисніть **Add**, щоб зарезервувати IP-адресу.

![Додавання резервування адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/address-reservation-1.png){class="glboxshadow" width=650}

З’явиться спливне вікно.

![Резервування IP-адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/address-reservation-2.png){class="glboxshadow" width=650}

Виберіть **MAC** із розкривного списку. Відповідну доступну **IP**-адресу буде підставлено автоматично. За потреби введіть **hostname** і власне **name** для зручної ідентифікації. Потім натисніть **Submit**.

![Параметри резервування адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/address-reservation-3.png){class="glboxshadow" width=650}

Після додавання нового резервування IP-адреси сторінка матиме вигляд, показаний нижче. Це означає, що налаштування успішне.

![Зарезервовані адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/address-reservation-4.png){class="glboxshadow" width=650}

## Гостьова мережа {#guest-network}

**Guest Network** надає окрему мережу Wi-Fi для гостей. Вона ізольована від основної мережі, що підвищує безпеку та забезпечує зручний доступ до інтернету.

**Примітка**: деякі моделі (наприклад, GL-MT5000, GL-MT2500/GL-MT2500A) не підтримують Wi-Fi, тому налаштування Guest Network недоступні в їхній вебпанелі адміністрування.

У розділі Guest Network відображаються стан інтерфейсу, VLAN ID, Gateway і DHCP Range.

![Гостьова мережа](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/guest-network-1.png){class="glboxshadow"}

Натисніть **Edit** у нижньому правому куті. Панель налаштування гостьової мережі відкриється праворуч на сторінці.

![Редагування гостьової мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/guest-network-2.png){class="glboxshadow"}

Сторінка конфігурації містить Basic settings і DHCP server settings.

### Основні налаштування {#basic-settings_1}

Можна задати підмережу в межах приватних діапазонів IPv4: `192.168.0.0/16`, `172.16.0.0/12`, `10.0.0.0/8`.

![Основні налаштування гостьової мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/guest-network-basic.png){class="glboxshadow" width=650}

- **Gateway**

    **Шлюз за замовчуванням** для гостьової мережі — **192.168.9.1**. Якщо він конфліктує з локальною мережею, задайте інше значення.

- **Netmask**

    За замовчуванням використовується **255.255.255.0**. Якщо потрібна більша підмережа з більшою кількістю IP-адрес, виберіть **255.255.0.0**.

- **VLAN ID**

    VLAN ID гостьової мережі за замовчуванням — **9**. За потреби його можна змінити.

- **AP Isolation**

    Ця функція доступна починаючи з прошивки v4.5.

    Можна ізолювати клієнтські пристрої в окремому сегменті мережі. Вони не зможуть обмінюватися даними з іншими пристроями в тій самій мережі.

- **WAN Access Control**

    WAN Access Control керує доступом локальної підмережі до мереж на боці WAN, зокрема інтернету та інших підмереж WAN.

    Доступні три режими контролю доступу до WAN:

    - **Unrestricted**: дозволяє цій підмережі без обмежень отримувати доступ до інтернету та інших підмереж на боці WAN.

    - **Block WAN Subnet**: блокує доступ до інших підмереж на боці WAN. Доступ до інтернету залишається дозволеним.

    - **Block Internet Access**: блокує весь вихідний доступ, зокрема до інтернету та підмереж на боці WAN.

## Мережі VLAN {#vlan-networks}

Угорі головної сторінки можна створити додаткові **мережі VLAN** для ізоляції різних типів пристроїв або трафіку гостей.

**DHCP Server** увімкнено за замовчуванням. Сервер DHCP автоматично призначає IP-адреси та інші параметри зв’язку кожному клієнтському пристрою.

Якщо сервер DHCP вимкнено, мережеві параметри клієнтських пристроїв потрібно налаштувати вручну. Як вручну налаштувати статичну IP-адресу, описано [тут](../tutorials/manually_configure_static_ip.md).

Можна змінити початкову й кінцеву IP-адреси відповідно до потреб, наприклад у разі розширення або скорочення мережі, конфліктів IP-адрес чи зміни діапазону маски підмережі.

![Сервер DHCP мережі VLAN](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/vlan-networks-dhcp-server-1.png){class="glboxshadow" width=650}

За потреби натисніть **Advanced** для додаткового налаштування.

![Додаткові налаштування DHCP мережі VLAN](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/vlan-networks-dhcp-server-2.png){class="glboxshadow" width=650}

![Параметри DHCP мережі VLAN](https://static.gl-inet.com/docs/router/en/4/interface_guide/subnet/vlan-networks-dhcp-server-3.png){class="glboxshadow" width=650}

- **Lease Time**: період, протягом якого IP-адреса, призначена DHCP, є дійсною для пристрою.

- **Gateway**: пристрій, який маршрутизує трафік між локальною мережею та зовнішніми мережами, зокрема інтернетом.

- **DNS Server 1**: основний сервер для перетворення доменних імен на IP-адреси.

- **DNS Server 2**: додатковий сервер для визначення адрес доменів, коли основний DNS-сервер недоступний.

- **LPR Server** (Line Printer Remote Server): сервіс, який керує завданнями друку та дозволяє мережевим пристроям надсилати запити друку на віддалені принтери. Можна налаштувати кілька портів принтерів LPR.

Після налаштування нова мережа VLAN з’явиться на поточній сторінці з відомостями про підмережу.
