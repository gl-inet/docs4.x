# IGMP Snooping {#igmp-snooping}

Öppna **NETWORK** -> **IGMP Snooping** på vänster sida i webbadministrationspanelen.

Aktivera IGMP snooping för att använda routerns multicast-funktion.

IGMP Snooping lyssnar på IGMP-protokollpaket, hämtar relevant information samt upprättar och underhåller en multicast-vidarebefordringstabell på lager 2. Multicast-gruppdata vidarebefordras sedan endast till värdar som har anslutit till gruppen, medan andra värdar inte kan ta emot dessa data.

**Obs!** IGMPv3 är kompatibelt med v1 och v2. Använd v3 som standard och byt version om problem uppstår.
