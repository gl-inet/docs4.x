# 古いルーターをGL.iNetルーターに交換した後、インターネットに接続できない場合の対処方法 {#what-should-i-do-if-i-have-no-internet-after-replacing-the-old-router-with-a-glinet-router}

古いルーターをGL.iNetルーターに交換した後にインターネットにアクセスできない場合は、WANポートをモデムに接続しても、新しいルーターがIPアドレス（DHCPまたはPPPoE）を取得できていない可能性があります。

インターネットサービスプロバイダーが**MACバインディング**を有効にしている可能性があります。この場合、以前のルーターのMACアドレスでのみネットワークに接続できます。

この問題を解決するには、次の方法を試してください。

- 古いルーターのMACアドレスを新しいGL.iNetルーターにクローンします。詳しくは[こちら](./internet_connection_troubleshooting.md#q2-when-should-i-clone-a-mac-address)を参照してください。
- モデムを再起動します。問題が解決しない場合は、モデムの電源を30分間切ってから、再度電源を入れてください。
- インターネットサービスプロバイダーに連絡し、モデムをリセットしてもらってください。
