# Гостьова мережа {#guest-network}

Починаючи з прошивки v4.5, налаштування гостьової мережі відокремлено від [LAN](lan.md).

У лівому меню вебпанелі адміністрування відкрийте **NETWORK** -> **Guest Network**.

На цій сторінці можна створити окрему мережу Wi-Fi для гостей. Вона ізольована від основної мережі, що підвищує безпеку та забезпечує зручний доступ до інтернету.

**Примітка**: деякі моделі (наприклад, GL-MT5000, GL-MT2500/GL-MT2500A) не підтримують Wi-Fi, тому налаштування Guest Network недоступні в їхній вебпанелі адміністрування.

Сторінка містить два розділи: Basic Settings і DHCP Server Settings.

## Основні налаштування {#basic-settings}

Можна задати підмережу в межах приватних діапазонів IPv4: `192.168.0.0/16`, `172.16.0.0/12`, `10.0.0.0/8`.

![Основні налаштування гостьової мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/guest_network/guest_network_1.png){class="glboxshadow"}

- **Gateway**

    **Шлюз за замовчуванням** для гостьової мережі — **192.168.9.1**. Якщо він конфліктує з локальною мережею, задайте інше значення.

- **Netmask**

    За замовчуванням використовується **255.255.255.0**. Якщо потрібна більша підмережа з більшою кількістю IP-адрес, виберіть **255.255.0.0**.

- **AP Isolation**

    Ця функція доступна починаючи з прошивки v4.5.

    Можна ізолювати клієнтські пристрої в окремому сегменті мережі. Вони не зможуть обмінюватися даними з іншими пристроями в тій самій мережі.

- **Block WAN Subnets**

    Ця функція доступна починаючи з прошивки v4.8.

    Після увімкнення гостьова мережа не матиме доступу до мережі вищого рівня та її підмережі.

## Сервер DHCP {#dhcp-server}

Коли гостьову мережу увімкнено, її сервер DHCP також буде увімкнено.

Сервер DHCP автоматично призначає IP-адреси та інші параметри зв’язку кожному клієнтському пристрою, підключеному до гостьової мережі. Якщо сервер DHCP вимкнено, мережеві параметри клієнтських пристроїв потрібно налаштувати вручну. Як вручну налаштувати статичну IP-адресу, описано [тут](../tutorials/manually_configure_static_ip.md).

Можна змінити початкову й кінцеву IP-адреси відповідно до потреб, наприклад у разі розширення або скорочення мережі, конфліктів IP-адрес чи зміни діапазону маски підмережі.

![Сервер DHCP гостьової мережі](https://static.gl-inet.com/docs/router/en/4/interface_guide/guest_network/guest_network_2.png){class="glboxshadow"}

За потреби натисніть **Advanced** для додаткового налаштування.

![Відкриття додаткових налаштувань DHCP](https://static.gl-inet.com/docs/router/en/4/interface_guide/guest_network/dhcp_advanced1.png){class="glboxshadow"}

![Додаткові налаштування DHCP](https://static.gl-inet.com/docs/router/en/4/interface_guide/guest_network/dhcp_advanced2.png){class="glboxshadow"}

- **Lease Time**: період, протягом якого IP-адреса, призначена DHCP, є дійсною для пристрою.

- **Gateway**: пристрій, який маршрутизує трафік між гостьовою мережею та зовнішніми мережами, зокрема інтернетом.

- **DNS Server 1**: основний сервер для перетворення доменних імен на IP-адреси.

- **DNS Server 2**: додатковий сервер для визначення адрес доменів, коли основний DNS-сервер недоступний.

- **LPR Server**: Line Printer Remote Server — сервіс, який керує завданнями друку та дозволяє мережевим пристроям надсилати запити друку на віддалені принтери. Можна налаштувати кілька портів принтерів LPR.
