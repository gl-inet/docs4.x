# Een apparaat met alleen Ethernet via een GL.iNet-router met wifi verbinden {#how-to-connect-an-ethernet-only-device-to-wi-fi-with-a-glinet-router}

Als je apparaat alleen Ethernet ondersteunt maar verbinding met een draadloos netwerk moet maken, kan een GL.iNet-router deze verbinding tot stand brengen.

Een GL.iNet-router kan als Ethernet-naar-wifi-brug dienen voor apparaten met alleen een bekabelde verbinding. Stel de router hiervoor in als Repeater.

Sluit je apparaat aan op de LAN-poort van de router en stel vervolgens [repeater](../interface_guide/internet_repeater.md) in.
