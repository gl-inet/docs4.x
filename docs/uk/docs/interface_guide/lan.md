# LAN {#lan}

У меню ліворуч у вебпанелі адміністрування перейдіть до **NETWORK** -> **LAN**.

LAN — мережа, до якої пристрій підключається через основну мережу Wi-Fi або кабелем Ethernet.

Сторінка містить основні налаштування, налаштування DHCP-сервера та резервування адрес.

## Основні налаштування {#basic-settings}

Можна задати підмережу в межах приватних діапазонів IPv4-адрес: `192.168.0.0/16`, `172.16.0.0/12`, `10.0.0.0/8`.

![Основні налаштування LAN](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/basic_settings.jpg){class="glboxshadow"}

- **Router IP Address**

    Цю адресу потрібно ввести в адресний рядок браузера, щоб відкрити сторінку адміністрування маршрутизатора.

    За замовчуванням — **192.168.8.1**. Якщо адреса конфліктує з вашою мережею, змініть її.

- **Netmask**

    За замовчуванням — **255.255.255.0**. Якщо потрібна більша підмережа з більшою кількістю IP-адрес, виберіть **255.255.0.0**.

- **AP Isolation**

    Можна ізолювати клієнтські пристрої в окремому сегменті мережі. Вони не зможуть обмінюватися даними з іншими пристроями в тій самій мережі.

## DHCP-сервер {#dhcp-server}

**DHCP Server** увімкнено за замовчуванням. DHCP-сервер автоматично призначає IP-адреси та інші параметри зв’язку кожному клієнтському пристрою.

Якщо DHCP-сервер вимкнено, налаштуйте мережеві параметри клієнтських пристроїв вручну. Інструкції з налаштування статичної IP-адреси наведено [тут](../tutorials/manually_configure_static_ip.md).

Можна змінити початкову та кінцеву IP-адреси відповідно до потреб, наприклад у разі розширення або зменшення мережі, конфліктів IP-адрес чи зміни діапазону маски підмережі.

![Основні налаштування DHCP-сервера](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/dhcp_server.png){class="glboxshadow"}

За потреби натисніть **Advanced**, щоб виконати додаткові налаштування.

![Відкриття додаткових параметрів DHCP](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/dhcp_advanced_1.png){class="glboxshadow"}

![Додаткові параметри DHCP-сервера](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/dhcp_advanced_2.png){class="glboxshadow"}

- **Lease Time**: Термін дії IP-адреси, призначеної пристрою DHCP-сервером.

- **Gateway**: Пристрій, який спрямовує трафік між локальною мережею та зовнішніми мережами, наприклад інтернетом.

- **DNS Server 1**: Основний сервер, який перетворює доменні імена на IP-адреси.

- **DNS Server 2**: Додатковий сервер для перетворення доменних імен, якщо основний DNS-сервер недоступний.

- **LPR Server** (Line Printer Remote Server): Служба, яка керує завданнями друку та дає змогу мережевим пристроям надсилати запити на друк віддаленим принтерам. Можна налаштувати кілька портів принтерів LPR.

## Резервування адрес {#address-reservation}

Якщо зарезервувати IP-адресу для клієнта в LAN, він щоразу отримуватиме ту саму адресу під час звернення до DHCP-сервера маршрутизатора. Резервовані IP-адреси можна призначати комп’ютерам або серверам, яким потрібні постійні налаштування IP.

**Примітка:** Щоб налаштування набули чинності, налаштовані клієнти мають повторно підключитися до маршрутизатора.

Натисніть **Add**, щоб зарезервувати IP-адресу.

![Додавання резервування адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/address_reservation_1.png){class="glboxshadow"}

З’явиться спливне вікно.

![Вікно резервування адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/address_reservation_2.png){class="glboxshadow"}

Виберіть **MAC** із розкривного списку. Відповідне поле **IP** буде заповнено автоматично. Задайте зрозумілу назву та натисніть **Submit**.

![Вибір MAC-адреси та IP-адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/address_reservation_3.png){class="glboxshadow"}

Після додавання нового резервування IP-адреси сторінка матиме такий вигляд, що означає успішне налаштування.

![Успішне резервування IP-адреси](https://static.gl-inet.com/docs/router/en/4/interface_guide/lan/address_reservation_4.jpg){class="glboxshadow"}
