# Análisis de seguridad

**Nota**: Esta función se incorporó en el firmware v4.11.

---

En el menú lateral izquierdo del panel de administración web, vaya a **SECURITY** -> **Security Scan**.

Security Scan realiza una comprobación de seguridad del router. Evalúa los ajustes de seguridad y genera una puntuación junto con alertas de riesgo y sugerencias de optimización. Puede ajustar la configuración según los resultados para mejorar la seguridad del router.

El análisis de seguridad se inicia automáticamente al abrir esta página. Comprueba distintos elementos, como Wi-Fi Security, WAN Ping, Remote SSH, Port Forwarding y DPI Content Protection. También puede hacer clic en el icono de puntuación para restablecer y volver a ejecutar el análisis. Cuando termine, podrá consultar las métricas principales.

![Security Scan](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/security_scan.png){class="glboxshadow"}

- **Score**: Puntuación general de seguridad de la configuración del router.

- **Risks**: Problemas de seguridad críticos que deben solucionarse.

- **Suggestions**: Prácticas recomendadas para mejorar la seguridad; no son correcciones obligatorias.

- **Safe**: Elementos que han superado la comprobación de seguridad.

Puede consultar los resultados detallados mediante las dos pestañas siguientes.

- **Risk & Suggestion**

    Haga clic en **Risk & Suggestion** para ver los riesgos y las sugerencias de optimización.

    ![Risk & Suggestion](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/risk_suggestion.png){class="glboxshadow"}

    Para mejorar la seguridad del router, puede hacer clic en **Go to Settings** junto a cada elemento para acceder directamente a la página de configuración correspondiente y ajustar sus opciones.

- **Safe**

    Haga clic en **Safe** para ver todos los elementos que han superado la comprobación de seguridad.

    ![safe](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/safe.png){class="glboxshadow"}
