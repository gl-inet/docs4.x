# Plug-ins {#plug-ins}

Ga links in het webbeheerpaneel naar **APPLICATIONS** -> **Plug-ins**.

Op deze pagina kun je OpenWrt-pakketten beheren en naar behoefte installeren of verwijderen.

We raden aan op **Update** te klikken voordat je plug-ins van derden gebruikt. **Werk vooraf geïnstalleerde plug-ins uit de officiële GL.iNet-firmware niet bij**, zoals `nginx`, `adguard home` en `tailscale`.

![Plug-ins](https://static.gl-inet.com/docs/router/en/4/interface_guide/plug-ins/plug-ins.png){class="glboxshadow"}

Handmatig geïnstalleerde plug-ins van derden kunnen worden bijgewerkt. GL.iNet is niet aansprakelijk voor beveiligingsproblemen door dergelijke plug-ins. Neem bij vragen contact op met de maker.
