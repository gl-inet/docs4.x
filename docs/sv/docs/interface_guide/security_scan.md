# Security Scan {#security-scan}

**Note**: This feature was introduced in firmware v4.11.

---

Öppna **SECURITY** -> **Security Scan** på vänster sida i webbadministrationspanelen.

Security Scan kontrollerar routerns säkerhetsinställningar och ger en säkerhetspoäng, riskvarningar och optimeringsförslag. Anpassa konfigurationen efter resultatet.

En kontroll startar automatiskt när sidan öppnas och granskar Wi-Fi Security, WAN Ping, Remote SSH, Port Forwarding och DPI Content Protection. Klicka på poängikonen för att återställa och köra om kontrollen.

![Security Scan](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/security_scan.png){class="glboxshadow"}

- **Score**: Övergripande säkerhetspoäng för routerkonfigurationen.

- **Risks**: Critical security issues that require remediation.

- **Suggestions**: Recommended best practices to improve security, not mandatory fixes.

- **Safe**: Poster som klarar säkerhetskontrollen.

Visa detaljerade resultat via de två flikarna nedan.

- **Risk & Suggestion**

    Klicka på **Risk & Suggestion** för risker och optimeringsförslag.

    ![Risk & Suggestion](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/risk_suggestion.png){class="glboxshadow"}

    Klicka på **Go to Settings** bredvid en post för att öppna motsvarande konfigurationssida.

- **Safe**

    Klicka på **Safe** för alla poster som klarade kontrollen.

    ![safe](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/safe.png){class="glboxshadow"}
