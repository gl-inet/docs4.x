# Як вручну оновити прошивку маршрутизатора або повернутися до ранішої версії (з v4.x на v4.x)? {#how-to-manually-upgrade-or-downgrade-your-router-firmware-from-v4x-to-v4x}

У цьому посібнику описано, **як вручну оновити прошивку маршрутизатора або повернутися до ранішої версії (з v4.x на v4.x)**. Кроки ручного встановлення новішої та ранішої прошивки однакові.

!!! Note "Про оновлення та повернення до ранішої прошивки"

    **Оновлення:** Маршрутизатори GL.iNet із прошивкою 4.x не підтримують автоматичне оновлення.

    Коли доступна нова прошивка, після входу в панель адміністрування з’явиться "Upgrade Reminder". Натисніть **Upgrade**, щоб установити найновішу версію з цього повідомлення. Щоб установити конкретну версію, виконайте наведені нижче дії для ручного оновлення.

    **Повернення до ранішої версії:** Можна встановити ранішу прошивку для усунення певних проблем.

## 1. Перевірте, чи встановлено найновішу прошивку (лише для оновлення) {#1-check-if-your-router-is-running-the-latest-firmware-version-only-for-upgrade}

1. У веббраузері відкрийте адресу панелі адміністрування маршрутизатора, наприклад 192.168.8.1, і ввійдіть.
2. У меню ліворуч виберіть **SYSTEM** > **Upgrade**.

## 2. Завантажте файл прошивки {#2-download-the-firmware-file}

1. Знайдіть і виберіть модель маршрутизатора в рядку пошуку [центру завантаження прошивок](https://dl.gl-inet.com/).
2. На вкладці **Stable** або іншій вкладці виберіть **DOWNLOAD FOR COMMON UPGRADE AND U-BOOT** біля потрібної версії прошивки.

## 3. Завантажте прошивку на маршрутизатор {#3-upload-the-firmware}

Нижче наведено завантаження прошивки через панель адміністрування маршрутизатора. Для використання мобільного застосунку GL.iNet [завантажте застосунок](https://www.gl-inet.com/app/) і налаштуйте його.

1. У веббраузері відкрийте адресу панелі адміністрування маршрутизатора, наприклад 192.168.8.1, і ввійдіть.
2. (Необов’язково) Щоб створити резервну копію поточних налаштувань, виконайте такі дії.

    ??? "Резервне копіювання поточних налаштувань"

        a. У меню ліворуч виберіть **SYSTEM** > **Advanced Settings**.

        b. Натисніть посилання або кнопку **Go To LuCI**, щоб відкрити сторінку входу в LuCI.

        c. Уведіть пароль адміністратора та натисніть **Log in**.

        d. Виберіть **System** > **Backup / Flash Firmware**.

        e. У розділі **Backup** натисніть **Generate archive**. Файл із поточними налаштуваннями буде завантажено на пристрій.

        **Цей файл підходить лише для версії прошивки, установленої на час резервного копіювання, і не підходить для інших версій.**

3. У меню ліворуч виберіть **SYSTEM** > **Upgrade**.
4. Натисніть **Local Upgrade** і виберіть завантажений файл.
5. Під час оновлення, щоб зберегти поточні налаштування, наприклад пароль адміністратора, увімкніть **Keep Settings**. Під час повернення до ранішої прошивки НЕ вмикайте **Keep Settings**.
6. Натисніть **Install**.

**Примітка:** Не вимикайте живлення маршрутизатора під час оновлення. Після завершення з’явиться сторінка входу в маршрутизатор.

Якщо під час оновлення прошивки налаштування втрачено, відновіть їх.

Якщо цей спосіб не працює, спробуйте оновити прошивку через [U-boot](../faq/debrick.md).
