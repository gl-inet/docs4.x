# OpenVPN, TCP vs UDP {#openvpn-tcp-vs-udp}

GL.iNetルーターのOpenVPNサーバーは、TCPとUDPの両方のプロトコルをサポートしています。両者の違いは何でしょうか？

TCPは信頼性が高い一方、速度は遅くなります。UDPは高速ですが、信頼性は低くなります。

アプリケーションを正常に動作させるために低遅延で途切れないデータ転送が必要な場合は、UDPが適しています。それ以外の場合は、転送中にデータを失うことなく送信できる、信頼性の高いTCPが適しています。

UDPはゲーム、ストリーミング、VoIPサービスの利用に適しています。TCPはメール、Webブラウジング、ファイル転送に適しています。

まずUDPプロトコルを試し、接続の不安定、パケットロス、その他の信頼性に関する問題が発生した場合にのみTCPに切り替えることをおすすめします。
