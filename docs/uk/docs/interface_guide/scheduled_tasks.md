# Заплановані завдання {#scheduled-tasks}

У меню ліворуч у вебпанелі адміністрування перейдіть до **SYSTEM** -> **Scheduled Tasks**.

Scheduled Tasks дає змогу налаштувати щоденні розклади основних операцій: увімкнення й вимкнення світлодіодних індикаторів, перезавантаження маршрутизатора, увімкнення й вимкнення Wi-Fi та перемикання рівня потужності передавання TX.

**Примітка**: Перед використанням цієї функції синхронізуйте час у розділі [Часовий пояс](time_zone.md). Якщо пристрій вимкнений у запланований час, завдання не буде виконано.

## Розклад роботи світлодіодних індикаторів {#led-display-schedule}

Ця функція дає змогу налаштувати розклад увімкнення та вимкнення світлодіодного індикатора маршрутизатора.

Увімкніть функцію, задайте час увімкнення та вимкнення, виберіть дні тижня, коли діє розклад, і натисніть Apply.

![Розклад роботи світлодіодних індикаторів](https://static.gl-inet.com/docs/router/en/4/interface_guide/scheduled_tasks/led_display_schedule.png){class="glboxshadow gl-90-desktop"}

На моделях із сенсорним екраном (наприклад, GL-BE3600 Slate 7) розклад роботи LCD-дисплея дає змогу задати час увімкнення та вимкнення сенсорного екрана.

![Розклад роботи LCD-дисплея](https://static.gl-inet.com/docs/router/en/4/interface_guide/scheduled_tasks/lcd_display_schedule.png){class="glboxshadow"}

## Перезавантаження за розкладом {#schedule-reboot}

Ця функція дає змогу налаштувати розклад автоматичного перезавантаження маршрутизатора.

Увімкніть функцію, задайте час перезавантаження, виберіть дні тижня, коли діє розклад, і натисніть Apply.

![Перезавантаження за розкладом](https://static.gl-inet.com/docs/router/en/4/interface_guide/scheduled_tasks/schedule_reboot.png){class="glboxshadow gl-90-desktop"}

## Розклад Wi-Fi {#wi-fi-schedule}

Ця функція дає змогу налаштувати розклади Wi-Fi відповідно до частотних діапазонів, які підтримує маршрутизатор, наприклад 2.4 GHz, 5 GHz, 6 GHz і MLO Wi-Fi.

MLO Wi-Fi підтримує лише розклад увімкнення та вимкнення. Для всіх інших частотних діапазонів Wi-Fi доступні два режими розкладу: Turn On/Off і Switch TX Power.

- **Turn On/Off**: Автоматично вмикає або вимикає бездротову мережу в заданий час, поєднуючи зручність підключення з економією енергії. Наприклад, можна вимикати мережу під час сну, щоб зменшити зайве споживання енергії.

- **Switch TX Power**: Автоматично змінює потужність бездротового передавання, яка визначає рівень сигналу та покриття, у заданий час. Це дає змогу поєднати продуктивність з енергоефективністю, наприклад зменшуючи потужність за низького навантаження.

### Розклад MLO Wi-Fi {#mlo-wi-fi-schedule}

| Підтримувані моделі      |         |
| :----------------------- | :-----: |
| GL-BE14000 (Flint 4)     |    √    |
| GL-BE10000 (Slate 7 Pro) |    √    |
| GL-MT3600BE (Beryl 7)    |    √    |
| GL-BE6500 (Flint 3e)     |    √    |
| GL-BE9300 (Flint 3)      |    √    |
| GL-BE3600 (Slate 7)      |    √    |

Можна налаштувати розклад увімкнення та вимкнення як основної, так і гостьової мережі MLO Wi-Fi.

Увімкніть Main або Guest Wi-Fi Schedule, задайте час увімкнення та вимкнення, виберіть дні тижня, коли діє розклад, і натисніть Apply.

![Розклад увімкнення та вимкнення MLO Wi-Fi](https://static.gl-inet.com/docs/router/en/4/interface_guide/scheduled_tasks/mlo_turn_on_off.png){class="glboxshadow"}

### Розклад Wi-Fi у діапазоні 6 GHz {#6-ghz-wi-fi-schedule}

| Підтримувані моделі      |         |
| :----------------------- | :-----: |
| GL-BE14000 (Flint 4)     |    √    |
| GL-BE10000 (Slate 7 Pro) |    √    |
| GL-E5800 (Mudi 7)        |    √    |
| GL-BE9300 (Flint 3)      |    √    |

У режимі розкладу **Turn On/Off** можна налаштувати час увімкнення та вимкнення як основної, так і гостьової мережі Wi-Fi у діапазоні 6 GHz.

Увімкніть Main або Guest Wi-Fi Schedule, задайте час увімкнення та вимкнення, виберіть дні тижня, коли діє розклад, і натисніть Apply.

![Розклад увімкнення та вимкнення Wi-Fi 6 GHz](https://static.gl-inet.com/docs/router/en/4/interface_guide/scheduled_tasks/6g_turn_on_off.png){class="glboxshadow"}

У режимі розкладу **Switch TX Power** можна налаштувати перемикання потужності передавання TX для основної мережі Wi-Fi у діапазоні 6 GHz. Гостьова мережа Wi-Fi у діапазоні 6 GHz не підтримує цей режим розкладу.

Увімкніть Main Wi-Fi Schedule, задайте дві заплановані дії для перемикання потужності передавання TX, виберіть дні тижня, коли діє розклад, і натисніть Apply.

![Розклад перемикання потужності TX для Wi-Fi 6 GHz](https://static.gl-inet.com/docs/router/en/4/interface_guide/scheduled_tasks/6g_switch_tx_power.png){class="glboxshadow"}

- **Switch**: Задайте певний рівень TX Power (наприклад, Low) у визначений час (наприклад, 22:00).
- **Restore**: Відновіть інший рівень TX Power (наприклад, Max) в інший час (наприклад, 07:00).
- **days**: Виберіть дні тижня, коли діють ці налаштування.
