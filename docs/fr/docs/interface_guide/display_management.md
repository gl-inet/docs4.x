# Gestion de l’affichage

**Note** : Cette page est disponible uniquement sur les modèles équipés d’un écran tactile.

Sur le côté gauche du panneau d’administration web, allez à **SYSTEM** -> **Display Management**.

Cette page vous permet de gérer l’écran tactile et ses paramètres associés.

## GL-BE14000

![be14000 display](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be14000_display.png){class="glboxshadow"}

- **Wallpaper** : personnalisez le fond d’écran et le style d’affichage au réveil.
    ![be14000 wallpaper](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be14000_wallpaper.png){class="glboxshadow"}
- **Brightness** : ajustez la luminosité de l’écran tactile. Utilisez le curseur ou saisissez un pourcentage pour l’adapter aux différentes conditions d’éclairage.
- **Auto Lock** : définissez le délai après lequel l’écran se verrouille automatiquement en l’absence d’activité. La plage va de 1 à 30 minutes.
- **Screen Always On** : activez ou désactivez cette option pour choisir si l’écran tactile reste allumé en continu ou s’éteint après une période d’inactivité.
- **Enable Screen Passcode** : activez si nécessaire un code pour l’écran tactile (nombre à 4 chiffres uniquement).

## GL-BE3600

![be3600 display](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_display.png){class="glboxshadow"}

- **Function Management** : gérez les fonctions affichées sur l’écran tactile. Si nécessaire, cliquez sur l’icône à trois lignes à gauche et faites-la glisser pour modifier leur ordre.

    ![be3600 function](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_function.png){class="glboxshadow" width="650"}
    
- **Lock Screen** : personnalisez les paramètres de l’écran de verrouillage, y compris le réveil de l’écran et le fond d’écran.

    ![be3600 lock screen](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_lockscreen.png){class="glboxshadow"}

    Basculez le fond d’écran sur **Customize** pour pouvoir téléverser une image de 5 MB maximum.

    ![be3600 wallpaper customize](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_wallpaper_custom.png){class="glboxshadow"}

- **Brightness** : ajustez la luminosité de l’écran tactile. Utilisez le curseur ou saisissez un niveau précis (de 1 à 10) pour l’adapter aux différentes conditions d’éclairage.  
- **Auto Lock** : définissez le délai après lequel l’écran se verrouille automatiquement en l’absence d’activité. La plage va de 1 à 30 minutes.
- **Screen Always On** : activez ou désactivez cette option pour décider si l’écran tactile reste allumé en continu ou s’éteint après une période d’inactivité.
- **Enable Screen Passcode** : activez si nécessaire un code pour l’écran tactile (nombre à 4 chiffres uniquement).

## GL-E5800

![e5800 display](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/e5800_display.png){class="glboxshadow"}

- **Wallpaper** : personnalisez le fond d’écran et le style d’affichage au réveil.
    ![e5800 wallpaper](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/e5800_wallpaper.png){class="glboxshadow"}
- **Brightness** : ajustez la luminosité de l’écran tactile. Utilisez le curseur ou saisissez un pourcentage pour l’adapter aux différentes conditions d’éclairage.
- **Personalised Signature** : ajoutez un texte personnalisé à l’écran tactile pour afficher votre style personnel ou faciliter l’identification rapide.
- **Auto Lock** : définissez le délai après lequel l’écran se verrouille automatiquement en l’absence d’activité. La plage va de 15 secondes à 5 minutes.
- **Passcode** : définissez un code pour l’écran tactile. Ce code est requis pour protéger votre vie privée et la sécurité de vos données.
