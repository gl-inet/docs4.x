# Оновлення прошивки зупинилося на «Installing» {#stuck-on-installing-during-firmware-update}

Якщо під час оновлення прошивки маршрутизатор залишається у стані «Installing», виконайте наведені нижче дії.

![Стан Installing під час оновлення](https://static.gl-inet.com/docs/router/en/4/faq/troubleshooting/stuck_on_installing/installing.png){class="glboxshadow"}

Після кожного кроку перевіряйте, чи проблему усунуто. Якщо так, решту кроків можна пропустити.

1. Перевірте успішність оновлення прошивки.

    Відкрийте браузер, перейдіть на `192.168.8.1` та увійдіть.

    Перевірте версію прошивки у верхньому лівому куті. Якщо вона відповідає потрібній версії, оновлення успішне. Якщо ні, перейдіть до наступного кроку.

2. Забезпечте стабільне мережеве з’єднання та повторно завантажте прошивку.

3. Спробуйте завантажити прошивку через інший браузер, наприклад Edge або Safari.
