# Internet {#internet}

Logga in på webbadministrationspanelen och öppna **INTERNET**.

Den övre halvan visar ett diagram över internetstatusen, och den nedre halvan listar upp till fyra internetanslutningsmetoder (tillgängligheten varierar efter modell).

## Status Diagram {#status-diagram}

![status diagram](https://static.gl-inet.com/docs/router/en/4/interface_guide/internet/status_diagram.png){class="glboxshadow"}

**Vänster sida** av diagrammet visar aktuell internetstatus.

- A solid green line means the network connection is active.
- A dashed gray line means no network connection.
- A solid white line with a yellow exclamation mark means connected but no Internet access.

**Mitten** av diagrammet visar aktuell routermodell, status för centrala funktioner (t.ex. [AdGuard Home](adguardhome.md), [IPv6](ipv6.md), [VPN](vpn_dashboard.md) och [Tor](tor.md)) samt status för [trådlöst nätverk](wireless.md).

- Grönt visar att funktionen är aktiverad och grått att den är inaktiverad. För VPN och Tor betyder vitt att anslutning pågår.
- Håll pekaren över en aktiverad Wi‑Fi-ikon för att visa dess Wi‑Fi-QR-kod. Skanna den med en telefon eller surfplatta för att snabbt ansluta till motsvarande Wi‑Fi-nätverk.

    ![wifi qr code](https://static.gl-inet.com/docs/router/en/4/interface_guide/internet/wifi_qrcode.png){class="glboxshadow"}

**Höger sida** av diagrammet visar enheterna ([Clients](clients.md)) som är anslutna till routern.

- Trådlöst anslutna enheter visas i det övre avsnittet och kabelanslutna enheter i det nedre.
- Siffrorna bredvid varje avsnitt anger antalet anslutna enheter.

## Internet Access Methods {#internet-access-methods}

Det finns upp till fyra internetanslutningsmetoder. Se motsvarande guider nedan eller börja med [Setup Wizard](#setup-wizard).

- [Ethernet](internet_ethernet.md)
- [Repeater](internet_repeater.md)
- [Tethering](internet_tethering.md)
- [Cellular](internet_cellular.md)

## Setup Wizard {#setup-wizard}

Konfigurationsguiden är tillgänglig från firmware v4.7.

Klicka på bokikonen i det övre högra hörnet på sidan INTERNET.

![setup wizard 1](https://static.gl-inet.com/docs/router/en/4/interface_guide/internet/setup_wizard1.png){class="glboxshadow"}

Följ konfigurationsguiden för att ge routern internetåtkomst.

![setup wizard 2](https://static.gl-inet.com/docs/router/en/4/interface_guide/internet/setup_wizard2.png){class="glboxshadow"}

Om du använder [GL.iNet-appen](https://www.gl-inet.com/app/#download-app-glinet){target="_blank"} följer du anvisningarna på skärmen för att konfigurera internetåtkomst.
