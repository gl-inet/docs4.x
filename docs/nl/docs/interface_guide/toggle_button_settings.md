# Toggle Button Settings {#toggle-button-settings}

Met Toggle Button Settings kun je functies aan de fysieke schakelaar van de router toewijzen voor snelle toegang en bediening. Op sommige modellen heet dit de modusschakelaar.

Je kunt het gedrag van de schakelaar in het webbeheerpaneel aanpassen.

## Instellen {#setup}

Ga links in het webbeheerpaneel naar **SYSTEM** -> **Toggle Button Settings**.

![toggle button settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/toggle_button_settings/toggle_button_settings.jpg){class="glboxshadow"}

Vóór firmware v4.8 waren vijf opties beschikbaar om de functie van de schakelaar aan te passen.

- No Function
- AdGuard Home
- OpenVPN Client
- Tor
- WireGuard Client

Sinds firmware v4.8 zijn Repeater, Wi‑Fi en LED toegevoegd. Je kunt de schakelaar naar behoefte aanpassen.

- No Function
- Repeater
- Wi-Fi (Main/Guest Wi-Fi)
- VPN
- Tor
- AdGuard Home
- LED

![toggle button 4.8](https://static.gl-inet.com/docs/router/en/4/interface_guide/toggle_button_settings/toggle_button_4.8.png){class="glboxshadow"}

Bij het toepassen van instellingen kun je bepalen of de geselecteerde functie direct wordt in- of uitgeschakeld op basis van de positie van de schakelaar: aan/uit, links/rechts.

**Opmerking**: na een herstart past het systeem de functiestatus automatisch aan de stand van de schakelaar aan.

Als je WireGuard Client door de schakelaar laat bedienen, start de client automatisch wanneer de schakelaar LINKS (AAN) staat. Bij RECHTS (UIT) blijft WireGuard Client uitgeschakeld.
