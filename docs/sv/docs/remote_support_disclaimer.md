# ANSVARSFRISKRIVNING FÖR FJÄRRSUPPORT {#remote-support-disclaimer}

Bästa användare,

Tack för att du har valt produkter och tjänster från GL.iNet (nedan kallat ”GL.iNet” eller ”vi”).

För att bättre kunna hjälpa dig att lösa de problem som du har stött på använder vårt tekniska supportteam programvaran Anydesk för att fjärransluta, identifiera orsaken till problemen och ge riktad hjälp.

Läs detta meddelande noggrant innan en fjärranslutning upprättas och svara via e-post om du godkänner fjärråtgärder.

Om du inte godkänner villkoren i denna ansvarsfriskrivning upprättas ingen fjärråtkomst. Genom att fortsätta med fjärranslutningen bekräftar du att du har förstått och godkänt dessa villkor i sin helhet.

## I. Syftet med fjärranslutningen {#i-purpose-of-remote-connection}

Vi använder endast fjärranslutningen för att hjälpa dig att lösa tekniska problem som rör GL.iNets produkter och tjänster, däribland men inte begränsat till:

1. Diagnostisering och felsökning av problem

2. Kontroll och ändring av konfigurationer för GL.iNets produkter och tjänster

Vi förbinder oss att inte visa, samla in, lagra eller sprida dina personuppgifter, filer eller andra uppgifter som saknar koppling till den tekniska supporten för GL.iNets produkter och tjänster. Vi installerar inte heller någon programvara utan ditt samtycke.

## II. Behörighetens omfattning {#ii-authorized-scope}

För att underlätta felsökningen ger du oss behörighet att:

1. **Ta emot ditt Anydesk-fjärr-ID med ditt uttryckliga samtycke.**

    Före varje fjärranslutning bekräftar vi ditt Anydesk-fjärr-ID och ser till att det inte lämnas ut till tredje part.

2. **Fjärrstyra datorskärmen samt visa eller ändra relevant information.**

    Detta innebär främst att vi visar nätverksinformation på din dator och öppnar routerns gränssnitt för att kontrollera konfigurationsuppgifter och utföra andra nödvändiga åtgärder som rör våra produkter eller tjänster, i syfte att diagnostisera och åtgärda problem. Om vi under kontrollen fastställer att problemet orsakas av en felaktig routerkonfiguration ändrar vi routerkonfigurationen för att lösa problemet.

3. **Tillåta att Anydesk-programvaran behandlar information.**

    När vi har tillhandahållit tjänsten via Anydesk kan AnyDesk behålla åtgärdsloggar. Mer information finns i [Anydesks integritetspolicy](https://anydesk.com.cn/en/privacy){target="blank"}.

## III. Användarens rättigheter och skyldigheter {#iii-user-rights-and-obligations}

1. **Rätt att övervaka och avsluta anslutningen**

    Du har rätt att övervaka våra åtgärder under hela fjärranslutningen och när som helst avsluta anslutningen eller begära att vår tekniska supportpersonal avbryter en åtgärd.

2. **Skyldighet att säkerställa en skyddad miljö**

    Du ansvarar för att enheten finns i en skyddad och stabil nätverksmiljö under fjärranslutningen och för att stänga program och filer som kan innehålla personliga eller privata uppgifter.

3. **Kännedom om möjliga risker**

    Du förstår och godkänner att vissa risker (t.ex. nätverksfördröjningar och anslutningsavbrott) kan uppstå under fjärranslutningen och eventuellt leda till misslyckade åtgärder eller dataförlust.

4. **Den behöriga assistansens omfattning**

    Du får inte be oss att hantera eller lösa problem som ligger utanför den behöriga omfattningen eller saknar koppling till våra produkter eller tjänster.

## IV. Ansvarsfriskrivning {#iv-disclaimer}

GL.iNet och dess tekniska supportpersonal ansvarar inte för följande situationer:

1. **Fjärråtgärder som utförs av personer som inte tillhör GL.iNet**

    Vi ansvarar inte för dataförlust, röjande eller skada, eller för direkta eller indirekta förluster som uppstår till följd av fjärråtgärder som utförs av andra personer än vår egen personal. Du rekommenderas att säkerhetskopiera viktiga data för att förebygga risken för dataförlust.

2. **Ansvar begränsat till GL.iNets produkter och tjänster**

    Vi ansvarar endast för våra egna produkter och tjänster. Vi lämnar inga garantier och tar inget ansvar för andra produkter eller tjänster.

3. **Förluster på grund av användaråtgärder eller nätverksproblem**

    Vi ansvarar inte för förluster som orsakas av dina egna handhavandefel, av att du inte följer anvisningar eller inte lämnar nödvändig information, eller av problem i nätverksmiljön.

4. **Problem med programvara eller maskinvara från tredje part**

    Vi ansvarar inte om vår tekniska fjärrsupport inte kan genomföras normalt på grund av problem med programvara eller maskinvara från tredje part.

5. **Force majeure**

    Vi ansvarar inte för tjänsteavbrott, förseningar eller förluster som orsakas av force majeure-händelser (t.ex. naturkatastrofer eller krig).

6. **Ingen garanti för att problem kan lösas**

    Du förstår och godkänner att fjärranslutning endast är en kompletterande felsökningsmetod. GL.iNet garanterar inte att alla tekniska problem kan lösas eller att alla dina behov kan tillgodoses.

## V. Tvistlösning {#v-dispute-resolution}

Detta meddelandes upprättande, giltighet, fullgörande och tolkning samt eventuella relaterade tvister ska regleras av lagstiftningen i Hongkong, Kina (med undantag för lagvalsregler). Om en tvist uppstår mellan dig och oss ska båda parter först försöka lösa den genom förhandling i samförstånd. Om förhandlingarna misslyckas godkänner du att tvisten hänskjuts till domstolarna i Hongkong, Kina.
