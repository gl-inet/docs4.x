# Reset Firmware {#reset-firmware}

Öppna **SYSTEM** -> **Reset Firmware** på vänster sida i webbadministrationspanelen.

Om routern inte fungerar kan du försöka återställa firmware. Klicka på **Delete All and Reboot**.

**Obs!** Alla inställningar, program och data raderas. Processen tar cirka 2 minuter. Stäng INTE av routern.

![reset firmware](https://static.gl-inet.com/docs/router/en/4/interface_guide/reset_firmware/reset_firmware_4.8.png){class="glboxshadow"}

Om webbadministrationspanelen inte kan öppnas visar videon hur du återställer med återställningsknappen.
