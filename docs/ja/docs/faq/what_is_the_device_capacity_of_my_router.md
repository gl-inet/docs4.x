# ルーターに接続できるデバイス数はどのくらいですか？ {#what-is-the-device-capacity-of-my-router}

デバイス収容数とは、ルーターが安定して接続を維持できるデバイスの最大数を指します。

固定的なハードウェア仕様とは異なり、ルーターが実際に処理できるデバイス数は絶対的な値ではなく、実際の環境や使い方によって大きく変わります。デバイス収容数に影響する主な要因は次のとおりです。

## トラフィック強度 {#traffic-intensity}

高帯域幅の処理（4K動画ストリーミング、オンラインゲーム、大容量ファイルの転送など）は、ルーターのCPUとメモリリソースをより多く消費します。このようなタスクを同時に実行するデバイスが多いほど、ルーターが安定してサポートできる総デバイス数は減少します。

## 接続方法 {#connection-methods}

無線デバイス（2.4GHz / 5GHz Wi-Fi）は、有線LANデバイスよりも多くのルーターの処理能力を必要とします。旧式のWi-Fiチップを搭載した古いクライアントデバイスや、受信感度の低いデバイスもルーターのリソース負荷を増加させ、全体の収容数を減少させる場合があります。

## ハードウェアパフォーマンス {#hardware-performance}

ルーターのCPU、メモリ、無線モジュールの仕様は、同時接続の処理能力を直接左右します。高性能なハードウェアほど、遅延や切断を起こさずにより多くのデバイスを管理できます。

## 無線干渉 {#wireless-interference}

近隣のルーター、家電製品（電子レンジ、Bluetoothデバイス）、物理的な障害物（コンクリート壁、金属製の家具）などによるWi-Fi信号の干渉は接続の安定性を低下させ、間接的に、実際にサポートできるデバイス数を制限します。

## 有効な機能 {#enabled-features}

[VPN](../tutorials/build_your_own_wireguard_home_server_with_two_glinet_routers.md)、[AdGuard Home](../interface_guide/adguardhome.md)、[ペアレンタルコントロール](../interface_guide/parental_control.md)、[Tailscale](../interface_guide/tailscale.md)などのルーター機能を有効にすると、追加のシステムリソースが消費されるため、デバイス接続に使用できるルーターの余力が減少する可能性があります。

## ネットワークトポロジー {#network-topology}

長時間の連続稼働や、複数のサブデバイス（複数のセンサーと連携するスマートホームハブなど）の接続により、リソース使用量が蓄積し、時間の経過とともに安定して接続できるデバイス数が減少する可能性があります。
