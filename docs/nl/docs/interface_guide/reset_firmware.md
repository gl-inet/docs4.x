# Reset Firmware {#reset-firmware}

Ga links in het webbeheerpaneel naar **SYSTEM** -> **Reset Firmware**.

Bij een storing kun je proberen de firmware te resetten. Klik op **Delete All and Reboot** om dit uit te voeren.

**Opmerking:** alle huidige instellingen, toepassingen en gegevens gaan verloren. Dit duurt ongeveer 2 minuten. Schakel de router tijdens het proces NIET uit.

![reset firmware](https://static.gl-inet.com/docs/router/en/4/interface_guide/reset_firmware/reset_firmware_4.8.png){class="glboxshadow"}
