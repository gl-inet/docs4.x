# Плагіни {#plug-ins}

У меню ліворуч у вебпанелі адміністрування перейдіть до **APPLICATIONS** -> **Plug-ins**.

На цій сторінці можна керувати пакетами OpenWrt: установлювати або видаляти їх за потреби.

Перед використанням сторонніх плагінів рекомендовано натиснути кнопку **Update**. Однак **не оновлюйте плагіни, попередньо встановлені в офіційній прошивці GL.iNet**, зокрема `nginx`, `adguard home`, `tailscale` тощо.

![Керування плагінами](https://static.gl-inet.com/docs/router/en/4/interface_guide/plug-ins/plug-ins.png){class="glboxshadow"}

Сторонні плагіни, які користувачі встановили вручну, можна оновлювати. Однак GL.iNet не несе відповідальності за проблеми безпеки, спричинені сторонніми плагінами. Із запитаннями звертайтеся до авторів відповідних плагінів.
