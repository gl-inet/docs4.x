# Перевірка безпеки {#security-scan}

**Примітка**: цю функцію додано у прошивці v4.11.

---

У лівому меню вебпанелі адміністрування відкрийте **SECURITY** -> **Security Scan**.

Security Scan перевіряє безпеку маршрутизатора. Функція оцінює налаштування безпеки та формує загальну оцінку, сповіщення про ризики й рекомендації з поліпшення. Змініть конфігурацію відповідно до результатів перевірки, щоб підвищити безпеку маршрутизатора.

Перевірка безпеки розпочинається автоматично після відкриття сторінки. Вона охоплює різні параметри, зокрема Wi-Fi Security, WAN Ping, Remote SSH, Port Forwarding і DPI Content Protection. Натисніть піктограму оцінки, щоб скинути результати та виконати перевірку повторно. Після завершення відобразяться основні показники.

![Перевірка безпеки](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/security_scan.png){class="glboxshadow"}

- **Score**: загальна оцінка безпеки конфігурації маршрутизатора.

- **Risks**: критичні проблеми безпеки, які потрібно усунути.

- **Suggestions**: рекомендовані дії для підвищення безпеки, які не є обов’язковими виправленнями.

- **Safe**: параметри, які успішно пройшли перевірку безпеки.

Для перегляду докладних результатів перевірки використовуйте дві вкладки нижче.

- **Risk & Suggestion**

    Натисніть **Risk & Suggestion**, щоб переглянути ризики та рекомендації з поліпшення.

    ![Ризики та рекомендації](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/risk_suggestion.png){class="glboxshadow"}

    Щоб підвищити безпеку маршрутизатора, натисніть **Go to Settings** біля потрібного пункту. Відкриється відповідна сторінка конфігурації, де можна змінити налаштування.

- **Safe**

    Натисніть **Safe**, щоб переглянути всі параметри, які успішно пройшли перевірку безпеки.

    ![Параметри, які пройшли перевірку](https://static.gl-inet.com/docs/router/en/4/interface_guide/security_scan/safe.png){class="glboxshadow"}
