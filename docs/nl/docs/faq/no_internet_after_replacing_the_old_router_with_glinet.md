# Wat moet ik doen als ik na vervanging van mijn oude router door een GL.iNet-router geen internet heb? {#what-should-i-do-if-i-have-no-internet-after-replacing-the-old-router-with-a-glinet-router}

Als je na vervanging van je oude router door een GL.iNet-router geen internettoegang hebt, kan de nieuwe router mogelijk geen IP-adres via DHCP of PPPoE verkrijgen wanneer de WAN-poort met de modem is verbonden.

Je internetprovider heeft mogelijk **MAC binding** ingeschakeld, waardoor alleen het MAC-adres van je vorige router verbinding met het netwerk kan maken.

Probeer de volgende methoden om het probleem op te lossen.

- Clone your old router's MAC address to your new GL.iNet router. Refer to [here](./internet_connection_troubleshooting.md#q2-when-should-i-clone-a-mac-address) for details.
- Start je modem opnieuw op. Schakel deze 30 minuten uit en daarna weer in als het probleem aanhoudt.
- Neem contact op met je internetprovider om de modem opnieuw in te stellen.
