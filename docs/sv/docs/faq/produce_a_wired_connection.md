# Hur ansluter jag en enhet med endast Ethernet till Wi-Fi med en GL.iNet-router? {#how-to-connect-an-ethernet-only-device-to-wi-fi-with-a-glinet-router}

Om din enhet endast stöder Ethernet men behöver anslutas till ett trådlöst nätverk kan en GL.iNet-router överbrygga anslutningarna.

En GL.iNet-router kan fungera som en Ethernet-till-Wi-Fi-brygga för enheter som endast har en trådbunden anslutning, så att de kan ansluta till ett trådlöst nätverk. Det gör du genom att konfigurera routern som repeater.

Anslut enheten till routerns LAN-port och konfigurera sedan [repeaterfunktionen](../interface_guide/internet_repeater.md).
