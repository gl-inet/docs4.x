# ファームウェアアップデート中に「Installing」のまま進まない {#stuck-on-installing-during-firmware-update}

ファームウェアアップデート中にルーターが「Installing」のまま進まない場合は、以下の手順に従って問題を解決してください。

![stuck on installing](https://static.gl-inet.com/docs/router/en/4/faq/troubleshooting/stuck_on_installing/installing.png){class="glboxshadow"}

各手順の後に、問題が解決したかどうかを確認してください。解決した場合は、残りの手順は不要です。

1. ファームウェアアップデートが成功したかどうかを確認します。

    最初に、Webブラウザを開き、`192.168.8.1`にアクセスしてログインします。

    次に、左上のファームウェアバージョンを確認します。更新先のバージョンと一致している場合は、アップデートに成功しています。一致していない場合は、次の手順に進みます。

2. 安定したネットワーク接続を確保してから、ファームウェアを再アップロードします。

3. 別のブラウザ（Edge、Safariなど）を使用してファームウェアを再アップロードします。

---

ご不明な点がある場合は、[コミュニティフォーラム](https://forum.gl-inet.com){target="_blank"} または [お問い合わせ](https://www.gl-inet.com/contacts/){target="_blank"} をご利用ください。
