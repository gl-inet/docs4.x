# Розширені налаштування {#advanced-settings}

У лівому меню вебпанелі адміністрування відкрийте **SYSTEM** -> **Advanced Settings**.

Розширені налаштування можна змінювати за допомогою LuCI — стандартного вебінтерфейсу OpenWrt.

![Розширені налаштування](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/go_to_luci.png){class="glboxshadow"}

LuCI — відкритий незалежний проєкт, який підтримує OpenWrt і який надається «як є». GL.iNet не відповідає за підтримку LuCI.

Натисніть кнопку **Go To LuCI**, щоб перейти на сторінку входу в LuCI.

![Вхід у LuCI](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/luci_login.jpg){class="glboxshadow"}

Введіть пароль для входу. Він збігається з паролем вебпанелі адміністрування.

Після входу відкриється сторінка LuCI. Нижче наведено приклад сторінки LuCI для GL-AX1800 (Flint).

![Сторінка LuCI після входу](https://static.gl-inet.com/docs/router/en/4/interface_guide/advanced_settings/luci_logged_in.jpg){class="glboxshadow"}
