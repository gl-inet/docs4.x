# What is LuCI? {#what-is-luci}

LuCI is de webinterface van OpenWrt waarin je geavanceerde instellingen kunt configureren.

Het is een open en onafhankelijk project dat door OpenWrt wordt onderhouden. GL.iNet is niet verantwoordelijk voor het onderhoud van LuCI.

Open LuCI via SYSTEM in de linkerzijbalk van het webbeheerpaneel -> Advanced Settings.

![advanced settings](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/go_to_luci.png){class="glboxshadow"}

Klik op de knop **Go To LuCI**. Je wordt doorgestuurd naar de aanmeldpagina van LuCI.

![luci login](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/luci_login.jpg){class="glboxshadow"}

Voer het aanmeldwachtwoord in. Dit is hetzelfde wachtwoord als voor het webbeheerpaneel.

Je wordt aangemeld bij LuCI. Hieronder staat een voorbeeld van de LuCI-pagina voor GL-AX1800 (Flint).

![luci logged in](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/luci_logged_in.jpg){class="glboxshadow"}
