# AdGuard Home {#adguard-home}

AdGuard Home — це програмне забезпечення для блокування реклами та відстеження в усій мережі. Після налаштування воно охоплює всі пристрої домашньої мережі без встановлення додаткового програмного забезпечення на клієнтських пристроях.

## Налаштування {#setup}

Увійдіть у вебпанель адміністрування маршрутизатора та відкрийте **APPLICATIONS** -> **AdGuard Home**.

Увімкніть AdGuard Home за допомогою перемикача та натисніть **Apply**.

![Увімкнення AdGuard Home](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/apply.png){class="glboxshadow"}

- **AdGuard Home Handle Client Requests**: Якщо цей параметр увімкнено, DNS-запити клієнтських пристроїв оброблятимуться безпосередньо AdGuard Home. У такому разі політики VPN на основі доменів і правила батьківського контролю не діятимуть.

Після ввімкнення на сторінці відображається статистика, зокрема DNS-запити та заблоковані домени, отримана через API AdGuard Home.

![Вебпанель AdGuard Home](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/adguardhome_web_panel.png){class="glboxshadow"}

Натисніть **Settings Page** угорі сторінки.

![Перехід до налаштувань AdGuard Home](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/settings_page.png){class="glboxshadow"}

Вас буде перенаправлено на офіційну сторінку налаштувань AdGuard Home, де можна налаштувати розширені правила фільтрації.

![Налаштування AdGuard Home](https://static.gl-inet.com/docs/router/en/4/interface_guide/adguard_home/adguardhome_dashboard.png){class="glboxshadow"}

Якщо у вас виникли запитання, зверніться по допомогу до [центру підтримки AdGuard Home](https://adguard.com/en/support.html){target="_blank"}.
