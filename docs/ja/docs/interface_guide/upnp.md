# UPnP {#upnp}

**注意**: この機能はファームウェア v4.11 で導入されました。

---

Web管理パネルの左側で、**SECURITY** -> **UPnP** に移動します。

UPnP（Universal Plug and Play）により、対応するLANデバイスやアプリケーションは、GL.iNetルーターにポートマッピングを自動的に要求できます。これらのマッピングは、WANからの着信トラフィックを指定したLANのIPアドレスとポートに転送します。外部クライアントは、ポート転送ルールを手動で設定せずにローカルサービスに接続できます。

UPnPは[ポート転送](./port_forwarding.md)や[DMZ](./port_forwarding.md#dmz)とは異なり、デバイスからの要求に応じてマッピングを自動的に作成します。ポート転送は選択したポートを公開し、DMZはLANホストのすべてのポートを公開します。ポート転送とDMZはいずれも手動設定が必要です。これらの機能を有効にする前に、仕組みと関連するセキュリティリスクを理解してください。

**注意**: 

1. UPnPを有効にすると、対応するLANデバイスやアプリケーションは、要求ごとの承認なしでポートマッピングを要求できます。

2. 侵害されたデバイスや悪意のあるアプリケーションが、UPnPを使用してローカルサービスをインターネットに公開する可能性があります。UPnPは信頼できるネットワークでのみ有効にし、不要なときは無効にしてください。

3. UPnPでインターネットからの着信接続を受け付けるには、ルーターのWANインターフェースにパブリックIPが必要です。ISPがCGNATを使用している場合は機能しません。

UPnPの一般的な用途は次のとおりです。

- **オンラインゲーム**: 対応するゲームやゲーム機（Steamのマルチプレイヤーゲーム、Xbox Series X|S、PlayStation 5、Nintendo Switchなど）は、ポートマッピングを自動作成して、他のプレイヤーとの接続を確立しやすくします。

- **ピアツーピアのファイル共有**: BitTorrentクライアントやその他の対応するP2Pアプリケーションは、待受ポートを自動的にマッピングし、ピアからの着信接続を受け付けます。

- **リモートアクセス**: 一部のNASデバイス、IPカメラ、メディアサーバーなど、UPnPポートマッピングに対応するデバイスやアプリケーションは、ローカルネットワークの外部からアクセスするためのマッピングを自動設定できます。

## クイックセットアップ {#quick-setup}

スイッチをオンにしてUPnPを有効にします。対応するデバイスやアプリケーションは、次の例のように、必要に応じてポートマッピングを要求できます。

![enable upnp](https://static.gl-inet.com/docs/router/en/4/interface_guide/upnp/upnp.png){class="glboxshadow"}

- Client / Application: クライアントやアプリケーションの説明と、要求元デバイスのLAN IPアドレスです。

- Protocol: マッピングのトランスポートプロトコルです（TCPやUDPなど）。

- External Port: 着信接続用のWANポートです。

- Internal Target: 宛先のLAN IPアドレスとポートです。

- Lease: マッピングの有効期限までの残り時間です。デフォルトのリース期間は7日です。

- Action: ごみ箱アイコンをクリックするとマッピングを削除できます。クライアントやアプリケーションが動作中の場合、再度要求することがあります。

有効なポートマッピングは、クライアントが解放するかリース期間が終了すると削除されます。**Refresh** をクリックすると、最新のポートマッピングが表示されます。

![refresh port mappings](https://static.gl-inet.com/docs/router/en/4/interface_guide/upnp/refresh_upnp_information.png){class="glboxshadow"}
