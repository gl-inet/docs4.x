# Не працює спільний доступ до інтернету через iPhone {#iphone-tethering-failed}

Якщо спільний доступ до інтернету через iPhone не працює, спробуйте такі дії для усунення проблеми.

1. Переконайтеся, що **Maximise Compatibility** має стан **Enabled** (iPhone 8 або новіший).

    ![Увімкнення Maximise Compatibility](https://static.gl-inet.com/docs/router/en/4/faq/iphone_tethering_fail/maxcompat.png){class="glboxshadow gl-50-desktop" }

2. Вимкніть точку доступу на телефоні, зачекайте 5 секунд і ввімкніть її знову.

    ![Увімкнення точки доступу iPhone](https://static.gl-inet.com/docs/router/en/4/faq/iphone_tethering_fail/hotspot.png){class="glboxshadow gl-50-desktop"}

3. Переконайтеся, що встановлено iOS 15 або новішу версію.

4. Від’єднайте та знову підключіть кабель Lightning / Type-C.

5. Спробуйте інший кабель USB. Переконайтеся, що він підтримує передавання даних, а не лише заряджання.

6. Використовуйте оригінальний блок живлення маршрутизатора.

7. Перезавантажте маршрутизатор та iPhone. Іноді перезавантаження iPhone усуває проблему спільного доступу.
