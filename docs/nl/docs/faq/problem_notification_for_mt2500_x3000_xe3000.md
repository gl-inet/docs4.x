# Critical Problem Notification for GL-MT2500/GL-X3000/GL-XE3000 {#critical-problem-notification-for-gl-mt2500gl-x3000gl-xe3000}

Dear GL.iNet Customers,

Deze melding gaat over opstartproblemen en firmwareherstel via U-Boot op GL-MT2500/GL-X3000/GL-XE3000. Door een softwarefout waren enkele parameters onjuist gedefinieerd, waardoor de routers niet normaal werkten. Dit probleem kan de levensduur van de routers verkorten. Onze excuses hiervoor.

We raden alle gebruikers van GL-MT2500, GL-X3000 en GL-XE3000 dringend aan zowel de U-Boot-bootloader als de firmware bij te werken. Beide upgrades zijn noodzakelijk om het probleem volledig op te lossen.

Ook als je apparaat al de nieuwste firmware gebruikt, moet je de U-Boot-bootloader bijwerken om mogelijke problemen te voorkomen. Als de nieuwste firmware al is geïnstalleerd, hoef je deze na de U-Boot-upgrade niet opnieuw te installeren.

Voer de upgrade uit met Chrome of Microsoft Edge. Gebruik Mozilla/Firefox NIET.
