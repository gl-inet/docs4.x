# Display Management

**Nota**: Esta página solo está disponible en los modelos equipados con pantalla táctil.

En el lado izquierdo del panel de administración web, vaya a **SYSTEM** -> **Display Management**.

Esta página le permite gestionar la pantalla táctil y sus ajustes relacionados.

## GL-BE14000

![be14000 display](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be14000_display.png){class="glboxshadow"}

- **Wallpaper**: personalice el fondo de pantalla y el estilo de activación de la pantalla.
    ![be14000 wallpaper](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be14000_wallpaper.png){class="glboxshadow"}
- **Brightness**: ajuste el brillo de la pantalla táctil. Use el control deslizante o introduzca un porcentaje para adaptarlo a distintas condiciones de iluminación.
- **Auto Lock**: establezca el tiempo de espera para que la pantalla se bloquee automáticamente cuando no haya actividad. El rango va de 1 a 30 minutos.
- **Screen Always On**: active o desactive esta opción para decidir si la pantalla táctil permanece encendida de forma continua o se apaga tras un periodo de inactividad.
- **Enable Screen Passcode**: habilite un código de acceso para la pantalla táctil cuando sea necesario (solo un número de 4 dígitos).

## GL-BE3600

![be3600 display](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_display.png){class="glboxshadow"}

- **Function Management**: gestione qué funciones se muestran en la pantalla táctil. Si es necesario, haga clic en el icono de tres líneas de la izquierda y arrástrelo para cambiar su orden.

    ![be3600 function](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_function.png){class="glboxshadow" width="650"}

- **Lock Screen**: personalice los ajustes de la pantalla de bloqueo, incluida la pantalla de activación y el fondo de pantalla.

    ![be3600 lock screen](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_lockscreen.png){class="glboxshadow"}

    Cambie el fondo de pantalla a **Customize** y podrá cargar una imagen de tamaño no superior a 5 MB.

    ![be3600 wallpaper customize](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/be3600_wallpaper_custom.png){class="glboxshadow"}

- **Brightness**: ajuste el brillo de la pantalla táctil. Use el control deslizante o introduzca un nivel específico, de 1 a 10, para adaptarse a distintas condiciones de iluminación.
- **Auto Lock**: establezca el tiempo de espera para que la pantalla se bloquee automáticamente cuando no haya actividad. El rango va de 1 a 30 minutos.
- **Screen Always On**: active o desactive esta opción para decidir si la pantalla táctil permanece encendida de forma continua o se apaga tras un periodo de inactividad.
- **Enable Screen Passcode**: habilite un código de acceso para la pantalla táctil cuando sea necesario (solo un número de 4 dígitos).

## GL-E5800

![e5800 display](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/e5800_display.png){class="glboxshadow"}

- **Wallpaper**: personalice el fondo de pantalla y el estilo de activación de la pantalla.
    ![e5800 wallpaper](https://static.gl-inet.com/docs/router/en/4/interface_guide/display_management/e5800_wallpaper.png){class="glboxshadow"}
- **Brightness**: ajuste el brillo de la pantalla táctil. Use el control deslizante o introduzca un porcentaje para adaptarlo a distintas condiciones de iluminación.
- **Personalised Signature**: añada un texto personalizado a la pantalla táctil para mostrar su estilo único o para una identificación rápida.
- **Auto Lock**: establezca el tiempo de espera para que la pantalla se bloquee automáticamente cuando no haya actividad. El rango va de 15 segundos a 5 minutos.
- **Passcode**: establezca un código de acceso para la pantalla táctil. Este código es necesario para proteger su privacidad y la seguridad de sus datos.
