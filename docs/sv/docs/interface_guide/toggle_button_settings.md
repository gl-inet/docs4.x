# Toggle Button Settings {#toggle-button-settings}

Med Toggle Button Settings kan du tilldela funktioner till routerns fysiska växlingsknapp för snabb åtkomst till vanliga åtgärder.

Du kan anpassa knappens funktion i webbadministrationspanelen.

## Setup {#setup}

Öppna **SYSTEM** -> **Toggle Button Settings** på vänster sida i webbadministrationspanelen.

![toggle button settings](https://static.gl-inet.com/docs/router/en/4/interface_guide/toggle_button_settings/toggle_button_settings.jpg){class="glboxshadow"}

Före firmware v4.8 finns fem alternativ för att anpassa knappen.

- No Function
- AdGuard Home
- OpenVPN Client
- Tor
- WireGuard Client

Från firmware v4.8 finns även Repeater, Wi‑Fi och LED.

- No Function
- Repeater
- Wi-Fi (Main/Guest Wi-Fi)
- VPN
- Tor
- AdGuard Home
- LED

![toggle button 4.8](https://static.gl-inet.com/docs/router/en/4/interface_guide/toggle_button_settings/toggle_button_4.8.png){class="glboxshadow"}

När inställningarna tillämpas kan vald funktion aktiveras eller inaktiveras direkt utifrån knappens vänster-/högerläge.

**Note**: After a device reboot, the system will automatically apply the feature state according to the toggle switch position.

Om WireGuard Client styrs av knappen startar den automatiskt i LEFT (ON) och förblir inaktiverad i RIGHT (OFF).
