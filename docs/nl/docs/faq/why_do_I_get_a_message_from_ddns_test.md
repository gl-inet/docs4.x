# Waarom krijg ik een bericht van de DDNS-test? {#why-do-i-get-a-message-from-ddns-test}

Wanneer je de DDNS-test op de pagina Dynamic DNS uitvoert, kan het onderstaande bericht verschijnen.

**"The IP address from DDNS domain resolution is not the same as the WAN IP of the device."**

**"You need an Internet Public IP address to use Dynamic DNS."**

![ddnstest](https://static.gl-inet.com/docs/router/en/4/faq/warning_on_ddns_test/ddnstest.jpg){class="glboxshadow"}

Dit is geen **Warning** of **Error**, maar een melding over de netwerkstatus van je router.

Dit resultaat geeft doorgaans de positie van de router in het netwerk weer. Het bericht verschijnt bijvoorbeeld wanneer je GL.iNet-router als secundaire router in je thuisnetwerk is geconfigureerd.

Het bericht verdwijnt niet als je port forwarding op je primaire router hebt ingesteld. Het geeft alleen aan dat de router zich achter NAT bevindt.

Als je diensten via NAT toegankelijk wilt maken, bijvoorbeeld voor externe toegang, zijn aanvullende instellingen vereist.
