# Проблема роботи GL-X3000/GL-XE3000/GL-X2000 із SIM-картками EE та способи усунення {#problem-notification-and-solutions-for-gl-x3000gl-xe3000gl-x2000-failure-to-work-with-ee-sim-cards}

Шановні користувачі GL.iNet!

Нещодавно ми виявили, що деякі користувачі стикаються зі збоями підключення на GL-X3000/GL-XE3000/GL-X2000 під час використання SIM-карток EE. Подальша перевірка показала, що певні SIM-картки EE підтримують лише IPv4. Натомість налаштування стільникових маршрутизаторів GL.iNet за замовчуванням одночасно вмикають IPv4 та IPv6, що спричиняє цю проблему.

## Рішення та тимчасові способи усунення {#solutions-workarounds}

1. **Оновлення прошивки**

    Ми випустили нові оновлення прошивки, у яких протокол за замовчуванням змінено на IPv4 для усунення проблеми. Якщо потрібен IPv6, у панелі адміністрування можна змінити налаштування на IPv4 та IPv6.

    | Модель маршрутизатора         |                       |
    | :---------------------------- | :-------------------: |
    | GL-X3000 (Spitz AX)           | [Завантажити прошивку](https://dl.gl-inet.com/router/x3000/stable)     |
    | GL-XE3000 (Puli AX)           | [Завантажити прошивку](https://dl.gl-inet.com/router/xe3000/stable)    |
    | GL-X2000 (Spitz Plus)         | [Завантажити прошивку](https://dl.gl-inet.com/router/x2000/stable)   |

2. **Тимчасове рішення для інших моделей**

    Якщо у вас інша модель або ви не хочете використовувати зазначену прошивку, після початку підключення до стільникової мережі послідовно виконайте такі AT-команди.

    ```
    AT+CGDCONT=1,"IP","User_APN"
    AT+CFUN=0
    AT+CFUN=1
    ```

    **Примітка**: Для SIM-карток EE значення "User_APN" зазвичай — "everywhere". Повторюйте ці дії після кожного перезавантаження маршрутизатора.

    ??? note "Як виконати AT-команду?"

        1. У вебпанелі адміністрування перейдіть до розділу INTERNET -> Cellular, натисніть значок із трьома крапками вгорі праворуч і виберіть **Modem AT Command**.

            ![Відкриття AT-команд модема](https://static.gl-inet.com/docs/router/en/4/faq/ee_sim_failure/at_command_0.jpg){class="glboxshadow"}

            Для старіших прошивок натисніть кнопку інструментів угорі праворуч, щоб відкрити сторінку керування модемом.

            ![Сторінка керування модемом](https://static.gl-inet.com/docs/router/en/4/faq/ee_sim_failure/modem_management_button.png){class="glboxshadow"}

        2. Знайдіть AT command, як показано нижче.

            ![Поле AT command](https://static.gl-inet.com/docs/router/en/4/faq/ee_sim_failure/at_command_1.png){class="glboxshadow"}
