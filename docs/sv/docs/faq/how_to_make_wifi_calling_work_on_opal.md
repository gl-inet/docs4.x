# Hur får jag Wi-Fi-samtal att fungera på Opal (GL-SFT1200)? {#how-to-make-wi-fi-calling-work-on-opal-gl-sft1200}

## Uppgradera firmware {#upgrade-firmware}

Gå till SYSTEM -> Upgrade i webbadministrationspanelen och uppgradera firmware till den senaste versionen. Kontrollera den senaste versionen i [Firmware Download Center](https://dl.gl-inet.com/){target="_blank"}.

![opal4317](https://static.gl-inet.com/docs/router/en/4/faq/wifi_call/opal4317.jpg){class="glboxshadow"}

## Inaktivera nätverksacceleration {#disable-network-acceleration}

Vår erfarenhet och kundernas återkoppling visar att Wi-Fi-samtal fungerar korrekt när Network/Hardware Acceleration har inaktiverats.

När du har uppgraderat firmware loggar du in på webbadministrationspanelen, går till **NETWORK** -> **Network Acceleration** och inaktiverar funktionen.

![networkacc](https://static.gl-inet.com/docs/router/en/4/faq/wifi_call/netacc.jpg){class="glboxshadow"}
