# Hur reparerar jag nätverket eller återställer fabriksinställningarna? {#how-to-repair-network-or-factory-reset}

Alla GL.iNet-routrar har en fysisk återställningsmekanism, antingen en återställningsknapp eller ett hål för en nål. Att trycka på knappen eller föra in en nål i hålet har samma effekt: nätverksanslutningen återställs eller routern återställs till fabriksinställningarna.

På modeller med ett hål använder du en nål, ett uträtat gem eller ett liknande verktyg.

Kontrollera att routern har startat helt innan du återställer den. Tryck **INTE** på återställningsknappen omedelbart efter att strömmen har slagits på, eftersom det kan aktivera U-Boots felsäkra läge.

## Reparera nätverket {#repair-network}

Håll återställningsknappen intryckt i **4 sekunder** och släpp den sedan för att utföra en mjuk återställning som kan reparera nätverket.

Åtgärden startar om nätverksgränssnittet och återställer internetgränssnittet till standardinställningarna, samtidigt som Wi-Fi-inställningar, VPN-inställningar, systeminställningar osv. behålls.

**Obs!**

1. Om Wi-Fi har inaktiverats återställer en mjuk återställning Wi-Fi till standardläget aktiverat.

2. En mjuk återställning kan även användas för att snabbt växla från ett annat driftläge till routerläget.

## Återställ fabriksinställningarna {#reset-to-factory}

**På modeller utan pekskärm** kan firmware återställas på två sätt: med återställningsknappen eller via webbadministrationspanelen. Titta på videon eller följ stegen nedan.

<iframe width="560" height="315" src="https://www.youtube.com/embed/jguDqBWP-Fw" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

1. Använd den fysiska återställningsmekanismen (knapp eller hål för en nål).

    Håll återställningsknappen intryckt (eller för in en nål i hålet) i **10 sekunder** och släpp den sedan för att återställa routern till fabriksinställningarna. Alla användardata raderas.

    **Obs!** Om fabriksåterställningen inte fungerar kan du behöva följa [U-Boot-guiden](debrick.md) för att återställa routern.

2. Återställ firmware i webbadministrationspanelen.

    Logga in på routerns webbadministrationspanel och gå till SYSTEM -> Reset Firmware. Klicka på knappen för att återställa firmware.

    **Obs!** Alla aktuella inställningar och data går förlorade. Processen tar cirka 2 minuter. Stäng **INTE** av routern under processen.

    ![glinet reset firmware](https://static.gl-inet.com/docs/router/en/4/faq/repair_network_or_reset_firmware/reset_firmware_4.8.png){class="glboxshadow"}

**På modeller med pekskärm** kan firmware återställas på tre sätt: via pekskärmen, återställningsknappen eller webbadministrationspanelen.
