# Måste jag konfigurera Ethernet WAN när jag använder VPN? {#do-i-have-to-configure-ethernet-wan-when-using-vpn}

Nej. Du kan konfigurera valfri WAN-källa för GL.iNet-routern när den används som VPN-klient. Ditt LAN och WLAN omfattas då av VPN-tunneln.

## Konfigurera via Wi-Fi-repeater {#configure-by-wi-fi-repeater}

Du kan ansluta GL.iNet-routern (konfigurerad som VPN-klient) trådlöst till din primära router. GL.iNet-routern fungerar då som en Wi-Fi-repeater.

![repater](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/repeater.jpg){class="glboxshadow"}

## Konfigurera via Ethernet-kabel {#configure-by-ethernet-cable}

Du kan ansluta GL.iNet-routern (konfigurerad som VPN-klient) till din primära router med en Ethernet-kabel.

![ethernet](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/ethernet.jpg){class="glboxshadow"}

## Konfigurera via internetdelning med USB {#configure-by-usb-tethering}

Du kan ansluta GL.iNet-routern (konfigurerad som VPN-klient) till din telefon med en USB-kabel. Detta kallas även internetdelning med USB (USB tethering).

![tethering](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/tethering.jpg){class="glboxshadow"}
