# Як налаштувати правила фільтрації доменів та IP-адрес на маршрутизаторах GL.iNet за допомогою текстового файла в інтернеті? {#how-to-configure-domain-and-ip-filtering-rules-for-glinet-routers-via-an-online-text-file}

Починаючи з прошивки v4.7, такі функції підтримують імпорт правил за URL текстового файла в інтернеті:

- VPN Policy Based on Target Domains or IP Addresses (у розділі VPN)
- Add a New Ruleset (у розділі Parental Control)

У цьому посібнику описано імпорт правил фільтрації доменів та IP-адрес на маршрутизатори GL.iNet за допомогою текстового файла в інтернеті.

## Підтримувані формати URL і файлів {#supported-url-file-formats}

Підтримуються такі формати URL:

- URL звичайних текстових файлів (HTTP/HTTPS)
- URL необробленого вмісту GitHub Raw

Підтримуються файли `.txt`, `.conf`, `.log` та інші звичайні текстові формати.

**Примітка**: Двійкові файли не підтримуються, зокрема `.exe`, `.zip`, `.jpg`, `.png` тощо.

## Розміщення текстового файла на GitHub {#use-github-to-host-text-file}

Якщо текстовий файл розміщено у відкритому репозиторії GitHub, використовуйте URL необробленого вмісту замість звичайного URL GitHub.

Наприклад, цей URL GitHub указує на вебсторінку, а не на необроблений вміст:

`https://github.com/SecOps-Institute/FacebookIPLists/blob/master/facebook_ipv4_cidr_blocks.lst`

Щоб маршрутизатор завантажив правильний вміст, використовуйте URL необробленого вмісту в такому форматі:

`https://raw.githubusercontent.com/SecOps-Institute/FacebookIPLists/master/facebook_ipv4_cidr_blocks.lst`

Тоді маршрутизатор зможе отримати звичайний текстовий вміст файла.

## Формати фільтрів для політики VPN (домен/IP) {#filter-formats-for-vpn-policy-domainip}

Функція "VPN Policy Based on Target Domain or IP Address" підтримує такі формати фільтрів у текстовому файлі в інтернеті:

* Доменне ім’я: задайте домен, наприклад `netflix.com` (охоплює всі піддомени).
* Піддомен: задайте повний піддомен, наприклад `www.netflix.com` (охоплює лише цей піддомен).
* Діапазон CIDR: задайте діапазон IP-адрес у форматі CIDR, наприклад `192.168.10.0/24`.
* IPv4-адреса: задайте окрему IPv4-адресу, наприклад `192.168.10.10`.

## Формати фільтрів для батьківського контролю (набір правил) {#filter-formats-for-parental-control-ruleset}

Функція "Add a New Ruleset" у Parental Control підтримує такі формати фільтрів у текстовому файлі в інтернеті:

* Доменне ім’я: задайте домен, наприклад `instagram.com` (охоплює всі піддомени).
* Піддомен: задайте повний піддомен, наприклад `www.instagram.com` (охоплює лише цей піддомен).

Під час створення текстового файла розміщуйте один фільтр у кожному рядку. Маршрутизатор оброблятиме рядки відповідно до формату та застосовуватиме відповідні правила до VPN або Parental Control.

Дотримуючись цих форматів, можна створювати та підтримувати текстовий файл в інтернеті для налаштування VPN і батьківського контролю маршрутизатора.
