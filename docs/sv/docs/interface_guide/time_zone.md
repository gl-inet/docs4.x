# Time Zone {#time-zone}

Öppna **SYSTEM** -> **Time Zone** på vänster sida i webbadministrationspanelen.

Routern tidsstämplar loggar enligt systemtiden, och vissa funktioner kräver rätt tid. Kontrollera att rätt tidszon har valts och synkroniserats.

Tidszonen synkroniseras inte automatiskt. Klicka på **Sync** för att uppdatera den.

![time zone no sync](https://static.gl-inet.com/docs/router/en/4/interface_guide/time_zone/time_zone_no_sync.png){class="glboxshadow"}

After synchronization, the page will appear as shown below.

![time zone sync](https://static.gl-inet.com/docs/router/en/4/interface_guide/time_zone/time_zone_sync.png){class="glboxshadow"}
