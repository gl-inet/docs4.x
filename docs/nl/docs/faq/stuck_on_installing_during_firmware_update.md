# Stuck on "Installing" during firmware update {#stuck-on-installing-during-firmware-update}

Volg de onderstaande stappen als je router tijdens een firmware-update blijft hangen op "Installing".

![stuck on installing](https://static.gl-inet.com/docs/router/en/4/faq/troubleshooting/stuck_on_installing/installing.png){class="glboxshadow"}

Controleer na elke stap of het probleem is opgelost. Sla in dat geval de resterende stappen over.

1. Controleer of de firmware-update is geslaagd.

    First, open a web browser, access `192.168.8.1` and log in.

    Controleer daarna linksboven de firmwareversie. Als deze overeenkomt met de doelversie, is de update geslaagd. Ga anders door met de volgende stap.

2. Zorg voor een stabiele netwerkverbinding en upload de firmware opnieuw.

3. Use a different browser (e.g., Edge, Safari) to re-upload the firmware.
