# Vad är LuCI? {#what-is-luci}

LuCI är OpenWrts webbaserade användargränssnitt där du kan göra vissa avancerade inställningar.

Det är ett öppet och oberoende projekt som underhålls av OpenWrt. GL.iNet ansvarar inte för underhållet av LuCI.

För att öppna LuCI går du till SYSTEM på vänster sida i webbadministrationspanelen -> Advanced Settings.

![advanced settings](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/go_to_luci.png){class="glboxshadow"}

Klicka på knappen **Go To LuCI**. Du omdirigeras till LuCI:s inloggningssida.

![luci login](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/luci_login.jpg){class="glboxshadow"}

Ange inloggningslösenordet, som är samma lösenord som för webbadministrationspanelen.

Du loggas in på LuCI-sidan. Bilden nedan visar ett exempel på LuCI-sidan för GL-AX1800 (Flint).

![luci logged in](https://static.gl-inet.com/docs/router/en/4/faq/what_is_luci/luci_logged_in.jpg){class="glboxshadow"}
