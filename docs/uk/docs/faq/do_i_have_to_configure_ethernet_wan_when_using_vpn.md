# Чи обов’язково налаштовувати Ethernet WAN для використання VPN? {#do-i-have-to-configure-ethernet-wan-when-using-vpn}

Ні. Якщо маршрутизатор GL.iNet працює як клієнт VPN, можна налаштувати будь-яке джерело WAN. LAN і WLAN будуть охоплені тунелем VPN.

## Підключення через ретранслятор Wi-Fi {#configure-by-wi-fi-repeater}

Підключіть маршрутизатор GL.iNet, налаштований як клієнт VPN, до головного маршрутизатора бездротово. Він працюватиме як ретранслятор Wi-Fi.

![Підключення клієнта VPN через ретранслятор](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/repeater.jpg){class="glboxshadow"}

## Підключення кабелем Ethernet {#configure-by-ethernet-cable}

Підключіть маршрутизатор GL.iNet, налаштований як клієнт VPN, до головного маршрутизатора кабелем Ethernet.

![Підключення клієнта VPN через Ethernet](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/ethernet.jpg){class="glboxshadow"}

## Спільний доступ до інтернету через USB {#configure-by-usb-tethering}

Підключіть маршрутизатор GL.iNet, налаштований як клієнт VPN, до телефона кабелем USB. Цей спосіб називається USB Tethering.

![Підключення клієнта VPN через USB](https://static.gl-inet.com/docs/router/en/4/faq/wan_source_vpn/tethering.jpg){class="glboxshadow"}
