# Log {#log}

Ga links in het webbeheerpaneel naar **SYSTEM** -> **Log**.

Op de pagina Log kun je System-, Kernel-, Crash-, Cloud- en Nginx-logboeken bekijken voor analyse en probleemoplossing.

Sommige modellen voor mobiele netwerken met eSIM-ondersteuning bieden een eSIM-logboek.

GL-X3000 wordt hieronder als voorbeeld gebruikt.

![log page](https://static.gl-inet.com/docs/router/en/4/interface_guide/log/log.png){class="glboxshadow"}

De functie **filtering** is vanaf firmware v4.8 beschikbaar op de pagina System Log. Je kunt een niveau of module kiezen of trefwoorden invoeren om snel in logboeken te zoeken.

Klik op **Refresh** voor de nieuwste logboekgegevens.

Klik op **Export Log** om System-, Kernel-, Crash- en Cloud-logboeken te exporteren. Stuur het geëxporteerde bestand bij feedback naar de technische ondersteuning van GL.iNet om het probleem sneller te analyseren.
