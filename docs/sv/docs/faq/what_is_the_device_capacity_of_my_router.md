# Hur många enheter klarar min router? {#what-is-the-device-capacity-of-my-router}

Enhetskapaciteten är det största antal enheter som en router kan hantera stabilt.

Till skillnad från vissa fasta maskinvaruspecifikationer är det faktiska antalet enheter som routern kan hantera inget absolut värde. Det varierar kraftigt beroende på den verkliga miljön och användningsmönstren. Följande faktorer påverkar enhetskapaciteten.

## Trafikintensitet {#traffic-intensity}

Aktiviteter som kräver stor bandbredd (t.ex. strömning av 4K-video, onlinespel och överföring av stora filer) förbrukar mer av routerns processor- och minnesresurser. Ju fler enheter som utför sådana uppgifter samtidigt, desto färre enheter kan routern hantera stabilt totalt.

## Anslutningsmetoder {#connection-methods}

Trådlösa enheter (2.4GHz/5GHz Wi-Fi) kräver mer processorkraft från routern än trådbundna Ethernet-enheter. Äldre klientenheter med föråldrade Wi-Fi-kretsar eller svag signalmottagning kan också öka belastningen på routerns resurser och minska den totala kapaciteten.

## Maskinvaruprestanda {#hardware-performance}

Specifikationerna för routerns processor, minne och trådlösa modul avgör direkt hur väl den kan hantera samtidiga anslutningar. Maskinvara med högre prestanda kan hantera fler enheter utan fördröjningar eller avbrott.

## Trådlösa störningar {#wireless-interference}

Störningar i Wi-Fi-signalen från närliggande routrar, hushållsapparater (mikrovågsugnar och Bluetooth-enheter) eller fysiska hinder (betongväggar och metallmöbler) försämrar anslutningens stabilitet och begränsar indirekt det effektiva antalet enheter som stöds.

## Aktiverade funktioner {#enabled-features}

Aktiverade routerfunktioner som [VPN](../tutorials/build_your_own_wireguard_home_server_with_two_glinet_routers.md), [AdGuard Home](../interface_guide/adguardhome.md), [Parental Control](../interface_guide/parental_control.md) och [Tailscale](../interface_guide/tailscale.md) förbrukar ytterligare systemresurser, vilket kan minska routerns tillgängliga kapacitet för enhetsanslutningar.

## Nätverkstopologi {#network-topology}

Långvarig kontinuerlig drift eller anslutning av flera underenheter (t.ex. smarta hem-hubbar som är kopplade till flera sensorer) kan med tiden öka resursanvändningen och minska antalet enheter som kan anslutas stabilt.
