# First time setup {#first-time-setup}

De eerste installatie is voor de meeste GL.iNet-routers vergelijkbaar. De meeste modellen hebben wifi, maar sommige niet.

Therefore, the following guidance is divided into two cases based on the presence of a Wi-Fi module.

* [Voor modellen met wifi](#for-models-that-have-wi-fi)
* [Voor modellen zonder wifi](#for-models-that-dont-have-wi-fi)

## Voor modellen met wifi {#for-models-that-have-wi-fi}

The following steps use the GL-MT3000 (Beryl AX) as an example.

Leg de volgende meegeleverde onderdelen klaar.

- A router GL-MT3000 (Beryl AX)
- A power adapter
- An Ethernet cable

Bekijk de video of volg de onderstaande stappen.

<iframe width="560" height="315" src="https://www.youtube.com/embed/WW8wGk68lEU" title="YouTube-videospeler" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

1. **Power on**

    Sluit de voedingsadapter aan op de router en een stopcontact. De router wordt automatisch ingeschakeld.

    Sommige modellen, zoals Slate AX, hebben een TF-kaartsleuf. Plaats de TF-kaart voordat je de router inschakelt. Hot-swapping van TF-kaarten wordt niet ondersteund.

2. **Connect to the router**

    Connect a device (e.g., smartphone, laptop, or computer) to the router via an Ethernet cable or via Wi-Fi.

    * Connect via Ethernet: Connect a device to the LAN port of the router via an Ethernet cable.

    * Verbinding via wifi: zoek Wi-Fi SSID en Wi-Fi key op het etiket onder de router. Selecteer de SSID op je apparaat en voer de wifisleutel in.

        !!! tip

            1. De QR-code op het etiket bevat de standaard-wifigegevens. Scan deze om snel verbinding te maken.
            2. Probeer bij sommige oudere modellen "goodlife" als de wifisleutel niet op het etiket staat.

    Na verbinding met wifi heb je mogelijk nog geen internet. Configureer eerst het netwerk in de volgende stap.

3. **Log in to the web Admin Panel**

    Open een webbrowser, bij voorkeur Chrome, Edge of Safari, en ga naar [http://192.168.8.1](http://192.168.8.1). Je wordt naar de aanmeldpagina van GL.iNet geleid. Raadpleeg [deze pagina](cannot_access_web_admin_panel.md) als je het webbeheerpaneel niet kunt openen.

    Stel je beheerderswachtwoord in en klik op **Next**.

    ![mt3000 set up admin password](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_admin_password.png){class="glboxshadow"}

    Stel wifi in. Als je de wifigegevens wijzigt, maak je opnieuw verbinding met het bijgewerkte netwerk en klik je op **Next**.

    ![mt3000 set up wifi](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_set_up_wifi.png){class="glboxshadow"}

    Wacht tot de router is geïnitialiseerd.

    ![mt3000 initializing](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_initializing.png){class="glboxshadow"}

    Vervolgens wordt het webbeheerpaneel van de router geopend.

    ![mt3000 admin panel](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt3000_admin_panel.png){class="glboxshadow"}

4. **Connect to the Internet**

    * [Connect to the Internet via an ethernet cable](../interface_guide/internet_ethernet.md)
    * [Connect to the Internet via an existing Wi-Fi](../interface_guide/internet_repeater.md)
    * [Connect to the Internet via usb tethering](../interface_guide/internet_tethering.md)
    * [Connect to the Internet via usb modem](../interface_guide/internet_cellular.md)

## Voor modellen zonder wifi {#for-models-that-dont-have-wi-fi}

The following steps use the GL-MT5000 (Brume 3) as an example.

1. **Power on**

    Sluit de voedingsadapter aan op de router en een stopcontact. De router wordt automatisch ingeschakeld.

2. **Connect to the router**

    Connect a device (e.g., laptop, computer) to the LAN port of the router via an Ethernet cable.

3. **Log in to the web Admin Panel**

    Open een webbrowser, bij voorkeur Chrome, Edge of Safari, en ga naar [http://192.168.8.1](http://192.168.8.1). Je wordt naar de aanmeldpagina van GL.iNet geleid. Raadpleeg [deze pagina](cannot_access_web_admin_panel.md) als je het webbeheerpaneel niet kunt openen.

    Stel je beheerderswachtwoord in en klik op **Next**.

    ![mt5000 set up admin password](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt5000_admin_password.png){class="glboxshadow"}

    Wacht tot de router is geïnitialiseerd.

    ![mt5000 initializing](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt5000_initializing.png){class="glboxshadow"}

    Vervolgens wordt het webbeheerpaneel van de router geopend.

    ![mt5000 admin panel](https://static.gl-inet.com/docs/router/en/4/faq/first_time_setup/mt5000_admin_panel.png){class="glboxshadow"}

4. **Connect to the Internet**

    * [Connect to the Internet via an ethernet cable](../interface_guide/internet_ethernet.md)
    * [Connect to the Internet via usb tethering](../interface_guide/internet_tethering.md)
