# iPhone Tethering failed {#iphone-tethering-failed}

Probeer de onderstaande stappen als iPhone-tethering mislukt.

1. Controleer of **Maximise Compatibility** is **Enabled** (iPhone 8 of nieuwer).

    ![maxcompat](https://static.gl-inet.com/docs/router/en/4/faq/iphone_tethering_fail/maxcompat.png){class="glboxshadow gl-50-desktop" }

2. Schakel de hotspot op je telefoon uit, wacht 5 seconden en schakel deze weer in.

    ![hotspot](https://static.gl-inet.com/docs/router/en/4/faq/iphone_tethering_fail/hotspot.png){class="glboxshadow gl-50-desktop"}

3. Make sure the iOS version is 15 or above.

4. Koppel de Lightning- of Type-C-kabel los en sluit deze opnieuw aan.

5. Use another USB cable. Ensure it supports data transfer (not just charging).

6. Gebruik de originele voeding van de router.

7. Start zowel de router als je iPhone opnieuw op. Soms lost het opnieuw opstarten van de iPhone het tetheringprobleem op.
