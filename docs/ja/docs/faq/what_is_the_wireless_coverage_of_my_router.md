# ルーターの無線カバレッジ範囲はどのくらいですか？ {#what-is-the-wireless-coverage-of-my-router}

ルーターの理論上の無線カバレッジは、障害物や干渉のない開けた環境でテストされた参考値です。実際の家庭やオフィスでは、環境内の障害物や干渉によってカバレッジ範囲が狭くなり、場所によって信号強度が異なる場合があります。

無線カバレッジ範囲に影響する主な要因は次のとおりです。

## 無線チップセット {#wireless-chipset}

無線チップセットはWi-Fi機能の中核となる処理ユニットで、信号のエンコード、デコード、伝送制御を担います。

高性能なチップセット（Wi-Fi 6/6E以降のプロトコルに対応したものなど）を搭載したルーターは、信号の伝送効率と干渉耐性が大幅に向上し、複雑な環境でもより広い有効カバレッジを実現できます。

一方、古いチップセットやローエンドのチップセットは処理能力に制約があるため、信号の伝送距離と安定性が低下します。

## 無線帯域 {#wireless-band}

2.4 GHz Wi-Fiは透過性が高くカバレッジ範囲が広い一方、帯域幅は狭くなります。5 GHz Wi-Fiは高速ですが透過性が低く、カバレッジ範囲は狭くなります。

## 送信出力 {#tx-power}

ルーターのTX Power（無線送信出力）は、信号伝送の基本となるパラメーターです。

複数のルーターがある環境では、信号干渉を最小限に抑えるためにTX Powerを下げ、近隣のWi-Fiネットワークとの重なりを軽減してネットワークの安定性を高める場合があります。ただし、その分Wi-Fiのカバレッジ範囲は直接狭くなります。

TX Powerは、Web管理パネルの[WIRELESS](../interface_guide/wireless.md)ページで必要に応じて調整できます。

## ルーターの設置場所 {#router-location}

ルーターを家の中央の高い場所（棚やキャビネットの上など）に設置すると、障害物を最小限に抑えられます。最適なカバレッジを得るため、部屋の隅、家具の裏、干渉源の近くには設置しないでください。

## 物理的な障害物 {#physical-obstacles}

厚い壁（特にコンクリート、レンガ、金属の壁）、床、大型家具はWi-Fi信号を遮ったり弱めたりします。複数階の建物や仕切られた空間では、開けた場所に比べてカバレッジが大幅に狭くなります。

## 無線干渉 {#wireless-interference}

他の無線デバイス（近隣のルーター、スマートホームハブ、スマートカメラなど）や家電製品（電子レンジなど）は信号干渉を引き起こし、有効なWi-Fiカバレッジ範囲を狭める可能性があります。
