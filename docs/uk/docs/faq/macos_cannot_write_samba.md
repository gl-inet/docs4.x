# macOS не може записувати файли в спільний ресурс Samba {#macos-cannot-write-to-a-samba-share}

Якщо для спільного ресурсу Samba використовується накопичувач, відформатований в exFAT, деякі пристрої macOS під час запису файлів можуть показувати одну з таких помилок.

- "The operation can't be completed because an unexpected error occurred (error code 100093)."

    ![Помилка з кодом 100093](https://static.gl-inet.com/docs/router/en/4/faq/macos_cannot_write_samba/macopyerror.jpg){class="glboxshadow"}

- "The operation can't be completed because an unexpected error occurred (error code -50)."

    ![Помилка з кодом -50](https://static.gl-inet.com/docs/router/en/4/faq/macos_cannot_write_samba/error-code-50.jpg){class="glboxshadow"}

Спробуйте усунути проблему такими способами.

1. **Перевірте дозволи спільного ресурсу Samba.**

    Переконайтеся, що для спільного ресурсу Samba дозволено запис. Увійдіть у вебпанель адміністрування маршрутизатора та перевірте, чи для спільної папки вашому обліковому запису надано дозволи "Read/Write".

2. **Скопіюйте файл командою `cp -X file-name`.**

    Під час передавання Finder автоматично додає розширені атрибути, зокрема resource forks і метадані, що може конфліктувати з обробленням exFAT у Samba. Спробуйте скопіювати файл командою **cp -X file-name**.

    ![Копіювання файла командою cp -X file-name](https://static.gl-inet.com/docs/router/en/4/faq/macos_cannot_write_samba/macopyfile.png){class="glboxshadow"}

    Для копіювання папки скористайтеся командою **cp -rX folder-name**.

    ![Копіювання папки командою cp -rX folder-name](https://static.gl-inet.com/docs/router/en/4/faq/macos_cannot_write_samba/macopyfolder.png){class="glboxshadow"}

3. **Перезавантажте Mac.**

    Відкрийте меню Apple та натисніть Restart. Якщо проблема залишається, вимкніть комп’ютер, від’єднайте всі зовнішні пристрої, зачекайте 30 секунд і перезапустіть його.

4. **Перейменуйте файл.**

    Натисніть файл правою кнопкою миші та виберіть Rename. Використовуйте прості назви без спеціальних символів на кшталт !@# і пробілів.

5. **Повторно підключіть накопичувач.**

    Якщо використовується зовнішній накопичувач, наприклад USB-накопичувач, спочатку безпечно вийміть його в системі, а потім фізично від’єднайте. Зачекайте 10 секунд і підключіть його знову. Також можна спробувати інший порт USB.

6. **Виправте помилки диска за допомогою First Aid.**

    Пошкоджені дані диска можуть спричиняти збої запису. Для усунення проблем можна скористатися Disk Utility у macOS.

    1. Відкрийте Finder -> Applications -> Utilities -> Disk Utility.
    2. Виберіть диск або накопичувач, локальний чи зовнішній, у меню ліворуч.
    3. Натисніть First Aid -> Run. Зачекайте, поки процес завершиться.

7. **Змініть файлову систему або відформатуйте накопичувач.**

    Накопичувач exFAT може мати проблеми сумісності із Samba в macOS. Спробуйте такі способи.

    - **Форматування у FAT32** (для зовнішніх накопичувачів і сумісності між платформами)

        1. Спочатку створіть резервну копію даних накопичувача: форматування видаляє всі файли.
        2. Відкрийте Disk Utility -> виберіть накопичувач -> Erase.
        3. Виберіть формат "MS-DOS (FAT)" (FAT32) і натисніть Erase.

    - **Форматування в ext4**

        !!! Note

            ext4 підтримується насамперед системами Linux. Після форматування в ext4 накопичувач може бути несумісним із Windows. Зокрема, пристрої Windows можуть не розпізнавати накопичувач або не мати змоги записувати на нього дані.

        1. Створіть резервну копію всіх даних накопичувача, оскільки форматування видалить їх.
        2. Відформатуйте накопичувач в ext4 за допомогою засобу на кшталт Disk Utility або системи Linux.

8. **Оновіть macOS і очистьте кеші.**

    Застаріле програмне забезпечення або пошкоджені кеші можуть спричиняти конфлікти. Перейдіть до System Settings -> General -> Software Update, установіть найновішу версію та очистьте системні кеші.
