# Що таке USB-C OTG і як спільно використовувати мережеве з’єднання через USB-C OTG {#what-is-usb-c-otg-and-how-to-share-your-network-via-usb-c-otg}

## USB OTG {#usb-otg}
**USB OTG** (On-The-Go) — стандарт USB, який дає змогу сумісним пристроям, зокрема маршрутизаторам, перемикатися між ролями **Host** і **Device**. Це забезпечує пряме передавання даних і живлення без окремого пристрою-хоста.

Через **USB OTG** можна перемикатися між двома режимами:

- Коли пристрій переходить у **Host mode** через USB OTG, він працює як USB-хост: ініціює передавання даних, забезпечує живлення та керує всіма операціями читання й запису між двома підключеними пристроями.

- У **Device mode** пристрій працює як периферійний: отримує живлення від хоста та реагує на його команди, без можливості самостійно ініціювати обмін даними.

## Спільне використання мережевого з’єднання через USB‑C OTG на Mudi 7 {#network-sharing-via-usbc-otg-on-mudi-7}

Порт USB‑C із підтримкою OTG на Mudi 7 працює в режимі **Device** або **Host** для спільного використання мережевого з’єднання із зовнішніми пристроями. Нижче наведено докладні сценарії.

### Підключення до комп’ютера {#connect-to-a-computer}

Більшість комп’ютерів працюють лише як хости й не підтримують OTG. Після підключення комп’ютера до маршрутизатора через USB на маршрутизаторі з’явиться вікно вибору режиму. Можна вибрати будь-який режим. Mudi 7 спробує автоматично узгодити роль залежно від підтримки системою й драйверами підключеного пристрою. Після успішного узгодження ролі комп’ютер розпізнає Mudi 7 як мережевий USB-адаптер для доступу до інтернету. У більшості випадків додаткові драйвери не потрібні.

### Підключення до смартфона {#connect-to-a-smartphone}

- **Device Mode**: Mudi 7 працює як USB-пристрій і надає телефону доступ до своєї мережі.

- **Host Mode**: після ввімкнення **USB Tethering** на телефоні він може передавати своє стільникове підключення Mudi 7 через USB. Таке USB-з’єднання може працювати як незалежний інтерфейс WAN для підключення Multi-WAN.

!!! Note

    1. Якщо для з’єднання використовується функція OTG телефона, переконайтеся, що телефон підтримує OTG, і використовуйте USB-кабель із підтримкою передавання даних. Кабелі лише для заряджання не передають мережеві сигнали.

    2. У режимі **Device Mode** телефон може не відображати сповіщення про мережеве підключення. Щоб перевірити роботу, перегляньте стан мережі в налаштуваннях телефона або виконайте перевірку з’єднання.

        Наприклад, якщо Mudi 7 надає телефону (як-от iPhone 17 Pro) доступ до своєї мережі через **Device Mode**, перевірте активність цього режиму за наведеними нижче кроками.

        1. За допомогою USB-кабелю з підтримкою OTG підключіть порт USB 3.1 на Mudi 7 до iPhone 17 Pro.

        2. На Mudi 7 виберіть **Device Mode**.

        3. У налаштуваннях телефона ви побачите, що Mudi 7 надає йому доступ до мережі, як показано на знімку екрана нижче.
